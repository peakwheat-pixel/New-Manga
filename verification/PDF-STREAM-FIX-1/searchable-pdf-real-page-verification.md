# 可搜索 PDF 在真实页上的验证（V6）

**产出**: 2026-10-20 · **结果**: `searchable-pdf-real-page-result.json`
**目的**：文本层是唯一没在真实输入上验证过的功能。

## 一、第一次跑出来的结果是错的，原因在我的探针

**第一版探针**：导出成功，但 `fonts: []`、`extracted_text: ""`、所有文本都找不到。

**我当时的判断是「文本层完全不工作」——那是错的。**

**根因**：`ExportService` 只在 `format_options` 含
`{"pdf_content": "searchable_dual_layer"}` 时才调 `compose_searchable`（`service.py` L494-498）。
**我的探针没设它，所以走了普通 `compose()`——那个 PDF 本来就不该有文本层。**

**`fonts: []` 是**正确结果**，不是缺陷。**

## 二、修正后的真实结果

**源页**：`日漫_JA/oc material/17/169.jpg`，1350×1920，82 KB。

**四个 region，文本取自素材树的实际语言**：

| lang | 文本 |
|---|---|
| ja | `こんにちは世界` |
| zh | `你好世界` |
| mixed | `漫画 manga 123` |

**（韩文被移除，原因见 §四。）**

**结果**：

```
pdf_bytes         : 12,632,851      ← 12.6 MB
extracted_text    : "こんにちは世界\n你好世界\n漫画 manga 123\n"
extracted_length  : 25
fonts             : ["P16ExportFont"]
text_found        : {ja: true, zh: true, mixed: true}
all_text_found    : true
render            : 2,592,000 px, 21,480 colours, 248,760 non-white
```

**所以文本层是真的**：

- **字体被嵌入**（`P16ExportFont`）
- **文本可提取**，且**逐字正确**（日文假名 + 汉字 + 拉丁字母混合）
- **页面仍然渲染**（21,480 色，248,760 非白——图片没被破坏）

## 三、限制 1：单页 12.6 MB

**一个 82 KB 的漫画页，导出成可搜索 PDF 后是 12.6 MB。**

**原因是字体**：`msyh.ttc` 原始 **19.5 MB**，压缩后仍占大部分。

**这不是缺陷，是一个真实的可用性代价**：

- **纯图片 PDF**：224,454 字节（上一步失败时的普通 PDF 大小）
- **可搜索 PDF**：12,632,851 字节

**56 倍。**

**一本 200 页的漫画，如果是可搜索 PDF，仅字体就重复 200 次**
（除非 PDF 生成器做字体子集化或跨页共享——**本实现是每页重新嵌入**）。

**我没有改这个行为**：它是 `SEC-FMT` 与 `PDF-STREAM-FIX-1` 范围外的事，
**但它是一个应该被记录的、影响用户选择的事实。**

## 四、限制 2：韩文不支持

**`_embedded_font` 用的候选字体是 `msyh.ttc`（微软雅黑）与 `arial.ttf`。**

**实测**：

| 文本 | 结果 |
|---|---|
| 日文 `こんにちは世界` | **embedded, 19,583,608 bytes** |
| **韩文 `안녕하세요`** | **`ValueError: no installed embeddable font covers searchable PDF text`** |
| 中文 `你好世界` | embedded |
| ASCII `hello` | embedded |

**微软雅黑不含谚文字形，而 `arial.ttf` 也不含。**

**所以**：**韩漫（`韩漫_KO/`）导出为可搜索 PDF 会直接抛异常。**

**这与产品范围直接冲突**：`P18` 的验收项包含 **JA/KO**。

**行为本身是 fail-closed 的**（抛 `ValueError` 而不是产出无文本的 PDF），**这是对的。**

**但它意味着**：**KO 的可搜索 PDF 功能当前不可用。**

**是否修、由谁修，不在本 Task 范围。**

## 五、这两条限制必须与「文本层已验证」一起说

**如果只写「文本层验证通过」，会漏掉**：

- **它只在 JA/ZH/拉丁 上通过**
- **它让文件大 56 倍**

**两个都不影响「文本层能工作」这个结论，但都影响「能不能用」。**

## 六、覆盖了什么

- **真实漫画页 + 真实路径**（`ExportService` + `compose_searchable`）
- **字体嵌入**（`P16ExportFont` 出现在 `get_fonts()`）
- **文本可提取且逐字正确**
- **图像流未被文本层破坏**
