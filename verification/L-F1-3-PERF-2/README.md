**结论**：typed 错误，**不崩溃、不挂起、不返回空结果** ⇒ fail-closed 且可诊断。**行为正确。**

## 3. 并发（**测试设计有缺陷，结论不可用**）

| 模式 | 总耗时 | 吞吐 |
|---|---|---|
| 串行 ×4 | 3.63 s | 1454 MB/s |
| 并发 ×4 线程 | **1.29 s** | **4082 MB/s**（2.8x） |

**表面更快，但结论不成立**：4 线程读**同一文件**，第一个线程把数据读进 **OS 页缓存**，
其余命中缓存。`并发总耗时 ≈ 单次耗时` 正是缓存复用特征，**不是并行 I/O 扩展性**。

**⇒ 本数据不能证明"并发吞吐优于串行"。**

要测真实扩展性需要：①冷缓存（需管理员权限）；②每线程读**不同文件**；③直接打 sidecar wire 层。
