## 3. 三条校准结论（方向性证据）

> 每条给出计算过程与样本基数；**n=50 总抽检量的样本量限制与分母域限制在各条内如实声明**。全部数字由 `summarize_c1_spot_audit.py` 计算（r2 版）。

### 3.a Recall 分母污染：A1/A2 全查范围内 0 个真实文字漏检，0.9618 与「对真实对白低估」方向一致

- **样本基数与分母域（R2）**：fn=35 = A1 6 + A2 GT 2 + FN-partial 27。本次全查覆盖 **A1/A2 两层的 8 个单元（8/35）**；结论**适用于 A1/A2 两层分母**，其余 **27 框（FN-partial，23 个部分命中 region 的残差 GT 框）未校验**，不得外推至全部分母。
- **计算**：8 个 = 7 伪 GT 噪声 + 1 切分粒度（A2-U02，GT 为真实对白但模型切分只盖上半段）+ **0 真实文字漏检**；8/8 完全划分无残差（脚本 fail-closed 校验）。
- 冻结 Recall = 882/917 = 0.9618。若把 7 个噪声从分母剔除：882/910 = **0.9692**；再剔除粒度单元（部分学分口径，显式标注）：882/909 = **0.9703**。
- **结论（方向性）**：可校验域内证据与「Recall 分母含噪声、冻结数字对真实对白文字低估」**一致**；0.9692–0.9703 为 A1/A2 域内的方向性修正估计，非全分母结论。

### 3.b Precision 污染方向确认：抽检 FP 中盲区 FP 25 个、真幻觉 4 个（n_eff=29）

- **样本基数**：108 个 block_coverage FP（B1 78 + B2 30）中按 conf 十分位分层抽取 **30 个**（B1 15/78 + B2 15/30）。
- **R1 重分类后口径**：B1-U11 改判粒度不达标（切分重复检出，非盲区），不计入盲区/幻觉二分；**有效二分样本 n_eff = 29**。
- **计算**：**盲区 FP 25**（83.3% of 30 抽检；86.2% of n_eff；内容构成见 §1：SFX 6、旁白/告示牌/海报 8、署名/标题/话数 7、手写/商标 3、真实对白 1）+ **真幻觉 4**（13.3%）。
- 冻结 Precision = 882/990 = 0.8909（C4 §5.1 已声明为「受污染下界」）。两个方向的修正估计（均只依赖幻觉数 4，R1 重分类不影响）：
  - **保守下界修正**：假设未抽检的 78 框全部为真幻觉 → 882/(882+78+4) = **0.9149**；
  - **比例外推**：108 × 4/30 ≈ 14.4 个真幻觉 → 882/896.4 ≈ **0.9839**（n=30 抽样，不作点估计引用）。
- **结论（方向性）**：两个修正估计均高于 0.8909 → 证据与「Precision 0.8909 下界为低估、污染方向=GT 盲区为主」**一致**。
- **样本量限定**：n=30（占 108 的 27.8%），分层但非全查。
- **对白相关证据（R1 后收窄为 n=1）**：盲区 FP 中仅 **B1-U05** 一例为真实对白（GT 标了相邻气泡）——即有 1 例直接证据表明模型对**对白本身**的检出因 GT 盲区被计 FP；样本量不足以支撑「对白 precision 系统性低估」的强声明，仅作方向性登记。

### 3.c D 层 GT 盲区率：10 抽 5 有字（全部非对白），盲区集中在 SFX 类

- **样本基数**：78 个 `n_det_block=0` region 随机抽 **10 个**全帧复核（种子 `20260930`）。
- **计算**：10 帧中 **5 帧存在可见真实文字**（模型零输出且 GT 零标注 = GT 盲区直接证据），5 帧确无可检文字 → 该层 GT 盲区率 **5/10 = 50%**，Wilson 95% CI **[0.237, 0.763]**（n=10，区间极宽）；朴素外推至 78 个零检测 region ≈ 39 个（仅供参考；D 层分母含 6 个 A1 有 GT region，未被抽中，R14 注）。
- **内容构成**：5 个含字帧全部为**非对白文字**——4 帧 SFX 拟声词 + 1 帧手机屏幕小字「우정사진」，**无一对白**。盲区集中在 SFX 类（恰在 C4 §5.1 冻结的伪 GT「污染」定义内）。
- **结论（方向性）**：D 层证据与「伪 GT 零标注与模型零输出在无对白意义上高度一致」相符；5 个有字帧的字均为 GT 主动排除的类型，模型未检出它们不构成对白能力反证。
- **样本量限定**：n=10，CI 宽；50% 是该层点估计而非精确盲区率。

## 4. C 层诚实呈现与「同源性疑虑」收窄

- **用户严格口径：2/2 粒度不达标**（C 层分母仅 2 对——882 匹配对中 coverage∈[0.5,0.7) 只有 2 对，fallback 全查，无抽样误差但绝对样本量极小）。用户裁决依据已入表（`user_rationale` 列，R5）：
  - **C-U01**（K01 r35，coverage 0.5568）：用户裁决=粒度不达标——检出只盖住 GT 范围的一部分（标题行「ART X vol.2」；下方两行小字由另框检出、被计 B1 FP，见 `frames-export.json` K01 r35 det#1/det#2）——切分差异而非假覆盖。检出框对标题行的覆盖本身是真实的。
  - **C-U02**（K03 r91，coverage 0.5160）：用户裁决=粒度不达标（用户原话：「下面的画面对话没识别」）——精确表述为**下半段已被另框检出但一对一匹配落选**（切分差异，R8 更正：非漏检）。
- **低 coverage 的主因 = 切分不完整**：模型按行/单元素切分，伪 GT 合并为更大块；方向是单向的（模型偏细粒度），与 K08 r3（A2-U02/B1-U11）同一模式。
- **「同源性疑虑」收窄表述**（对照 C4 §5.2 原文「检出框风格可能与机器伪 GT 标注风格对齐」）：**贴合非伪造**——抽检未发现任何「检出框与伪 GT 共同错到一起」的同源伪影；meanCov 0.9965 的高 coverage 与模型输出粒度和块级 GT 天然 1:1 的结构性事实一致（C4 §4：原始框 1021→合并后 990，-3.0% 近乎空转）。但**低 coverage 匹配存在系统性切分差异（方向=模型偏细粒度）**，此差异是真实的、需要在消费侧处理的。
- 反向佐证：B 层 25 个盲区 FP 恰恰说明模型大量检出了伪 GT **根本没标**的真实文字——模型与伪 GT 的「风格」并不趋同，趋同假说在抽检中未获支持。
- **限定**：C 层 n=2，本节结论强度有限（方向性）；meanCov 0.9965 的反面即贴合对稀缺（880/882 对 coverage≥0.7），「粒度差异」总体上被高 coverage 主导。

## 5. 对 C4 Gate 结论的真实世界重解读（核心章节）

### 5.1 重解读（方向性）

抽检证据与 **Recall/Precision 双双为低估（下界）** 的假设方向一致：

| 指标（冻结口径） | 冻结值 | 抽检后的真实世界解读（方向性） |
|---|---|---|
| Recall 882/917 | 0.9618 | A1/A2 全查域（8/35）0 例真实对白漏检、7 伪 GT 噪声 → 与「对真实对白低估」方向一致，域内修正估计 0.9692–0.9703（FN-partial 27 未校验，不外推） |
| Precision 882/990 | 0.8909 | 下界方向与抽检一致：n_eff=29 中 25 个为 GT 盲区真实文字 → 保守修正 0.9149，外推 ~0.98（n=30） |
| MeanCov 0.9965 | PASS | C 层 2 对均为真实文字贴合，未发现假贴合；高 coverage 主要反映粒度天然对齐而非同源伪造（§4） |
| Severe 0/416 | PASS | D 层校准不改变 severe（盲区帧本为 n_gt=0，不入分母），但提示「零检出」≠「无文字」 |

**Gate PASS 的真实含义（方向性表述）= 「对真实对白文字的检测能力优于冻结口径数字」这一解读与抽检证据一致**：C4 报告 §7 的口径声明（「生产块级消费口径、对机器伪 GT 下达标」）在抽检后获得方向性加强——就产品目标（对白检测）而言，冻结数字是真实能力的**保守下界**这一假设与全部可校验证据相容，且未发现反例。C4 §7.1 的「fine-tune 不投入」结论相应获得方向性支持：**在可校验范围内**，真实目标下的剩余空间比冻结口径显示的更小（不外推至未校验域）。

### 5.2 反方向限定与证据强度限定（如实列出，不得省略引用本报告时）

1. **粒度不达标是真实短板**：4 个判定单元 / 3 处独立位置（K08 r3 两段对白只检出上半段——对用户可读性有直接影响；K01 r35、K03 r91 同模式）。方向单向（模型偏细粒度），是消费/合并侧（C4 §7.3 集成 Task 范围）必须处理的已知问题。
2. **无语义装饰图案/物体仍会误检**：幻觉 4/30 抽检（海报字符花纹 ×2、塔尖装饰物、T 恤标签小字），外推约 14/108；且 conf 跨段分布（0.51–0.81），提高阈值不能定向消除。
3. **n=50、单一来源**：全部样本来自 KO webtoon 伪 GT 评测集（10 case）；日漫、扫图、不同排版/画风等真实世界变体未覆盖，本报告结论不外推到该分布之外。
4. **FN-partial 27 框协议外未校验**：Recall 修正估计不覆盖这部分（分母域=A1/A2 的 8/35，R2）。
5. **C 层分母仅 2 对**：同源性收窄结论的样本基础极小。
6. **单标注者（n=1）**：无独立第二标注者交叉验证；标注者内/间可靠性未测量。
7. **锚定效应未测量（R3）**：AI 预填先于人工审核，92% 采纳率与锚定效应相容；「用户审核后采纳」不等于「独立判定」，本报告结论的强度上限为方向性证据。
