## 3. 三条校准结论

> 每条给出计算过程与样本基数；**n=50 总抽检量的样本量限制在各条内如实声明**。全部数字由 `summarize_c1_spot_audit.py` 计算。

### 3.a Recall 分母污染：0 个真实文字漏检，0.9618 对真实对白是低估

- **样本基数**：8 个未匹配 GT 单元，A1×6 + A2×2——**两层均为全查层，无抽样误差，结论适用于正式口径全部分母中的未匹配 GT**。
- **计算**：8 个 = 7 伪 GT 噪声 + 1 切分粒度（A2-U02，GT 为真实对白但模型切分只盖上半段）+ **0 真实文字漏检**。
- 冻结 Recall = 882/917 = 0.9618。若把 7 个噪声从分母剔除：882/910 = **0.9692**；再剔除粒度单元：882/909 = **0.9703**。
- **结论**：Recall 分母确认含噪声，冻结数字对真实对白文字的检测能力是**低估**；真实对白 Recall ≥ 0.9618，点估计约 0.97。
- **样本量限定**：fn=35 中另有 FN-partial 27 框（23 个部分命中 region 的残差 GT 框）在冻结 6 层协议之外**未校验**，其中不排除真实漏检——上 述修正是「可校验范围」内的结论，非全分母结论。

### 3.b Precision 污染方向确认：30 个抽检 FP 中 26 个落在 GT 盲区的真实文字上

- **样本基数**：108 个 block_coverage FP（B1 78 + B2 30）中按 conf 十分位分层抽取 **30 个**（B1 15/78 + B2 15/30）。
- **计算**：30 = **26 盲区 FP（86.7%）**（检出落在真实但未被伪 GT 标注的文字上：SFX 6、旁白/告示牌/海报 8、署名/标题/话数 7、手写/商标 3、真实对白 2）+ **4 真幻觉（13.3%）**。
- 冻结 Precision = 882/990 = 0.8909（C4 §5.1 已声明为「受污染下界」）。两个方向的修正估计：
  - **保守下界修正**：假设未抽检的 78 框全部为真幻觉 → 882/(882+78+4) = **0.9149**；
  - **比例外推**：108 × 4/30 ≈ 14.4 个真幻觉 → 882/896.4 ≈ **0.9839**（n=30 抽样，宽度未量化）。
- **结论**：两个修正估计均高于 0.8909 → **Precision 0.8909 下界同为低估**，污染方向与 C4 §5.1 的假设一致（FP 主体是 GT 盲区，不是模型幻觉）。
- **样本量限定**：n=30（占 108 的 27.8%），分层但非全查；外推值 0.9839 不应作为点估计引用，保守值 0.9149 更稳妥。
- **值得单列的发现**：26 个盲区 FP 中有 **2 个是真实对白**（B1-U05、B1-U11）——即模型对**对白本身**的 precision 同样被 GT 盲区低估，不只在 SFX/装饰文字上。

### 3.c D 层 GT 盲区率：10 抽 5 有字（全部非对白），盲区集中在 SFX 类

- **样本基数**：78 个 `n_det_block=0` region 随机抽 **10 个**全帧复核（种子 `20260930`）。
- **计算**：10 帧中 **5 帧存在可见真实文字**（模型零输出且 GT 零标注 = GT 盲区直接证据），5 帧确无可检文字 → 该层 GT 盲区率 **5/10 = 50%**，Wilson 95% CI **[0.237, 0.763]**（n=10，区间极宽）；朴素外推至 78 个零检测 region ≈ 39 个（仅供参考）。
- **内容构成**：5 个含字帧全部为**非对白文字**——4 帧 SFX 拟声词 + 1 帧手机屏幕小字「우정사진」，**无一对白**。盲区集中在 SFX 类（恰在 C4 §5.1 冻结的伪 GT「污染」定义内：SFX/背景文字本就不在标注范围）。
- **结论**：D 层证实伪 GT 的零标注与模型的零输出在「无对白」意义上高度一致；「模型幻觉为零」的陈述在零检测帧上得到校准（5 个有字帧的字都是 GT 主动排除的类型，模型未检出它们不构成对白能力反证）。
- **样本量限定**：n=10，CI 宽；50% 是该层点估计而非精确盲区率。

## 4. C 层诚实呈现与「同源性疑虑」收窄

- **用户严格口径：2/2 粒度不达标**（C 层分母仅 2 对——882 匹配对中 coverage∈[0.5,0.7) 只有 2 对，fallback 全查，无抽样误差但绝对样本量极小）。
- 两对的具体事实：C-U01（K01 r35，coverage 0.5568）检出框**完整盖住**海报标题「ART X vol.2」，coverage 低是因 GT 块额外含下方两行小字；C-U02（K03 r91，coverage 0.5160）检出只盖 GT 两段的上半段。两对检出框都**真实贴合可见文字**——既非「擦边假覆盖」，也非完整匹配；检出只盖住 GT 的 **52%–56%**。
- **低 coverage 的主因 = 切分不完整**：模型按行/单元素切分，伪 GT 合并为更大块；方向是单向的（模型偏细粒度），与 K08 r3（A2-U02/B1-U11）同一模式。
- **「同源性疑虑」收窄表述**（对照 C4 §5.2 原文「检出框风格可能与机器伪 GT 标注风格对齐」）：**贴合非伪造**——抽检未发现任何「检出框与伪 GT 共同错到一起」的同源伪影；meanCov 0.9965 的高 coverage 与模型输出粒度和块级 GT 天然 1:1 的结构性事实一致（C4 §4：原始框 1021→合并后 990，-3.0% 近乎空转）。但**低 coverage 匹配存在系统性切分差异（方向=模型偏细粒度）**，此差异是真实的、需要在消费侧处理的。
- 反向佐证：B 层 26 个盲区 FP 恰恰证明模型大量检出了伪 GT **根本没标**的真实文字——模型与伪 GT 的「风格」并不趋同，趋同假说在抽检中未获支持。
- **限定**：C 层 n=2，本节结论强度有限；meanCov 0.9965 的反面即贴合对稀缺（880/882 对 coverage≥0.7），「粒度差异」总体上被高 coverage 主导。

## 5. 对 C4 Gate 结论的真实世界重解读（核心章节）

### 5.1 重解读

抽检证据下 **Recall 与 Precision 双双确认为低估（下界）**：

| 指标（冻结口径） | 冻结值 | 抽检后的真实世界解读 |
|---|---|---|
| Recall 882/917 | 0.9618 | 分母含 7 伪 GT 噪声（全查证实），0 个真实对白漏检 → 对真实对白**低估**，修正估计 0.9692–0.9703（FN-partial 27 未校验为剩余限定） |
| Precision 882/990 | 0.8909 | 下界确认：抽检 FP 的 86.7% 是 GT 盲区上的真实文字 → 保守修正 ≥0.9149，外推 ~0.98（n=30） |
| MeanCov 0.9965 | PASS | C 层 2 对均为真实文字贴合，未发现假贴合；高 coverage 主要反映粒度天然对齐而非同源伪造（§4） |
| Severe 0/416 | PASS | D 层校准不改变 severe（盲区帧本为 n_gt=0，不入分母），但提示「零检出」≠「无文字」 |

**Gate PASS 的真实含义 = 「对真实对白文字的检测能力优于冻结口径数字」**：C4 报告 §7 的口径声明（「生产块级消费口径、对机器伪 GT 下达标」）在抽检后可以加强为——就产品目标（对白检测）而言，冻结数字是真实能力的**保守下界**，「口径内 PASS」与「真实世界达标」的缝隙经人工抽检校验后**未发现反例，且方向性证据一致向好**。C4 §7.1 的「fine-tune 不投入」结论相应加强：真实目标下的剩余空间比冻结口径显示的更小。

### 5.2 反方向限定（如实列出，不得省略引用本报告时）

1. **粒度不达标是真实短板**：3/50（K08 r3 两段对白只检出上半段——对用户可读性有直接影响；K01 r35、K03 r91 同模式）。方向单向（模型偏细粒度），是消费/合并侧（C4 §7.3 集成 Task 范围）必须处理的已知问题。
2. **无语义装饰图案/物体仍会误检**：幻觉 4/30 抽检（海报字符花纹 ×2、塔尖装饰物、T 恤标签小字），外推约 14/108；且 conf 跨段分布（0.51–0.81），提高阈值不能定向消除。

4. **FN-partial 27 框协议外未校验**：Recall 修正估计不覆盖这部分。
5. **C 层分母仅 2 对**：同源性收窄结论的样本基础极小。
6. **单标注者**：人工判定无第二标注者交叉验证；47/3 的确认/修订结构表明审核有效，但标注者内/间可靠性未测量。
