# C1 GT 盲区抽检：用户人工判定指引（阶段二）

> 本目录由 M2-DOCTR-QUAL-C1 阶段一（agent 全自动）产出。**判定列必须由用户本人填写**——本审计的全部价值就在人工眼睛，agent 不代做、不预填。

## 你要做什么

逐个查看 50 个抽样单元的预览图，对每个单元给出**且仅给出一个**分类判定，填入工作表的 `verdict` 列，并用一句话依据填 `rationale` 列。

## 怎么开图

工作表每行 `preview_file` 形如 `B1-U07__K06_R036.png`。到预览目录打开同名文件即可。图顶部条带含单元 ID、case/region、conf/coverage；**绿框 = GT（伪 GT 标注框），红框 = 模型检出框**。

## 六层各自看什么

| 层 | 单元数 | 图上你会看到 | 判定问题 | 该层 verdict 枚举（二选一） |
|---|---|---|---|---|
| A1 真未检出 | 6 | 只有绿框（region 无任何检出） | 绿框是**真实文字**（模型漏检）还是**伪 GT 噪声**（SFX/背景纹理/拟声词等不该算文字的东西） | `真实文字漏检` / `伪 GT 噪声` |
| A2 coverage 不达标 | 2 | 绿框 + 红框（检出存在但覆盖不足 0.5） | 红框与绿框的错位是**粒度/边界问题**（框到了文字但形状/范围不合），还是 **GT 本身是噪声** | `粒度不达标` / `伪 GT 噪声` |
| B1 有 GT region 的 FP | 15 | 红框（待判定 FP）+ 细绿框（该 region 的 GT，仅作上下文） | 红框落在**真实但未被标注的文字**上（说明 GT 有盲区、模型其实是对的），还是落在**无文字处**（模型幻觉） | `盲区 FP` / `模型幻觉` |
| B2 无 GT region 的 FP | 15 | 只有红框（region 本无 GT） | 同 B1，这是盲区/幻觉判别最干净的样本 | `盲区 FP` / `模型幻觉` |
| C 贴合匹配对 | 2 | 绿框 + 红框高度重叠（coverage ∈ [0.5,0.7)） | 检出框是**正确覆盖了真实文字**（匹配可信），还是**仅擦边盖住 GT**（贴合是假的，粒度问题）——本层是对「检出框风格与伪 GT 同源」疑虑的直接检验 | `真匹配` / `粒度不达标` |
| D 零检测全帧复核 | 10 | 整帧缩略，无红框（该帧模型零输出） | 帧内**是否存在可见的真实文字**（若存在：模型与伪 GT 一起漏了 = GT 盲区证据）；还是确实无文字（零输出与零标注一致） | `一致（确无可检文字）` / `GT 盲区（有真实文字未标注未检出）` |

> B 层枚举语义替换（协议原文）：四分类中的「盲区 FP」在 B 层保留，「真实文字漏检/伪 GT 噪声」替换为「盲区 FP/模型幻觉」。上表已按层写明，直接照抄枚举原文填表即可。

## 填表规则

1. `verdict` 列：从该层枚举中**原文照抄一个**（不要自创枚举、不要留空、不要写两个）。
2. `rationale` 列：一句话依据，如「绿框处为 SFX 拟声词，非对白文字」「红框内无任何文字」「红框覆盖了对白但只盖住半行」。
3. 不确定时凭第一眼视觉判断填写，并在 `rationale` 里注明「不确定：」前缀——允许不确定，不允许空着。
4. 50 行全部填完后**不要改其他列**。

## 背景一分钟版

C4 评估中，现成 manga 域检测器在机器伪 GT 口径上 Recall 0.9618 全 Gate PASS。但伪 GT 本身是机器标注（`text_seg` score≥0.5），存在两种可能：未匹配的 GT 多为伪 GT 噪声（→ 真实表现比 0.9618 更好），或存在真实文字漏检/贴合失真（→ 需重估结论）。你这次的 50 单元人工判定就是在这两种可能之间做裁决；其中 C 层直接检验「检出框是否只是和伪 GT 标注风格对齐」。
