# P04：生产命令族与同通道桥接并发定向验证

## 来源与目标

来源为 [REBASELINE_PLAN 的 P04 路线项](../REBASELINE_PLAN.md)；PAGE-NAV 依赖 `M2-PAGE-NAV-PROJECTION-1` 已集成。代码证据静态核验基于 `main@88579622d85ff6d0dfd509c6f21931bd91d0881b`。

可观察目标：直接固定 `PAGE_NAV_PRODUCTION_ONLY_COMMANDS` 的精确成员，并以可控 sidecar 诊断 `StdioLibraryChannel` 同一实例上的并发请求/响应归属及现有协议字段。当前观察到 `main.rs` 已固定整张 15 项生产命令面，并在 probe/AC1 上扫过生产专属组；但该组常量缺少自身的精确成员断言，等长误替换可能漏过现有检查。`library_bridge.rs` 的 `round_trip` 分别锁 stdin 与 stdout，尚未核验并发调用下响应是否仍归属正确调用方；这是待复现风险，不是已确认缺陷。

协议核验以 [M2-C1 Typed IPC Contract §3–4](../contracts/M2-C1_TYPED_IPC_CONTRACT.md) 与当前 Core sidecar 的实际响应为证据；仅记录当前实现，不借本 Task 冻结新的产品协议语义。
