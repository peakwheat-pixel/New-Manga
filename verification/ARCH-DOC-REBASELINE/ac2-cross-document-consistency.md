## 3. 跨文档潜在历史残留与裁决说明

在核验过程中，我们审查了早期文档中遗留的术语表述，并作出正式重基线裁决：
1. **QML ViewModel 术语**：
   - *历史残留*：部分文档（如 02、04、05）曾提及“QObject / ViewModel 状态投影”。
   - *重基线裁决*：在 AD-001 新架构下，统一裁决为“**Python Core Application Service 产出 JSON 投影状态，通过 Tauri IPC 传递给 React 前端状态管理（如 Zustand/Redux）**”。原 ViewModel 的业务规约完全保留，但其实现形态与 Qt Quick 解耦。
2. **多进程与线程模型**：
   - *历史残留*：02 与 07 中曾提及“QThread 线程池”。
   - *重基线裁决*：新架构中，Tauri 运行在 Rust 主线程与 Tokio 异步池；Python Core 作为独立子进程（Sidecar），内部采用 `asyncio` + `concurrent.futures.ProcessPoolExecutor/ThreadPoolExecutor` 实现多核 CPU/GPU 隔离调度。业务上的线程安全与防卡死要求完全保留且标准不降。
