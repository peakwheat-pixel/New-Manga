# AC5 generated-file side effects

Cargo's Tauri build step marked 27 tracked generated schema/permission files modified while `core.autocrlf=true`. `git diff -- <those paths>` was empty, so the status was line-ending-only noise. The paths were restored individually with `git restore --worktree -- <the 27 paths>` after the final Cargo run. They no longer appear in `git status`; no product source, contract, dependency, schema content, or generated permission content was changed by this task.
