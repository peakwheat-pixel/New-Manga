## 结论与限制

`core.autocrlf=false` 能让目标文件按 Git blob 的 LF 检出，并消除已观察到的 checkout 行尾差异，但**并未证明 Tauri build 全程不会改写任何禁止路径**。由于 fail-closed sidecar 输入缺失，尚未实际调用 `tauri_build::try_build` 验证生成后的字节差异。若要在 P02 中真实构建，须先由 Codex明确登记隔离 Sidecar build input 的临时路径/来源与复算 Hash（或依当前 Task 诚实将依赖 AC 置为 `BLOCKED`）；不得用 `CARGO_TARGET_DIR` 代替该路径核验，也不得放宽整个 `src-tauri/**`。
