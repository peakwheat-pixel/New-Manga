## 分类准则与停止条件

- `PASS_WITH_EVIDENCE` 只表示某个精确只读检查成功且结果满足已冻结的局部条件；不表示整个 P02PRE、Technical Gate、Build Gate 或 AC 通过。
- `FAILED` 只在已冻结局部条件有直接相反证据时使用；查询错误/权限拒绝单独不算失败。
- `UNPROVABLE` 表示现有合同/采样无法证明必要条件。
- `REQUIRES_ACTIVE_TEST` 表示必须运行后续受控 API/写入/真实子进程测试才可证明；本 Task 不执行。
- `NOT_SAFE_FOR_R0` 表示调用/范围/顺序本身无法证明满足本只读 Task。
- 任一身份不符、未知子进程、写入、注册表/ACL/文件状态异常或取证异常：立即停止余下 OS 查询，不重试、不修复、不清理；写 evidence 后保持 `BLOCKED`。

## Microsoft Learn 来源

本 manifest 仅采用下列方法的 getter/query 语义，不推断它们能证明未来 AppContainer/controller 的执行安全：

- [`WindowsIdentity.GetCurrent(Boolean)`](https://learn.microsoft.com/en-us/dotnet/api/system.security.principal.windowsidentity.getcurrent)：返回当前线程/进程 Windows identity；只记录 SID/身份属性，不输出或保留 token handle。
- [`Environment.GetEnvironmentVariable(String)`](https://learn.microsoft.com/en-us/dotnet/api/system.environment.getenvironmentvariable)：只从当前 Process environment block 读取指定变量，不读 User/Machine registry target。
- [`Path.GetFullPath(String)`](https://learn.microsoft.com/en-us/dotnet/api/system.io.path.getfullpath)：返回 absolute path；仅做 r6 已列环境路径的路径归一化，不据此声称 filesystem canonical identity 或 reparse safety。
- [`FileSystemInfo.Attributes`](https://learn.microsoft.com/en-us/dotnet/api/system.io.filesysteminfo.attributes) 与 PowerShell [`Get-Acl`](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.security/get-acl)：读取精确路径对象属性与 security descriptor；只在 manifest 精确对象上调用，不调用写属性/`Set-Acl`。
- [`RegistryKey.OpenSubKey(String, Boolean)`](https://learn.microsoft.com/en-us/dotnet/api/microsoft.win32.registrykey.opensubkey)：`writable=false` 请求只读 key access；仅用作 r6 两个 WER 候选键存在性查询，不枚举 values/subkeys。
- PowerShell [`Get-FileHash`](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash)：计算固定文档文件的 SHA-256，不输出文件内容。
- Win32 [`GetTokenInformation`](https://learn.microsoft.com/en-us/windows/win32/api/securitybaseapi/nf-securitybaseapi-gettokeninformation) 确实检索给定 access token 的信息；本 Task 不通过 P/Invoke/`Add-Type` 调用它，因为实现/动态编译/子进程边界未冻结，相关详细 token fields=`NOT_SAFE_FOR_R0`。
