## 受审 Gate 通过后的单次执行顺序

1. 重核 root HEAD、branch、common Git directory、202 项保护清单状态/hash 与 RESUME snapshot hash；确认 scratch 绝对路径不存在。
2. 以 git -c core.autocrlf=false -C "G:/CODEX/New Manga" worktree add --detach "G:/CODEX/New Manga.worktrees/P02-scratch-build-r8-codex" 7ce3c40cd308e7093929bd5f53abc4f8a6c4ef7a 创建独立 checkout；记录 scratch HEAD/tree/status、目标输出目录存在状态与所有已跟踪生成文件的原始 hash。
3. 在 scratch 建立 verification/P02/npm-cache、cargo-home、cargo-target、tmp、python-cache、pyinstaller-config。frontend/node_modules、frontend/dist、src-tauri/target/core-sidecar、src-tauri/target/pyinstaller-work 必须初始不存在；src-tauri/gen/schemas 与 permissions/autogenerated 允许存在，并记录基线。
4. 在 frontend cwd 执行 npm ci --cache "<scratch>/verification/P02/npm-cache" 与 npm run build。从 scratch repo root 用已固定的 Python/weights 路径调用 packaging/m2ac5/build_sidecar.ps1 -Force，不得传 -SkipWeights。再在 scratch root 设置 CARGO_TARGET_DIR 到该 scratch 的 verification/P02/cargo-target，执行 cargo build --locked --release --manifest-path "<scratch>/apps/desktop/src-tauri/Cargo.toml"。每条命令记录完整 stdout/stderr/exit、CWD、工具版本、HEAD/tree、输入 hash 和产物 hash；若锁文件/工具链要求升级或修改依赖，立即停。
5. 复核 scratch 的完整 porcelain、tracked diff 与 ignored output 清单。只允许 Task 登记路径中的生成变化；记录 gen/schema 与 auto-permission 每个 changed file 的 before/after hash。其他 tracked path 变化、scratch 外写入、root manifest mismatch 或外部 cache 写入迹象均记 BLOCKED 并保留现场，不修复、不覆盖、不清理。
6. 不启动 EXE、不运行 installer/bundler、P02 runner、Vitest、GUI、WebView/CDP、鼠标/键盘操作。独立复核 build 结果之后仍须单独授权 AC1–AC6 实际验证。
