`-Force` 是显式冻结参数，用于纳入 hidden/system 对象；不表示递归、不解析 reparse target，也不读取内容。路径/drive cmdlet 以 `Microsoft.PowerShell.Management\` 模块限定，module metadata query 以 `Microsoft.PowerShell.Core\` 限定，且只允许使用已预先加载并经 `$PSHOME` 固定路径核验的 built-in module；不触发模块自动加载或同名函数/alias 替代。`Get-Item` 查询失败一律=`UNPROVABLE`，不从异常类别推断不存在。Utility serializer 仅在该 built-in module 也通过相同路径核验后调用；未通过时只向 stdout 输出固定 stop record 并返回。每条命令的错误必须保留原始 `ErrorRecord.ToString()`、`CategoryInfo`、`FullyQualifiedErrorId`、异常类型并绑定 exact target；不得更换方法或扩大范围重试。

## 冻结 PowerShell capture body

以下脚本是唯一允许的 R0S1 capture body。通过 Codex 的当前 PowerShell process 直接执行；不得将脚本写入 scratch、临时目录或其他项目路径。输出由调用工具捕获并随后写入 evidence 文档。

```powershell
$ErrorActionPreference = 'Stop'
$startedUtc = [DateTimeOffset]::UtcNow.ToString('o')
$capturePid = $PID
$expectedSid = 'S-1-5-21-2196946971-914346751-4210154634-1001'
$captureStatus = $null
$moduleResult = $null
$driveResult = $null
$moduleError = $null
$driveError = $null
$modulesTrusted = $false
$identityResult = $null
$identityError = $null
$threadIdentity = $null
try {
    $identity = [Security.Principal.WindowsIdentity]::GetCurrent($false)
    $threadIdentity = [Security.Principal.WindowsIdentity]::GetCurrent($true)
    $identityResult = [pscustomobject]@{
        Name = $identity.Name
        Sid = $identity.User.Value
        Authenticated = $identity.IsAuthenticated
        AuthenticationType = $identity.AuthenticationType
        ThreadIdentityPresent = ($null -ne $threadIdentity)
        ThreadName = if ($null -ne $threadIdentity) { $threadIdentity.Name } else { $null }
        ThreadSid = if ($null -ne $threadIdentity -and $null -ne $threadIdentity.User) { $threadIdentity.User.Value } else { $null }
    }
} catch {
    $identityError = [pscustomobject]@{ Category = [string]$_.CategoryInfo.Category; FullyQualifiedErrorId = $_.FullyQualifiedErrorId; ExceptionType = $_.Exception.GetType().FullName; ErrorRecord = $_.ToString() }
}
$commonPaths = @('G:\', 'G:\CODEX', 'G:\CODEX\P02-scratch-build-source', 'G:\CODEX\P02-scratch-build-source\apps', 'G:\CODEX\P02-scratch-build-source\apps\desktop', 'G:\CODEX\P02-scratch-build-source\apps\desktop\src-tauri')
$branches = @(
    [pscustomobject]@{ Id = 'L1'; Target = 'G:\CODEX\P02-scratch-build-source\apps\desktop\src-tauri\gen\schemas'; Ancestors = @('G:\CODEX\P02-scratch-build-source\apps\desktop\src-tauri\gen', 'G:\CODEX\P02-scratch-build-source\apps\desktop\src-tauri\gen\schemas') },
    [pscustomobject]@{ Id = 'L2'; Target = 'G:\CODEX\P02-scratch-build-source\apps\desktop\src-tauri\permissions\autogenerated'; Ancestors = @('G:\CODEX\P02-scratch-build-source\apps\desktop\src-tauri\permissions', 'G:\CODEX\P02-scratch-build-source\apps\desktop\src-tauri\permissions\autogenerated') }
)
$ancestorResults = @()
$leafResults = @()
$commonFailure = $null
if ($null -eq $identityResult) {
    $captureStatus = 'STOP_IDENTITY_UNPROVABLE'
} elseif ($identityResult.Sid -ne $expectedSid -or -not $identityResult.Authenticated -or $null -ne $threadIdentity) {
    $captureStatus = 'STOP_IDENTITY_MISMATCH_OR_THREAD_IMPERSONATION'
} else {
    $managementModule = @()
    $utilityModule = @()
    $moduleError = $null
    try {
        $managementModule = @(Microsoft.PowerShell.Core\Get-Module -Name 'Microsoft.PowerShell.Management' -ErrorAction Stop)
        $utilityModule = @(Microsoft.PowerShell.Core\Get-Module -Name 'Microsoft.PowerShell.Utility' -ErrorAction Stop)
        $expectedManagementPath = [IO.Path]::GetFullPath([IO.Path]::Combine($PSHOME, 'Modules', 'Microsoft.PowerShell.Management', 'Microsoft.PowerShell.Management.psd1'))
        $expectedUtilityPath = [IO.Path]::GetFullPath([IO.Path]::Combine($PSHOME, 'Modules', 'Microsoft.PowerShell.Utility', 'Microsoft.PowerShell.Utility.psd1'))
        $modulesTrusted = $managementModule.Count -eq 1 -and $utilityModule.Count -eq 1 -and [string]::Equals([IO.Path]::GetFullPath([string]$managementModule[0].Path), $expectedManagementPath, [StringComparison]::OrdinalIgnoreCase) -and [string]::Equals([IO.Path]::GetFullPath([string]$utilityModule[0].Path), $expectedUtilityPath, [StringComparison]::OrdinalIgnoreCase)
        $moduleResult = [pscustomobject]@{ Status = if ($modulesTrusted) { 'VERIFIED' } else { 'NOT_SAFE_FOR_R0' }; ManagementPath = if ($managementModule.Count -eq 1) { [string]$managementModule[0].Path } else { $null }; UtilityPath = if ($utilityModule.Count -eq 1) { [string]$utilityModule[0].Path } else { $null }; ExpectedManagementPath = $expectedManagementPath; ExpectedUtilityPath = $expectedUtilityPath }
    } catch {
        $moduleError = [pscustomobject]@{ Category = [string]$_.CategoryInfo.Category; FullyQualifiedErrorId = $_.FullyQualifiedErrorId; ExceptionType = $_.Exception.GetType().FullName; ErrorRecord = $_.ToString() }
        $modulesTrusted = $false
    }
    if (-not $modulesTrusted) {
        $commonFailure = 'NOT_SAFE_FOR_R0'
        $captureStatus = 'STOP_UNTRUSTED_OR_UNAVAILABLE_BUILTIN_MODULE'
    } else {
        try {
            $drive = Microsoft.PowerShell.Management\Get-PSDrive -Name 'G' -ErrorAction Stop
            $driveProvider = if ($null -ne $drive.Provider) { [string]$drive.Provider.Name } else { $null }
            $driveRoot = [string]$drive.Root
            $driveResult = [pscustomobject]@{ Name = [string]$drive.Name; Provider = $driveProvider; Root = $driveRoot }
            if ($driveProvider -ne 'FileSystem' -or -not [string]::Equals($driveRoot, 'G:\', [StringComparison]::OrdinalIgnoreCase)) {
                $commonFailure = 'NOT_SAFE_FOR_R0'
                $captureStatus = 'STOP_DRIVE_PROVIDER_OR_ROOT_MISMATCH'
            }
        } catch {
            $commonFailure = 'UNPROVABLE'
            $driveError = [pscustomobject]@{ Category = [string]$_.CategoryInfo.Category; FullyQualifiedErrorId = $_.FullyQualifiedErrorId; ExceptionType = $_.Exception.GetType().FullName; ErrorRecord = $_.ToString() }
            $captureStatus = 'STOP_DRIVE_QUERY_UNPROVABLE'
        }
    }
}
if ($null -ne $identityResult -and $identityResult.Sid -eq $expectedSid -and $identityResult.Authenticated -and $null -eq $threadIdentity -and $null -eq $commonFailure -and $null -eq $captureStatus) {
    foreach ($path in $commonPaths) {
        try { $items = @(Microsoft.PowerShell.Management\Get-Item -LiteralPath $path -Force -ErrorAction Stop) }
        catch {
            $category = [string]$_.CategoryInfo.Category
            $exceptionType = $_.Exception.GetType().FullName
            $ancestorResults += [pscustomobject]@{ Path = $path; Status = 'UNPROVABLE'; Category = $category; FullyQualifiedErrorId = $_.FullyQualifiedErrorId; ExceptionType = $exceptionType; ErrorRecord = $_.ToString() }
            $commonFailure = 'UNPROVABLE'
            break
        }
        if ($items.Count -ne 1) {
            $ancestorResults += [pscustomobject]@{ Path = $path; Status = 'NOT_SAFE_FOR_R0'; ResultCount = $items.Count }
            $commonFailure = 'NOT_SAFE_FOR_R0'
            break
        }
        $item = $items[0]
        if ($item -isnot [IO.FileSystemInfo]) {
            $ancestorResults += [pscustomobject]@{ Path = $path; Status = 'NOT_SAFE_FOR_R0'; ResultType = $item.GetType().FullName }
            $commonFailure = 'NOT_SAFE_FOR_R0'
            break
        }
        $provider = if ($null -ne $item.PSProvider) { [string]$item.PSProvider.Name } else { $null }
        $resolvedPath = if ($null -ne $item.FullName) { [IO.Path]::GetFullPath([string]$item.FullName) } else { $null }
        $expectedPath = [IO.Path]::GetFullPath($path)
        if ($provider -ne 'FileSystem' -or -not [string]::Equals($resolvedPath, $expectedPath, [StringComparison]::OrdinalIgnoreCase)) {
            $ancestorResults += [pscustomobject]@{ Path = $path; FullName = $item.FullName; Provider = $provider; Status = 'NOT_SAFE_FOR_R0' }
            $commonFailure = 'NOT_SAFE_FOR_R0'
            break
        }
        $attributes = $item.Attributes
        if (($attributes -band [IO.FileAttributes]::ReparsePoint) -ne 0) {
            $ancestorResults += [pscustomobject]@{ Path = $path; FullName = $item.FullName; Provider = $provider; Attributes = [string]$attributes; Status = 'NOT_SAFE_FOR_R0' }
            $commonFailure = 'NOT_SAFE_FOR_R0'
            break
        }
        if (-not $item.PSIsContainer) {
            $ancestorResults += [pscustomobject]@{ Path = $path; FullName = $item.FullName; Provider = $provider; IsContainer = $false; Attributes = [string]$attributes; Status = 'NOT_SAFE_FOR_R0' }
            $commonFailure = 'NOT_SAFE_FOR_R0'
            break
        }
        $metadata = [pscustomobject]@{ Path = $path; Name = $item.Name; FullName = $item.FullName; Provider = $provider; IsContainer = $true; Attributes = [string]$attributes; LastWriteTimeUtc = $item.LastWriteTimeUtc.ToString('o') }
        $ancestorResults += $metadata
    }
    if ($null -ne $commonFailure) {
        foreach ($branch in $branches) {
            $leafResults += [pscustomobject]@{ Id = $branch.Id; Target = $branch.Target; Status = $commonFailure; Reason = '共同祖先链未能完整确认；未继续访问该分支 leaf。'; ChildCount = $null }
        }
        $captureStatus = 'COMMON_ANCESTOR_STOP'
    } else {
        foreach ($branch in $branches) {
            $branchStatus = $null
            foreach ($path in $branch.Ancestors) {
                try { $items = @(Microsoft.PowerShell.Management\Get-Item -LiteralPath $path -Force -ErrorAction Stop) }
                catch {
                    $category = [string]$_.CategoryInfo.Category
                    $exceptionType = $_.Exception.GetType().FullName
                    $ancestorResults += [pscustomobject]@{ Path = $path; Branch = $branch.Id; Status = 'UNPROVABLE'; Category = $category; FullyQualifiedErrorId = $_.FullyQualifiedErrorId; ExceptionType = $exceptionType; ErrorRecord = $_.ToString() }
                    $branchStatus = 'UNPROVABLE'
                    break
                }
                if ($items.Count -ne 1) {
                    $ancestorResults += [pscustomobject]@{ Path = $path; Branch = $branch.Id; Status = 'NOT_SAFE_FOR_R0'; ResultCount = $items.Count }
                    $branchStatus = 'NOT_SAFE_FOR_R0'
                    break
                }
                $item = $items[0]
                if ($item -isnot [IO.FileSystemInfo]) {
                    $ancestorResults += [pscustomobject]@{ Path = $path; Branch = $branch.Id; Status = 'NOT_SAFE_FOR_R0'; ResultType = $item.GetType().FullName }
                    $branchStatus = 'NOT_SAFE_FOR_R0'
                    break
                }
                $provider = if ($null -ne $item.PSProvider) { [string]$item.PSProvider.Name } else { $null }
                $resolvedPath = if ($null -ne $item.FullName) { [IO.Path]::GetFullPath([string]$item.FullName) } else { $null }
                $expectedPath = [IO.Path]::GetFullPath($path)
                if ($provider -ne 'FileSystem' -or -not [string]::Equals($resolvedPath, $expectedPath, [StringComparison]::OrdinalIgnoreCase)) {
                    $ancestorResults += [pscustomobject]@{ Path = $path; Branch = $branch.Id; FullName = $item.FullName; Provider = $provider; Status = 'NOT_SAFE_FOR_R0' }
                    $branchStatus = 'NOT_SAFE_FOR_R0'
                    break
                }
                $attributes = $item.Attributes
                if (($attributes -band [IO.FileAttributes]::ReparsePoint) -ne 0) {
                    $ancestorResults += [pscustomobject]@{ Path = $path; Branch = $branch.Id; FullName = $item.FullName; Provider = $provider; Attributes = [string]$attributes; Status = 'NOT_SAFE_FOR_R0' }
                    $branchStatus = 'NOT_SAFE_FOR_R0'
                    break
                }
                if (-not $item.PSIsContainer) {
                    $ancestorResults += [pscustomobject]@{ Path = $path; Branch = $branch.Id; FullName = $item.FullName; Provider = $provider; IsContainer = $false; Attributes = [string]$attributes; Status = 'NOT_SAFE_FOR_R0' }
                    $branchStatus = 'NOT_SAFE_FOR_R0'
                    break
                }
                $metadata = [pscustomobject]@{ Path = $path; Branch = $branch.Id; Name = $item.Name; FullName = $item.FullName; Provider = $provider; IsContainer = $true; Attributes = [string]$attributes; LastWriteTimeUtc = $item.LastWriteTimeUtc.ToString('o') }
                $ancestorResults += $metadata
            }
            if ($null -ne $branchStatus) {
                $leafResults += [pscustomobject]@{ Id = $branch.Id; Target = $branch.Target; Status = $branchStatus; Reason = '该分支祖先/leaf 查询失败或范围不安全；未列举 children。'; ChildCount = $null }
                continue
            }
            try {
                $children = @(Microsoft.PowerShell.Management\Get-ChildItem -LiteralPath $branch.Target -Force -ErrorAction Stop)
                $status = if ($children.Count -eq 0) { 'PASS_WITH_EVIDENCE' } else { 'FAILED' }
                $leafResults += [pscustomobject]@{ Id = $branch.Id; Target = $branch.Target; Status = $status; ChildCount = $children.Count }
            } catch {
                $leafResults += [pscustomobject]@{ Id = $branch.Id; Target = $branch.Target; Status = 'UNPROVABLE'; Category = [string]$_.CategoryInfo.Category; FullyQualifiedErrorId = $_.FullyQualifiedErrorId; ExceptionType = $_.Exception.GetType().FullName; ErrorRecord = $_.ToString(); ChildCount = $null }
            }
        }
        $captureStatus = 'CAPTURED'
    }
}
if ($leafResults.Count -eq 0) {
    $stopStatus = if ($null -ne $commonFailure) { $commonFailure } else { 'UNPROVABLE' }
    foreach ($branch in $branches) { $leafResults += [pscustomobject]@{ Id = $branch.Id; Target = $branch.Target; Status = $stopStatus; Reason = '前置身份、module、drive 或共同路径检查未通过；未列举 children。'; ChildCount = $null } }
}
$endedUtc = [DateTimeOffset]::UtcNow.ToString('o')
$report = [pscustomobject]@{ CapturePid = $capturePid; StartedUtc = $startedUtc; EndedUtc = $endedUtc; Identity = $identityResult; IdentityError = $identityError; Drive = $driveResult; DriveError = $driveError; Modules = $moduleResult; ModuleError = $moduleError; CaptureStatus = $captureStatus; Ancestors = $ancestorResults; Leaves = $leafResults }
if ($modulesTrusted) {
    $report | Microsoft.PowerShell.Utility\ConvertTo-Json -Depth 8 -Compress
} else {
    [Console]::Out.WriteLine(('STOP|CapturePid={0}|CaptureStatus={1}|Identity={2}|IdentityError={3}|Modules={4}|ModuleError={5}' -f $capturePid, $captureStatus, [string]$identityResult, [string]$identityError, [string]$moduleResult, [string]$moduleError))
    return
}
```

## 结果字段与判定

Evidence 记录 UTC capture window、PID、identity/SID、thread impersonation 结果、内置 module 与 G: provider/root 检查、逐 ancestor/target exact command、path metadata、direct-child count、命令 exit/error 和限制。不得把 host 目录状态外推至未来执行时点；direct-child 清单不输出名称或内容。

- 命令成功、目录为普通目录且 direct child count=`0`：该 leaf 当前 empty=`PASS_WITH_EVIDENCE`，仅绑定精确路径及采集时点。
- 任一 `Get-Item` 失败（包括对象不存在类错误）：`UNPROVABLE`；不得由异常类别推断为 absent，也不继续访问该分支。
- direct child count>`0`：该 leaf 当前 empty-or-absent 谓词=`FAILED`；只记录已授权 metadata，不删除/改动任何对象。
- 读取失败、身份不符、当前对象不能确认或结果不完整：`UNPROVABLE`；身份或线程状态不符时停止全部路径查询。
- ReparsePoint、对象类型不符、多个结果、provider/root/FullName 异常或 API safety 不确定：目标=`NOT_SAFE_FOR_R0` 并停止该目标；不得跟随、递归或切换 getter。Direct children 只计数，不读取其属性或名称。
- 需要真实 LPAC token/canary、未来 freshness、并发/完整 child write closure 的项目仍=`REQUIRES_ACTIVE_TEST` 或 `UNPROVABLE`，本 Task 不处理。

## 停止条件与禁止项

身份/SID 不匹配、thread impersonation 存在、未冻结 process/API、共同祖先路径异常、冻结 ancestor/leaf 检查发现 reparse point、命令触及冻结 exact path 以外的可观察对象、输出包含未授权 metadata、出现写入或证据异常时立即停止对应范围。安全问题局限于单一分支时，另一 exact leaf 仅可在身份、共同 ancestor 与 process 前置检查仍有效且其独立读取安全时继续。

严禁：profile create/delete 或任何 AppContainer API；registry query/write；ACL query/modify；文件/目录写、删、移动、覆盖；受保护路径写入测试；子进程；递归；冻结 ancestor 以外的 parent/sibling enumeration 或祖先 child listing；child contents/hash/streams/ADS；build/Cargo/AC1–AC7；Windows Sandbox 查询/安装/启用/启动；用户漫画、DB、Lock、Revision、凭据、模型读取。
