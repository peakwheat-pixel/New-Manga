## 2. 标定（仅 E-IMG-01 可精确标定）

方法：像素扫描（色块边界/长白行/长白列）+ 与安装版 CSS 已知值比对。

| 观测量（图内 px） | 换算（CSS px，÷1.5） | 与 CSS 已知值比对 | 结论 |
|---|---|---|---|
| 视口 | 2488×1395 → **1659×930** | 推断 DPR≈1.5 | 标定基准 |
| 顶栏渐变高 ≈100（阴影渐隐到 ~116） | 64–67 | `.app-header--bookshelf{height:64px}` | ✅ 一致 |
| 内容区左右边界 232 / 2260 | 154.7 / 1506.7，宽 **1352** | `max-width:1400;padding:24` → 内容 1352 | ✅ 精确一致（容器居中：左右外边距 (2488−2028)/2≈230≈232） |
| 筛选白卡纵向 246..429 | 164..286，高 **122** | `padding:16` + 搜索行 ~42 + `gap:16` + chip 行 ~24 | ✅ 合理 |
| 网格起始 y≈465 | 310 | 筛选卡底 286 + `margin-bottom:24` | ✅ 一致 |
| 书卡宽 258 / 间距 37.5（图内） | **172.6 / 25** | `repeat(auto-fill,minmax(160px,1fr));gap:24` + 容器 1352 → **7 列**，列宽 (1352−6×24)/7=172.57 | ✅ 精确一致（本图仅 5 本书，右侧 2 列空） |
| 封面高≈345 | 230 | `aspect-ratio:3/4` × 172.6 = 230.1 | ✅ 一致 |
| 书卡信息区 810..995 | 545..663，高 118 | `padding:12` + 标题 ~20 + 章节数 ~20 + 标签行 ~20 + gap | ✅ 合理 |

**结论**：`bookshelf-display.png` 与 E 盘安装版静态包**同构/同版本族**，因此「CSS 权威值 + 图内比例」互为校验。除 E-IMG-01 外，E-IMG-02/03 尺寸标定**未做**（同一分辨率族，仅用于结构观察）。

> 使用注意：实现时直接用 `tokens-saber-purple.json` 的 DIP 值，**不要**把图像像素（2488 宽）当 CSS 值。

## 3. E-IMG-01 `bookshelf-display.png`（书架）

### 3.1 可观察到的元素（自上而下）

1. **顶栏**：全宽紫→紫红渐变（左 `#667eea` 倾向、右 `#764ba2` 倾向；采样中线 `#6876df` → `#7354af`），64px 高；左 logo 方形圆角图 + 白色粗体站名；中部半透明胶囊「🌐局域网设备可通过该网址访问 http://192.168.1.103:5000/ 📋」；右侧依次「本项目完全开源免费，请勿上当受骗」白胶囊、「使用教程」、GitHub 圆形图标、主题圆按钮（橙色圆形，Saber 的 ☀️/主题位）。
2. **页标题行**：`📚 我的书架`（深色、粗、约 29px），右侧三个按钮：紫色渐变「+ 新建书籍」、白底「🏷️ 管理标签」、白底「快速翻译」。
3. **筛选白卡**（圆角、浅阴影、横贯内容宽）：上方搜索框（浅灰底、占位「搜索书籍名称或标签...」）+ 右端紫色搜索按钮；下方 `标签筛选:` + 4 个浅紫圆角 chip（`123 3`、`333 2`、`12312 2`、`222222 1`）。
4. **书卡网格**：5 张等宽卡，封面 3:4（各为漫画封面）、白色信息区：书名（粗、单行）、`{n} 章节`（灰色）、彩色标签 pill（紫/粉紫/绿）。
5. **页面底色**：浅灰 `#f5f5f8`（≈ token `#F4F7F9`），内容区居中留白。
6. **右下角**：一个浮起的小圆形控件（Saber 的悬浮入口），不在我们的核心布局范围内。

### 3.2 配色采样（用于校验令牌）

| 顶栏左/中/右 | `#6778e5` / `#6876df` / `#744da6`（渐变连续） | `nm-gradient-brand` `#667EEA→#764BA2` ✅ |

### 3.3 缺口 / 不可观察

- 任何 hover / focus / active / disabled / 加载态；

## 4. E-IMG-02 `interface.png`（工作台，参考）

### 4.1 可观察到的元素

- **最右侧**：细窄的竖向滚动条/色带。

## 5. E-IMG-03 `Editor.png`（编辑模式，参考）

### 5.1 可观察到的元素

- **深色顶栏**：左 `◀◀ 图 1 / 1 ▶▶ | ☰ | ◀ 气泡 1 / 9 ▶ | ▭ [ ] 🔗 ⛶ + 38% − 原始比例`（最后一个为缩放复位，界面写作 1 比 1）；右浅描边按钮「退出编辑」。
- **深色工具条**：`检测` `批量检测` `翻译` `添加` `删除` `修复` `修复笔刷` `还原笔刷`（暗底、描边胶囊，部分带黄/白图标）+ 白胶囊「快捷键」；右端荧光绿主按钮「应用并下一张 →」。
- **左半画布**：`原图(日文)` 面板（深色标题条 + 红色小方块 + `−` 折叠），日文原图 + 黄色气泡索引 1–9。
- **右半画布**：`翻译图(中文)` 同构，渲染中文文本，可见选中气泡（绿色描边/高亮）与编辑控点。
- **右侧检查器（浅色，约占 1/3）**：`JP 日语原文 (OCR结果)` + 复制图标 → 原文文本域；行内 `📋 复制` + 红色 `50音`；`CN 中文译文` + 复制图标 → 译文文本域；行内 `复制` + 绿色 `✓ 应用文本`；样式卡：`字体` 下拉（微软雅黑）/ `字号` 42 + `A+ A-`；工具行：对齐/行距/颜色/气泡填充方式（`LAMA修复(漫画)`）/描边；位置微调（旋转、间距、上下左右、`0.0`、重置）；折叠 `字号预设`；底部 `应用`（绿）/`应用全部`（蓝）/`重置`（灰）。
- **深色采样**：顶栏 `#131c34→#161728` 渐变族、工具条 `#0d1b2a` 附近、面板 `#1a1a2e` 族 → 与 CSS `.edit-toolbar-wrapper{background:linear-gradient(135deg,#16213E,#1A1A2E)}` 同族。

### 5.2 缺口

- 编辑工作区整体尺寸标定未做（不追像素）；
- 不覆盖笔刷/快捷键弹窗/字号预设展开态；
- 不能作为工作区默认态（浅色）证据（那是 E-IMG-02）。
