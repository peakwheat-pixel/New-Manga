## 2. 术语与不变量

- **DIP**：设备无关像素；所有手势阈值以 DIP 计，不用物理像素。
- **手势（pointer gesture）**：一次 `PointerPressed → Released` 之间的指针交互；本契约范围只含**主指针（左键/单指按下）**。
- **单击 / 拖动**：按 `SC-C10-02` 的阈值语义判定，二者**互斥**。
- **作用域层级**：`overlay`（模态浮层）> `object`（对象级）> `mode`（工作台模式）> `space`（一级页面）> `global`。
- **可编辑态**：`SC-C10-04` 的合取谓词成立时的状态；不成立即**只读**。
- **draft owner**：按 `(SessionId, RegionId)` 唯一确定的编辑归属（C-13 SC-D03）。

**不变量（I1–I5，任何实现都不得违反）**：

| ID | 不变量 |
|---|---|
| I1 | 一次手势只能落在「单击」或「拖动/缩放」之一；不得既产生单击语义又产生拖动语义 |
| I2 | **取消的手势不产生编辑**：工具切换、`Esc`、失焦、窗口切换、关闭不得提交半截区域修改 |
| I3 | **只读面不因手势写入**：原图侧、只读对照、非 owner 会话的任何拖动都不得产生 patch/revision |
| I4 | **Lock 与工具解耦**：进入任何编辑工具都不解除 `region_locked`/`translation_locked`/`inpaint_locked`（引用 C-13 SC-D09） |
| I5 | **保护不因编辑态变化**：可编辑态判定不得改变 C-13 的保护语义（本契约不新增保护规则） |

**I5 的判定方式**：I5 是**不作为型不变量**，不设运行时断言；由「任何改动 `SC-C10-04` 判定或沿用条款的变更，必须走 C-13 的 UNFREEZE 或独立复核清单」保证（复核项：E1–E5 与 C-13 SC-D09 的映射未被修改）。

## 3. SC-C10-01 手势优先级与仲裁

1. **命中优先级（最具体者优先）**：已选可编辑区域的**控制点** > 已选**可编辑区域内部** > 空白画布；同一手势只命中一个目标。
2. **缩放锁定**：左键按住 + 滚轮后，本次手势**进入缩放**直至松开；期间不转平移、不移动区域、不框选；松开**不触发单击**（概念 `:150`）。
3. **工具决定语义**：默认检查/选择工具下「空白拖动 = 平移」；平移工具下画布内任何拖动 = 平移、不移动文字区域；框选创建/框选多选/标记工具须**显式启用**后才有各自语义，不与平移混用（概念 `:148-149`）。
4. **只读侧限制**：原图侧与只读对照模式只允许平移与查看，不执行区域编辑（概念 `:148`）。
5. **取消语义**：切换工具、`Esc`、失焦、窗口切换、关闭 → 未决手势按**取消**处理，不得提交部分修改（概念 `:150`；方案 `:273`）。
6. **Lock 解耦**：进入编辑工具不解除任何 Lock（概念 `:151`）；只读面即使拖动也不得写入（I3、I4）。

**验证判据**：

| ID | 可执行判据 |
|---|---|
| A1 | 叠加命中场景（控制点 / 区域内部 / 空白）→ 断言只触发最具体目标，其余目标状态不变 |
| A2 | 左键+滚轮后移动指针再松开 → 断言：无平移位移、无区域位移、无框选产生、松开不触发翻页/选中变更 |
| A3 | 工具 × 场景矩阵（3 类工具 × 空白/区域内部/控制点/只读侧）→ 断言每格语义与 §3 第 1–6 条一致（§3 无表格） |
| A4 | 原图侧与只读对照拖动 → 断言 0 写入、0 新 revision、0 `RegionCandidate` |
| A5 | 拖动中 `Esc` / 切工具 → 断言区域几何与样式不变、无 patch、无 candidate |
| A6 | `region_locked=1` + 进入编辑工具 + 拖动 → 断言仍只读、0 写入（与 C-13 SC-D09 的验证同口径） |

## 4. SC-C10-02 移动阈值（**用户 2026-11-01 裁定：`T = 4 DIP`，仅鼠标**）

1. **阈值（已裁定）**：`T = 4 DIP`，**仅适用于鼠标主指针**。判定：按下点到当前点的**视口内直线距离** `< 4` → **单击**；`≥ 4`（含恰好 4）→ **拖动/手势**（互斥，I1）。
2. **跨阈后不回落**：一旦进入拖动（含恰好 4），即使指针回到起点附近，本次手势仍为拖动；松开不触发任何单击语义（翻页、选中/取消选中、按钮激活）。
3. **不随画布缩放改变**：`T` 在**视口/屏幕 DIP** 空间度量，与画布缩放倍率、图片显示比例无关；放大/缩小画布时 `4 DIP` 不变。
4. **DPI 无关**：Windows 显示缩放（100% / 125% / 150% / 200%）下 `T` 仍为 4 DIP；实现须以 DIP 而非物理像素比较（同一 4 DIP 在不同 DPI 下的物理像素数可以不同）。
5. **单一来源与登记形式**：唯一命名常量 `InteractionMetrics.ClickThresholdDips = 4`，阅读器画布、工作台画布、区域拖动共用同一值；该常量的值以 [C-10 冻结记录](FEA-CONTRACT-FROZEN-C10.md) 条目为准。**修改该值须走 `CONTRACT-UNFREEZE-C10`**——本值为**首版工程基线**，不是「待定值」。
6. **缺失/非法即失败**：常量缺失、为 `null`、或与冻结记录不符（且无 UNFREEZE 记录）→ 启动/测试必须失败，不得静默使用其它默认值。
7. **范围边界**：触摸 / 触控笔不适用本阈值（见 §9 第 3 项）；若后续支持须另立契约或走 UNFREEZE，不得默认复用鼠标阈值。
8. **验证归属**：本条只冻结语义、数值与判据；**真实鼠标 / DPI / 画布缩放的交互验证由实现 Task 执行**，本契约不将其标记为已通过。

| T3 | 三处画布断言使用同一常量，且断言该常量值 == 4（值变更必须附 UNFREEZE 记录，否则测试失败） |

## 5. SC-C10-03 快捷键作用域

1. **层级与解析**：`overlay` > `object` > `mode` > `space` > `global`；命中唯一。代码事实：`ShellCommandDefinition.AppliesTo` 以 `Space=null` 表全局、`Mode` 仅在 `Space=Studio` 时参与（`KeyMap.cs:43-44`）。**注意**：`overlay` 层为**本契约新增要求**——现有代码只有 Space/Mode 两层、`TryMatch` 按注册顺序首命中（`KeyMap.cs:132-150`）；实现须新增该层判定，不得以「现状已有」冒充已实现。
2. **单一注册表**：每个 shell 命令在 `Shell/V2/ShellCommands.cs` 声明一次；**不得**在 View/ViewModel 内另行注册全局快捷键（V11R 契约 `:277`）。
3. **冲突即失败**：同一手势 + **重叠作用域** → `FindConflicts` 报告冲突，`EnsureValid` 启动断言失败（`KeyMap.cs:99-130`、`:87-97`）；不接受「后者覆盖」。
4. **`Esc` 语义**：浮层/面板内 `Esc` **最高优先**关闭该层，不冒泡执行底层命令；逐级退出（DESIGN_SYSTEM `:198`、`:202`）。
5. **文本输入优先**：输入框/IME 获得焦点时，**字母类快捷键全部让位**（DESIGN_SYSTEM `:203`；概念 `:144`、`:246`）。
6. **失焦窗口**：不执行全局编辑快捷键（方案 `:406`）。
7. **用户自定义边界**：允许按「全局/书架/阅读器/工作台」分类搜索、修改、单项/全部重置；保存前校验冲突，冲突则拒绝并提示，**不自动覆盖已有绑定**（概念 `:246`）；分类只是 UI 组织，不改变第 1 条的层级判定。
8. **输入法/组合键**：`CapsLock`/`NumLock` 等锁定位不得造成误匹配（代码事实：`ShellKeyGesture.Matches` 只比较 Control/Shift/Alt/Meta）。

## 6. SC-C10-04 可编辑态判定

`editable(page, region, session)` 为**合取**，五项全真才可编辑：

| ID | 条件 | 权威来源 |
|---|---|---|
| E1 | 页面可读/可见：`V(p,t)` 成立 | **C-05** 可见性谓词（引用，不重述） |
| E2 | 侧别/归属允许：**对照模式「允许编辑」时仅结果侧可编辑、原图侧永不可编辑**；「只查看」与非 owner 会话 → 不可编辑 | 概念 `:142`、`:148`；C-13 SC-D03 |
| E3 | 已取得未过期的 **edit token**（幂等键） | **C-13 SC-D04**（引用，不重述） |
| E4 | 目标域未被锁阻止（三锁 × 三域） | **C-13 SC-D09**（引用，不重述） |
| E5 | 无未决手势，且 flush 已完成（含 IME/未失焦文本） | **C-13 SC-D02**；方案 `:377` |

**阻断规则**：

- 判定不成立 → **保持只读**并给出原因（不得静默降级为「看起来能编辑」）。
- 切换页面/切换工作面/退出/关闭窗口/Run 提交前 → 必须满足 E5 的 flush 语义（引用 C-13 SC-D02 与方案 `:273`），否则**保留当前 UI 并说明原因**。
- 未决手势或 IME 未完成时不得进入可编辑态，也不得把半截手势变成人工修改（方案 `:273`）。
- Lock 不因进入编辑工具自动解除（I4，与 `SC-C10-01` 第 6 条一致）。

**验证判据**：

| ID | 可执行判据 |
|---|---|
| E1′ | `V(p,t)` 不成立的页 → 断言进入编辑被拒 + 明确原因 |
