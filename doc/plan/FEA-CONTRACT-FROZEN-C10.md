## 3. 冻结的实质内容（摘录，权威以契约为准）

- **移动阈值**：`T = 4 DIP`，仅鼠标主指针；视口内直线距离 `<4` 单击 / `≥4`（含恰好 4）拖动；跨阈后保持拖动；视口/屏幕 DIP 度量、**不随画布缩放**；**DPI 无关**；唯一常量 `InteractionMetrics.ClickThresholdDips = 4`；缺失/非法即失败；触摸/笔不适用。
- **手势优先级**：控制点 > 区域内部 > 空白；左键+滚轮后本次手势进入缩放；工具决定语义；只读侧仅查看；取消不落半截修改；Lock 与工具解耦。
- **快捷键作用域**：`overlay > object > mode > space > global`；单一注册表 `Shell/V2/ShellCommands.cs`；冲突即启动失败；`Esc` 逐级退出；文本/IME 让位；失焦不执行；用户改键需冲突校验（`K1–K8`）。
- **可编辑态**：`E1–E5` 合取（C-05 可见性 / 侧别与 owner / edit token / 锁域 / flush）；对照模式**仅结果侧**可编辑；进入失败须显式原因；`E1′–E6′`。
- **draft owner**：**只引用** C-13 SC-D03（零复述），仅补 UI 不变量 `U1–U4` 与判据 `U1′–U4′`。
- **需求追溯**：F-10/F-18/F-39 矩阵；验证等级 **L1–L4** 按用户确认定义；**不得把未执行的 L2–L4 标为已通过**。
- **范围边界**：§9 列明在范围（纯滚轮/缩放）与不在范围（触摸/笔、双击、右键、拖放、F-39 等）。
