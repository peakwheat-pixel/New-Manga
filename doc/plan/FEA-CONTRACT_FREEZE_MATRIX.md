## 4. 每步的验证动作（冻结时执行）

1. 草案 `approved` 且无 P0/P1 未解决；
2. 冻结条件逐条勾选；
3. 冻结后：在 `doc/plan/FEA-CONTRACT-FROZEN-<ID>.md` 记录冻结时间 + 字节 pin + 条件清单；
4. `check.ps1` PASS；
5. 冻结后不得再改草案正文（UNFREEZE 载体见 FREEZE_PACKAGE）。
