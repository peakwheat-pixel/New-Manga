## 语义正确性（复核结论）

- **过滤条件 `page.deleted_at == deleted_at` 正确**：本 batch 刚软删的行其 `deleted_at` 恰为本 batch 时间戳（同一字符串写入）；更早 batch 的页持有更早时间戳、不存在/活态的页不匹配或缺失——均不入 batch。该判据成立的前提是**时间戳全局唯一于 batch**，由防撞循环保证（`while deleted_at in existing: stamp += 1µs`，循环条件持续复查，existing 为有限集必然终止）。
- 防撞同时封住了同毫秒合并缺陷：回查过滤单独存在时，同毫秒两 batch 共享同一字符串，早 batch 的页会通过相等性检查漏入晚 batch（见下复现）；微秒精度＋防撞使相等 ⟺ 本 batch 所删。
- 残余理论边界（不构成 finding）：store 侧非 batch 途径的 `deleted_at`（如 TASK-008 单页 `soft_delete_page`，毫秒格式 `isoformat(timespec="milliseconds")`）与微秒格式字符串不可能相等，不会误记；`page_ids` 类型由全量 tuple 变为过滤后 tuple，manifest 形状不变。
