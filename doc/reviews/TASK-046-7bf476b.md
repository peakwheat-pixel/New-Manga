## 重点裁定：AC ② 的墙钟归因分解 —— **认可（uphold）**，并给出比作者更强的测量口径

作者的呈现有残余 4.61–5.22s「非字面噪声级」，请 Reviewer 按归因分解裁定。我不接受用墙钟裁这件事，
因此把口径换成**工作量计数 + 直接测得的下界**：`ac2_work_accounting_probe.py` 统计
`StreamingPngReader._unfilter` 调用数（真正重建了多少行）与 `rewind` 次数，并额外测一条
**理论下界** = 一次 `read_band(0, 8000)` 顺序扫掠 + 两次 4000 行 `_encode_png`（即「产出瓦片 0、1 所必须做的最少功」）。
同一脚本、同一 shell、同一 venv 分别跑修前树（`git archive ec5b4d1` 解到 TEMP）与修后树，各 ×2：

| 测量 | 修前树（默认 64） | 修后树（默认 0） |
|---|---|---|
| 400×20000 全页扫掠（25 块） | 0.985–1.000s，rewinds **24**，重建 **260000** 行 / 保留 20000 行 = **13.0× 冗余功** | 0.172s，rewinds **0**，重建 **20000** 行 / 保留 20000 行 = **1.00×（零冗余功）** |
| 1600×8000 两块同调用 | 13.094s，rewinds **1**，重建 12000 / 保留 8000 = 1.50× | 8.750–8.969s，rewinds **0**，重建 **8000 / 保留 8000 = 1.00×** |
| 实测 / 下界（两块） | **1.510–1.524** | **0.991–1.036** |
| 校准：实测 / 下界（单块 tile 0） | 0.947–1.004 | 0.927–0.956 |
| 第二块「不可避免工作量」＝(D8000−D4000)+E | 4.187s | 4.344s |
| 第二块实测额外耗时 | 8.766–8.922s | **4.609–4.844s** |
| 每行重建成本（4000 行程 vs 8000 行程，四次测量） | 1.086/1.059、1.059/1.064 ms | 1.062/1.066、1.102/1.088 ms ⇒ 上/下半程每行成本持平（下半程＝(D8000−D4000)/4000 ≈ 1.07 ms/行） |

**裁定理由**：修后两块调用的重建行数**恰好等于**其保有的行数（8000/8000，0 rewind），墙钟落在自测下界的
±4% 内；而同一脚本内单块的实测/下界比同样偏低 4–7%（下界把两次 `read_band` 拆成两次测量、并各带一次
`_encode_png`，本身略偏保守）。也就是说：**残余不可能来自重扫**——重扫的唯一途径是 `rewind()`（reader 的
唯一回退机制），而计数为 0。修前该调用的 12000 行重建 / 1 次 rewind / 1.51× 下界，才是重扫的样子。
作者的分解（修前 9.0s ≈ 第二块自身 ≈4.2–4.7s + 重扫前缀 ≈4.3s；修后重扫项归零）与实测逐项吻合，
**AC② 判达成**。

**同时给出口径反例（不是实现缺陷，是 AC 措辞缺陷）**：AC②「单块→两块的**额外**耗时应落在噪声级」在物理上
不可达。PNG 逐行反过滤要求产出瓦片 1 的 4000 行必须重建那 4000 行，额外的**下界就是单块解码本身**
（实测 4.19–4.41s），不是 0。建议 Codex 集成登记时改成可测形式：
「额外耗时 ≈ **1× 单块解码**（比值口径），而非修前的 **≈2×**」——合并作者 ×3 与 Reviewer ×2 共五轮：
修后比值 **1.10–1.21**、修前 **2.03–2.16**。本判据已达成。

**一条应入档的推论**：AC② 表把「5.4×」当作墙钟收益，但那是在 **filter-0 合成页**上测的——该类行重扫极便宜
（400×20000 页修前 260000 行只用 0.94–1.00s ⇒ ≈3.6 µs/行）。真实编码页以 Paeth 为主（Reviewer 实测
1600×8000 页直方图 `{None:32, Sub:63, Paeth:7905}` ≈ 1.06 ms/行；换算**每像素 ≈75×**，其中 4× 来自页宽差异）。
因此同样 13× 的冗余功在生产页上不会像 400×20000 那样藏在便宜重扫里。这不是问题，而是本切片的生产收益
**被 5.4× 低估**；建议 AC ⑩ 最终口径登记时一并写明，避免后来者按 5.4× 预期真实页收益。
