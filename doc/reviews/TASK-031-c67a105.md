## Architecture 轴

- **分层正确**：新增文件位于 `src/infrastructure/`，只依赖 `application.importing.images.ports`（Protocol/DTO）与同层 `infrastructure.filesystem.managed_storage`，未反向被 application 依赖，未引入 Qt 到 application/ports。PySide6 的延迟导入进一步保证模块可被无 Qt 环境安全 import。
- **契约未被扩张**：`ManagedCopyStore.store_original(chapter_id, source_filename, data, source_hash)` 保持原签名；book 层级由装配侧 resolver 补齐，符合 Task 文件"避免伪造或硬编码 book 层级"的要求，也未触碰 `src/ports`。
- **复用而非重写**：temp 写入、SHA-256 校验、不可覆盖发布、temp 清理全部复用 TASK-006 的 `ManagedFileStorage`，未复制一套文件安全逻辑。
- **失败边界**：`book_id_for_chapter` 在 `write_temp` **之前**调用，resolver 抛错时无 temp 泄漏；`finally` 仅在 `publish` 未成功时清理 temp（成功后置 `None`），对 `ImmutablePathViolation` 等发布失败同样成立。
- 次要项见 R-002（依赖注解用了具体类而非 Protocol）。
