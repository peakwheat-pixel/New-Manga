# 扩展能力与验收覆盖边界设计（TASK-024，仅设计）

状态：**草案，待用户批准**。本文件是 [STATUS](../STATUS.md) 授权窗口内 TASK-024 的
唯一设计交付；它只定义边界与条件，不实现任何扩展，也不默认扩建或删除任何 D01
已列能力（G17：来源存在、契约与 AC 不完整）。产品取舍经用户批准后才对
TASK-023/025/019/022 释放；未批准前相关 Task 不得据此开工。

来源：D01 §2/§5、D02 §6.2/§11/§12、D04 §8、D05 §43/§48/§52、D07 §72/§84、
G17 与验收追踪 `ACG-EXT-*` 组。冲突处理遵循 [00_INDEX](../00_INDEX.md)：
本文档与权威文档冲突时，以权威文档为准并修订本文件，不得倒置。

## 0. 总边界（适用于全部扩展条目）

1. 一级页面固定为书架/工作台/阅读器/设置（D01 §2、D02 §3）；任何扩展入口只能
   落在设置页既有分区、导入窗口（D05 §52）或工作台/书架既有面板内，
   **不得新增一级页面或常驻浮窗**。
2. 所有外部网络访问（网页导入、插件下载、Sakura 探测、模型下载）统一经过
   Network / Proxy Manager（D02 §6.2），遵循 Provider 级覆盖与连接测试；
   不存在绕过代理策略的直连扩展通道。
3. 任何扩展不得破坏 Domain 不变量、不得绕过 Repository 直接写库、不得写入
   用户源文件（D02 §12、D07 §72；Managed Copy 链路不变）。
4. 可选依赖（D07 §83 口径）：扩展缺失时核心翻译链路必须完整可用；扩展崩溃
   隔离为"当前扩展失败、应用可运行"（D07 §72）。
5. 每条目释放前必须完成：本文件的边界行被用户批准 → 对应实现 Task 的
   `allowed_paths` 由 Codex 按本文件收紧 → AC 从 ACG 草案升级为编号 AC 并回写
   [08_ACCEPTANCE_CRITERIA](../08_ACCEPTANCE_CRITERIA.md)。

|---|---|

### 1.4 AI 生成插件 Agent（ACG-EXT-PLUGIN 的一部分，"如保留"裁决）

D02 §12 原文："Plugin Agent **如保留**，只负责生成/管理插件，不进入漫画翻译主链路。"

**保留条件（同时满足才保留）**：

1. §1.3 的本地插件格式与权限模型已实现并验收（Agent 生成物必须落在该格式内）；
2. Agent 产物一律**不自动加载**：生成/修改插件后必须经用户在设置页逐个审阅、
   确认权限声明并手动启用（fail-closed，与 D07 §88 远程数据提示同口径）；
3. Agent 的 LLM 调用走既有 Provider/网络代理栈，不新增直连通道，不进入
   Pipeline DAG 的任何 Step（主链路可观测性不被 Agent 污染）；
4. 有独立的启停开关与审计日志（生成 prompt 摘要、产物 diff、启用记录）。

**不保留的判据（任一触发即裁剪）**：上述任一条件无法在实现 Task 内验收；
或生成插件的历史故障率使审阅成本高于手写（实现后按 D07 §72 隔离指标评估）。

| 维度 | 设计内容 |
|---|---|
| 支持矩阵（草案） | 入口=设置页 Plugin/Hooks 分区内"插件助手"按钮（弹窗，非一级页面）；输入=自然语言描述 + 目标 Hook；输出=manifest+hook 脚本草稿 + 差异说明 |
| AC 草案 | AC-EXT-AGENT-001（P3）：Agent 生成的插件不经用户确认不会出现在已加载清单；AC-EXT-AGENT-002（P3）：Agent 全部网络调用可在代理日志中审计 |
| 释放条件 | §1.3 释放且用户明确批准保留；TASK-025 将 Agent 作为第二批次单独切片 |

### 1.6 Sakura 本地服务监控（ACG-EXT-SAKURA）

| 维度 | 设计内容 |
|---|---|

| 支持矩阵（草案） | 范围裁定为**健康探测 + 就绪状态**（对齐 ACG-EXT-SAKURA 原文"模型/设备就绪状态"）：Provider Profile 类型为 Sakura-本地时，设置页连接测试即按需探测（复用 TASK-009 连接测试），可选后台轮询（默认关，开启后 60s 间隔、连续 2 次失败标记不可用）；工作台 Provider 选择器显示 就绪/不可用/未知 三态；**不做**显存/负载等未定义指标 |
| 授权/失败边界 | 探测地址取自 Profile（本地默认直连，D02 §6.2.2）；探测失败永不阻断翻译任务发起（任务失败由真实翻译请求自行报错）；轮询请求走统一网络栈并可被全局暂停停止 |
| AC 草案 | AC-EXT-SAKURA-001（P2）：Sakura Profile 的连接测试给出就绪/不可用与原因；AC-EXT-SAKURA-002（P3）：可选轮询开启后状态变化在工作台可见且连续失败自动标记；AC-EXT-SAKURA-003（P3）：探测关闭/失败不阻塞主流程 |
| 释放条件 | 用户批准"健康探测级"范围（不做深度指标）；TASK-019 白名单=`src/application/settings/monitoring/**` 或并入 Provider 选择器切片；实测需本地 Sakura 实例，环境不具备时按 D08 口径记录 BLOCKED/NOT_RUN |
