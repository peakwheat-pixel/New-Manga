## 1. App Shell 布局（D05 §3.1）

```text
┌────────┬────────────────────────────────────────────┐
│ Rail   │  当前一级页面（四页常驻，仅切 visible）      │
│ 64px   │                                            │
│ 书架 ● │   page-bookshelf / workbench / reader /     │
│ 工作台 │   settings，anchors.fill 填满剩余区域       │
│ 阅读器 │                                            │
│ 设置   │                                            │
└────────┴────────────────────────────────────────────┘
```

- 一级导航 Rail：固定左侧 64px，四个入口纵向排列（间距 4、外边距 6），顺序固定为
  书架 → 工作台 → 阅读器 → 设置（D05 §2.1）。按钮 checkable，选中态由
  `navigationViewModel.currentPage` 驱动，启动默认书架（AC-NAV-001）。
- 工作台入口右上角挂 NavBadge（10px 圆角胶囊，仅 running 时显示）——TASK-011 管线接入前始终隐藏。
- 切换一级页面不销毁任何页面（AC-NAV-003）；运行中管线不因离开工作台停止（D05 §3.1）。

## 2. 书架布局（D05 §7）

```text
┌──────────────────────────────────────┬──────────────────┐
│ BookshelfToolbar  48px  #f7f7f5      │ BookDetailPanel  │
│ [新建作品][导入][搜索][收藏][归档]    │ 320px  #ffffff   │
│ [排序：最近/标题][网格/列表]          │ 资料/标签/进度   │
├──────────────────────────────────────┤ 收藏/归档        │
│ BookGrid（GridView cell 168×210      │ 新建章节输入行   │
│  或 ListView 行高 64，外边距 8）      │ ChapterList 220px│
│                                      │ [进入翻译][进入阅读]│
└──────────────────────────────────────┴──────────────────┘
```

- BookCard：白底圆角 6，封面占位区（#dfe3ee，高约 45%）+ 标题（DemiBold）+ 原名（灰色小字，
  可选）+ 归档徽标（#f0b429）+ 进度占位；右上角收藏星（#e2a400，★/☆）。
- Grid/List 双视图常驻，`viewMode` 决定可见性；切换不销毁模型。
- 阅读进度：TASK-007 未交付字段，卡片与详情一律显示“—”，不虚构数值。
- ChapterList 行：编号（#4f6bed 加粗）+ 标题 + 类型/方向/页数摘要；行操作
  进入翻译 / 进入阅读 / 删除（可用），编辑 / 页面管理 / 翻译设置（disabled 占位，TASK-013/022）。
- BookDetailPanel 固定右侧 320px；未选中作品时显示“未选择作品”空状态。

## 3. 设置页（D05 §43.1）

左侧固定分类列表（宽 180，12 项，无子路由）+ 右侧占位内容面板。分类顺序固定：
Provider、网络 / 代理、OCR、翻译、图片修复、排版样式、模型 / GPU、任务 / 并发、
缓存 / Revision、回收站、备份 / 恢复、Plugin / Hooks。设置项本体由后续切片接入。

## 5. 字体与字号

- 全部使用 Qt 默认系统字体（不指定 family）；中文依赖系统字体回退。
- EmptyState 标题 18px DemiBold `#1f2328`；描述 12px `#6b7280`。
- 卡片标题默认加粗；摘要 / 徽标 10–11px；NavBadge 10px 白字。

## 6. 空状态与禁用态（D05 §62）

| 位置 | 文案 | 动作 |
|---|---|---|
| 书架空库 | 还没有作品 | 新建作品（可用）、导入作品（disabled 占位） |
| BookDetailPanel 未选中 | 未选择作品（描述：点击左侧作品查看详情） | — |
| ChapterList 无章节 | 暂无章节 | — |
| 工作台（本切片） | 尚未选择作品 / 章节 | 选择作品和章节（disabled，TASK-013） |
| 阅读器（本切片） | 尚未选择阅读章节 | 选择章节（disabled，TASK-015） |

- 禁用态：按钮 `enabled: false`（新建章节按钮随标题输入动态启用；进入翻译/进入阅读随
  ChapterList 选中启用）。
- 键盘焦点：Rail 首个按钮启动即获得 focus；Tab / 方向键走 Qt Controls 默认导航。
  键盘操作的全量验证归 TASK-022（本切片 NOT_RUN）。
