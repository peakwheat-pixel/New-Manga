## Coordinator 裁决与 Owner 合规确认（2026-10-16）

- **裁决 A：允许 `m2res` 作为专用例外。** 依据 [M2-C1 §10](../contracts/M2-C1_TYPED_IPC_CONTRACT.md) §10 / L783：大媒体展示经由 `resolve_page_resource` 与 `m2res` 自定义协议。该短期随机映射 URL / opaque handle 只用于 Viewer 页图读取，不是授权写操作的凭据。
- **精确边界**：仅允许 `resolve_page_resource` / `issue_resource_url` 产出的短期随机 `m2res` 页图 URL / opaque handle 进入 Viewer 媒体显示链路。请求、返回、事件 payload、错误 message 四处均禁止绝对/相对/UNC 文件系统路径、`ExportTargetRef` / `ImportSourceRef` / `ResourceRef` grant 材料、`host_session_credential` / `core_session_id` 等会话凭据及任何可解码出路径的字段。
- **合规确认**：四处核验见 [`boundary-evidence.md`](../../verification/P14/boundary-evidence.md)，未发现上述禁用内容。`m2res` 句柄只在内存中用于分块读取，最终渲染使用可撤销 `blob:` 对象 URL；不持久化、不写日志或事件 payload、不离开 Viewer 媒体显示路径，也不授权任何写操作。
- 导出面板由本页 `ExportDialog` 提供。选择目标通过 host 系统对话框完成，前端请求/快照/历史只保留导出 ID、业务范围、状态与格式/摘要；无输出路径或 `ExportTargetRef` 投影进 WebView。
