## Acceptance Criteria

- [ ] **D1-AC1 — 六棵目录完整盘点**：逐一审计 `src/domain`、`src/application`、`src/ports`、`src/infrastructure`、`src/bootstrap`、`src/ui`。记录各目录的 PySide6/Qt 直接、延迟及间接依赖，含 QObject、QImage、QPdfWriter，以及 QML 与 Python ViewModel 的接口。无命中也要给出实际命令与结果，不能省略目录。
- [ ] **D1-AC2 — 重点路径与权威边界**：追踪 Qt compositor、Qt layout、font handling、Webtoon tile decoding、image/document importing、bootstrap engine coupling、SQLite connection/writer/transaction 路径；对每项给出源文件/行、调用链、运行入口与状态权威。区分 UI 投影与持久化写入，核对 Python Core 单一持久化写者意图。

- [ ] **D1-AC4 — 可审查矩阵**：研究报告对每个有意义的耦合点逐项标 `KEEP`、`DECOUPLE`、`REPLACE`、`LEGACY` 或 `UNVERIFIED`，说明分类理由、对 headless 的影响、证据、风险、可复用条件和后续候选切片。`REPLACE` 仅表示需后续决策的候选，不授权重写。仅有 grep 命中不能构成分类证据。
- [ ] **D1-AC5 — 只读范围与交接**：源码、测试、打包、依赖、Schema、历史 Task/Handoff/Review/Verification 零修改；只新增/更新下列授权研究路径。固定 Delivery 与 Handoff，记录命令、shell/Python 路径、HEAD、原始输出、exit code、NOT_RUN/UNVERIFIED 项；`git diff --check <base> <delivery>` exit 0，由 Codex 对固定 base/head 做非作者 Review 后才能集成。无 React/Tauri/IPC 初始化。
