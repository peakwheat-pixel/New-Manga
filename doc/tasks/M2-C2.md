# M2-C2 — Typed IPC Contract Revision: Resource Channel Thresholds and Security Conclusions

## 来源与目标

来源：① [M2-S1 §7 产品阈值裁决](../../verification/M2-S1/product-thresholds-ruling-67c3d56.md)（2026-09-26，用户授权代行裁决 T1–T7）；② [M2-S2 验证报告](../research/M2-S2_SECURITY_VERIFICATION_SPIKE.md)（S1-B11 open-then-verify-from-handle 参考语义与 S1-B12 映射 ID 保密原型，24/24 场景，Review `approved`）；③ [M2-C1 Typed IPC Contract](../contracts/M2-C1_TYPED_IPC_CONTRACT.md) §10 现行 DEFERRED 条款（「This contract does not pick file URI/token…」「exact value object and expiry semantics are **DEFERRED** to that Spike」）——该 Spike（M2-S1/M2-S2）现已完成。

**目标**：把已裁决的阈值与已验证的安全设计结论落入 Contract 修订版（版本 `1.0` → `1.1`），解除「裁决悬在治理文档、契约未更新」的漂移，为后续大媒体 runtime Task 提供稳定需求基线。本 Task 只修订契约文档；不实现任何 runtime、不预选序列化库或 Tauri command 形态、不发布大媒体命令。

**修订聚焦**（Owner 按此执行，不自行扩大）：

1. **T1–T7 阈值落约**：在 §10 范围内新增资源通道阈值条款（单资源 256 MiB 上限与类型化拒绝；≥32 活跃引用/≥16 订阅者与类型化限流；首帧预算热 200 ms/冷 1 s 目标且冷缓存标注 S1-B6 未测；禁整份 Base64/JSON 物化与有界缓冲；分层信任与路径暴露规则；引用绑定 resource_id+revision 指纹、TTL=300 s 滑动续期、revision 变化立即撤销、已打开句柄不强制中断；模型权重独立通道）。每条标注来源（ruling T#）与证据等级标签，不得表述为已实现。
2. **安全语义落约**：引用解析必须 open-then-verify-from-handle（单次打开、句柄身份+大小+包含性校验、仅经句柄读取、digest 与读后复核——S1-B11 设计要求）；WebView 层引用保密采用 Core 侧不透明映射 ID（T5.4/S1-B12），Core↔host 可信层可解析派生缓存相对路径，用户源文件绝对路径不得下发任何层；从 M2-S2 实测提取类型化错误码最小集；明确「S1-B11 产品级保证仍 `UNVERIFIED`（S1-B3 DACL、S1-B8 打包复跑未做）——落约的是设计要求，不是验证结论」。
3. **§11 DEFERRED 表更新**：Large-media transport 行从 `DEFERRED` 更新为部分解除（thresholds/security semantics ruled at M2-C2；runtime form 仍 deferred to a future runtime Task）。
4. **版本与修订记录**：文档头版本 `1.1`；新增修订记录段（列出 §10/§11 变更清单与来源链接）。
