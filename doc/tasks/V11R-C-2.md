# V11R-C-2：Theme Studio 独立页面

## 目标
按 `doc/design/theming/THEME_STUDIO_SPEC.md`（冻结）实现独立覆盖式 Theme Studio 表面（`ShellSurface.ThemeStudio`），7 分区：主题库 / 预览 / 我的主题 / 主题编辑 / 外观 / 导入导出 / 恢复默认。数据与行为经 `IThemeService`/`IThemeRegistry`/`IThemePreviewEngine`/`IThemeValidator`（契约 §4）。

## Acceptance Criteria
- [ ] AC1 7 分区全部可用；左栏导航 + 右栏摘要（当前主题/外观/密度/布局 + 取消/应用）；入口：TopBand「主题」、`Ctrl+,`、Console「外观」。
- [ ] AC2 主题库：搜索/分类/筛选/收藏；卡片含**真实控件渲染**的迷你三视图预览（书架/工作台/阅读器），不是图片。
- [ ] AC3 预览：三视图真实控件 + 明暗/高对比/密度/缩放切换；「示例内容」明确标注，不读用户真实数据。
- [ ] AC4 我的主题：已安装/收藏/自定义；导入/导出/复制/删除；内置不可删。
- [ ] AC5 编辑：配色（语义色组 + 实时对比度校验）/字体/圆角/背景材质/阴影/动效 六组；另存为。
- [ ] AC6 外观：浅/深/系统 + 高对比 + 减少动效 + 跟随强调色；立即生效。
- [ ] AC7 导入导出：逐条校验结果（错误/警告/路径/建议）；错误阻止导入；round-trip 等价。
- [ ] AC8 恢复默认：二次确认；不删除用户主题文件；重启保持。
- [ ] AC9 实时预览：改动即时可见；**取消完整回滚**；预览期间不重建主界面、画布像素与未保存编辑不变（像素哈希 + 状态断言）。
- [ ] AC10 非法主题包 → issue + 回退默认，不崩溃；旧主题 ID 迁移到默认（9+2 用例）。
- [ ] AC11 键盘全可达、焦点可见、`Esc` 分级（预览→表面→空间）；无颜色单编码。
- [ ] AC12 证据：7 分区截图（暗/浅/高对比）、导入失败截图、像素哈希、测试日志。

## 禁止范围
旧 Views/Services、DS/ThemeEngine 内部、Python、`MainWindow.axaml`（INT-1 才切换）、git push；不得自建第二套令牌/样式。
