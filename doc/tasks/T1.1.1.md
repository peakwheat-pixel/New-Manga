  `DetectionProvider`；不生成业务 Region ID。

  `RegionCandidate` 包含稳定的 reading order、confidence 和 provider label。

  覆盖水平/竖排文本和边界裁剪。

  `region_creator` → `RegionEditingService.create_region` 路径，不新增 Region 写入路径。

- [ ] docTR 依赖、torch CPU/GPU 方案、模型架构和权重 SHA-256 固定并记录。
- [ ] §7.2 的 22 项 harness 检查全部转为 `tests/**` 自动化测试；skip 必须逐条记录，
  不得以 synthetic-only 结果代替真实测试。
- [ ] 至少一次用户指定真实漫画页面质量验证；真实漫画质量未验证前不得标记 Task done。
- [ ] 记录权重 license、训练数据/数据集条款和分发条件的 compliance re-check。
- [ ] 明确 CPU/GPU packaging choice 和 torch pin，并在目标 Windows/Python 3.12 环境复核。
- [ ] 无 Region 页面通过真实生产 bootstrap → detect → SQLite，生成 machine Region 和
  首个 `region_revisions`；源文件保持 byte-exact。
- [ ] 完成非作者 Review、focused tests、full suite、compileall、bootstrap smoke 和
  `git diff --check` 后，才允许改为 `done`。
