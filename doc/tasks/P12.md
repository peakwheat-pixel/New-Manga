- **来源（DAG）**：[REBASELINE_PLAN](../REBASELINE_PLAN.md) 的 P12 行「书架导入」，
  其依赖 `P09 / UI / C1 / FU2` **全部满足**：P09-FU2 已接通导入 wire、P12-C1 已冻结契约、
  HOST-ISSUER-1 已交付 host 侧原生选择器命令、[UI-DESIGN-1](UI-DESIGN-1.md) 已冻结四页设计基线
  （Review `3f312c5dc` **approved**，I1 收敛）。
- **设计权威（唯一 UI 依据）**：[AD-001 四页 UI/UX 设计基线](../design/AD001_FOUR_PAGE_UI_BASELINE.md)
  （I1 后版本）。实现者**不需要再做设计决策**；设计基线中 §7 的 **24 条真缺口**
  （G1–G5、G7–G18、G20–G26）对应交互一律按 **disabled 态** 呈现。
- **目标**：把现有 M2 探针壳（`apps/desktop/frontend/src/App.tsx` 现为 deny matrix + AC1 driver）

  沿项目既有 option-B 先例：**只有生产模式挂载新四页应用**；probe/AC1 模式继续渲染原有探针壳。
