# P12：书架导入 UI 实现（四页 Shell + 书架页）

## 来源与目标

- **来源（DAG）**：[REBASELINE_PLAN](../REBASELINE_PLAN.md) 的 P12 行「书架导入」，
  其依赖 `P09 / UI / C1 / FU2` **全部满足**：P09-FU2 已接通导入 wire、P12-C1 已冻结契约、
  HOST-ISSUER-1 已交付 host 侧原生选择器命令、[UI-DESIGN-1](UI-DESIGN-1.md) 已冻结四页设计基线
  （Review `3f312c5dc` **approved**，I1 收敛）。
- **设计权威（唯一 UI 依据）**：[AD-001 四页 UI/UX 设计基线](../design/AD001_FOUR_PAGE_UI_BASELINE.md)
  （I1 后版本）。实现者**不需要再做设计决策**；设计基线中 §7 的 **24 条真缺口**
  （G1–G5、G7–G18、G20–G26）对应交互一律按 **disabled 态** 呈现。
- **目标**：把现有 M2 探针壳（`apps/desktop/frontend/src/App.tsx` 现为 deny matrix + AC1 driver）
  升级为 AD-001 的**生产四页应用**，并交付**书架页**（含导入）的完整可运行实现。
- **不删旧能力**：probe / AC1 模式的冻结形状必须**逐字保留**（既有 e2e runner 依赖它）——
  沿项目既有 option-B 先例：**只有生产模式挂载新四页应用**；probe/AC1 模式继续渲染原有探针壳。

## Acceptance Criteria

- [ ] **AC1 四页 Shell**：实现 §1 冻结的导航 Shell——左侧 64px Rail、固定顺序（书架→工作台→阅读器→设置）、
      启动默认书架、`Ctrl+1..4` 切换、**切换不销毁页面组件**（keep-alive）、最小窗口 1024×680；
      工作台入口 NavBadge 在 **G15 未解前隐藏**（不得虚构运行状态）。
- [ ] **AC2 书架页数据面**：按 §6 绑定表实现 W1（`ListBooks`，`page_count=null` 渲染「—」）、
      W2/W3（`list_chapters` / `list_chapter_pages`）、W28（`ErrorEnvelope` 语义分支，**不按 message 文本分支**）。
- [ ] **AC3 导入 UI（核心）**：按 §6 W30/W31（**既有实现**，HOST-ISSUER-1）+ W4 实现导入流程：
      `library_import_file` / `library_import_folder` 原生选择器 → `ImportPages` → 逐源/逐页 `ImportReport`
      （imported / skipped_duplicate / rejected / pending）；**仅显示 basename，不显示路径**；
      取消返回 `cancelled` 时 UI 正确回到非 busy 态；重复策略默认 `skip`（P09）。
- [ ] **AC4 状态矩阵**：四页 Shell 与书架页按 §2.4 实现 **loading / empty / error / disabled / progress** 五态；
      缺口交互（G1–G5 等）全部 disabled，禁止 mock 或私有路径绕过。
- [ ] **AC5 边界合规**：按 §9 九条——无 SQLite/路径/模型直连；一切数据经 Tauri IPC；
      大图经资源通道（W5/`issue_resource_url`，**不经 JSON/Base64**）；UI 不写持久化状态。
- [ ] **AC6 不回归**：既有 probe / AC1 模式与 e2e runner **零回归**——保留其冻结 DOM/形状；
      `apps/desktop/frontend/e2e/**` 既有用例与前端单测全绿；给出原始日志与退出码。
- [ ] **AC7 构建证据**：frontend 生产构建 exit 0（归档原始日志）；Tauri 侧按需构建并归档退出码。
- [ ] **AC8 不越界**：**不修改** Python Core（`src/**`）、契约（`doc/contracts/**`）、Schema、依赖清单
      （除**必要**的前端依赖新增，须逐项说明理由并在 Handoff 单列）；不修改 probe/AC1 的冻结形状。
- [ ] **AC9 固定交付**：固定 commit、Handoff（[模板](../templates/HANDOFF.md)）、Canonical Evidence（真实 sha256）；
      未跑项如实 `NOT_RUN`/`BLOCKED`；不 `push`、不 `merge`。

- `depends_on` 全部满足（见来源）。设计基线 §7 的 24 条缺口是**有意 disabled**，不构成阻塞。

- 阻塞条件：若前端工具链不可用 → 如实 `BLOCKED` + 原始证据。
