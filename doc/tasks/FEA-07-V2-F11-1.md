# FEA-07-V2-F11-1（proposed）

## 背景
- 默认壳 = `v2`（`AppOptions.DefaultShellId`）；`App.axaml.cs` 仅在 `!UseV2Shell` 时创建 `MainWindow`。
- F11 沉浸实现只在 `MainWindow.TryHandleGlobalKey`/`OpenImmersiveReader` 与 `ReaderWindow`（legacy 壳）。
- 实测：`--shell=legacy` 下 F11 正常打开无边框全屏「阅读器」窗口（`verification/FEA-07-IMMERSIVE-F11-1/evidence/legacy-f11-native-20261109-153227.json`）；默认 `v2` 壳按 F11 无任何反应（无事件入口）。

## 待裁决
用户是否要求默认壳支持 F11 沉浸；若是，需冻结范围（入口/快捷键/返回页语义/与 Reader 页一致性）。

## 验收（草案，未冻结）
- 默认壳 F11 → 无边框全屏阅读窗口（覆盖当前显示器）；
- Esc/F11 退出并恢复来源页；
- headless 回归 + 真实桌面证据。

## 证据
- `verification/FEA-07-IMMERSIVE-F11-1/`（legacy 原生成功 + v2 无入口）。
