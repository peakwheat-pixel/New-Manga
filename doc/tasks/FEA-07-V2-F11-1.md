# FEA-07-V2-F11-1

## 背景

默认壳为 `v2`（`AppOptions.DefaultShellId`），`MainWindow`（含 F11/沉浸实现）只在 `--shell=legacy` 创建 ⇒ 用户按 F11 在默认壳无任何反应（用户可见缺口）。用户 2026-11-09 裁决：**沉浸入口改为按键**，在 v2 壳实现 F11。

## 实现

- `Shell/W2/ImmersiveReaderWindow.cs`（新）：无边框（`SystemDecorations.None`）、`WindowState.FullScreen`、黑底，内容为新的 `ReaderOverlay` 实例（绑定 `Library.Reader`）；`Esc`/`F11` 关闭（`TryHandleKey` 可 headless 断言）。
- `AppShellViewModel`：新增 `ImmersiveReaderRequested` 事件；`HandleKeyCore` 对**裸 F11**（无修饰键、非文本输入、非 palette/confirm）触发事件并消费；带修饰键/文本聚焦时**不消费**，不改变原有键语义；`ExecuteCommand(LibraryImmersiveReader)` 同样触发事件（命令面板可用）。
- `ShellCommands`：注册命令 `library.reader.immersive`（作用域「资料柜 · — · 阅读」，键位 F11）；`KeyMap.EnsureValid` 无冲突。
- `App.axaml.cs`：v2 壳创建时 `WireImmersiveReader`，持有单个沉浸窗口，F11 切换开/关，关闭后页面停留不变。

## AC

- [x] **AC1**：默认 v2 壳裸 F11 打开无边框全屏阅读窗口（`WindowState=FullScreen`、`SystemDecorations=None`、标题「阅读器」）。 <<MET>>
- [x] **AC2**：`Esc` 或再次 `F11` 关闭，主窗恢复原几何、页面不跳转。 <<MET>>
