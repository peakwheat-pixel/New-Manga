# P09-FU1：同步 legacy stub decoder 测试到真实 decoder 语义

## 来源与目标

- 来源：**P09 独立 Review 的 F2（P1，基线破坏）**——见 `verification/P09/dsh-review-r1.md` §2。
- 事实：
  - P09 让**生产装配**注入真实 decoder：`src/bootstrap/core_service.py` 第 370 行
    `image_decoder=QtImageDecoder()`（真实实现位于 `src/infrastructure/importing.py` 的 `QtImageDecoder`）。
  - `src/bootstrap/core_service.py:313` 的 `_PassthroughImageDecoder` **保留**，docstring 已标注
    `Legacy test double; production assembly uses QtImageDecoder`。
  - 但 `tests/core/test_stub_decoder.py::test_production_stub_decoder_returns_valid_decoded_image`
    仍断言**生产装配**的 decoder 把非法输入 `b"fake"` 解成 `1×1` —— 该断言与 P09 之后的真实语义**直接矛盾**，
    导致仓库测试基线为红。
- 目标：把该测试同步到 P09 之后的真实语义，**恢复测试基线**；不改动任何产品实现。

      对**非法字节**必须**拒绝**（抛异常或等价错误），不得再断言 `1×1`。
