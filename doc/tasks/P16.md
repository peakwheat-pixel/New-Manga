## Acceptance Criteria

- [ ] AC1 **Reader 投影与进度**：实现 `GetReaderProjection` 与 `SaveReadingProgress` handler，
      覆盖 `AC-READ-001..005`（原图/译图、独立阅读进度、RTL、LTR、Webtoon Vertical），
      并落实一长图一 Page、坐标回映、关闭重开语义（契约 §6.3）。
- [ ] AC2 **五格式导出**：实现 `StartExport` / `GetExportSnapshot` / `GetExportHistory` / `CancelExport` handler，
      覆盖 `AC-EXPORT-001` 的**五种格式**（PNG〔D1/D2 单图映射〕/ZIP/CBZ/PDF/文本），
      并表达**输出顺序、hash、lineage**（契约 §5、§6.3）。
- [ ] AC3 **`ExportTargetRef` Core 侧校验**（契约 §10.3，**安全 Gate**）：实现受信 grant 的**验证 / 解析 / 原子消费**，
      完整实现 6 类拒绝：`REF_MALFORMED` / `REF_SIGNATURE_INVALID` / `REF_EXPIRED` / `REF_UNKNOWN_ID` /
      `REF_REVOKED` / `REF_ALREADY_CONSUMED`；**任何目标写入前**完成校验；**源文件零写**。
      **不得**把任何路径字符串当作写授权。
- [ ] AC4 **进度与事件**：实现 `ReadingProgressChanged` / `ExportProgressChanged`，
      封装为 §3 `Event<T>`、与请求响应共用 JSONL；**仅在进度快照持久化后发出**；
      **不得携带文件路径或 `ExportTargetRef`**；不承诺送达/重放/排序。
- [ ] AC5 **stale / 取消 / 历史**：实现 `stale_policy`、`AC-EXPORT-003`（stale 提示）、
      `AC-EXPORT-002`（ExportHistory 记录输出路径等）、**临时发布与取消清理**（不留半成品）。
- [ ] AC6 **协议与既有语义**：Core 协议 envelope 同步为 **major 2 / minor 1**；
      **不得弱化** `§10.1/§10.2` 的既有读语义（复用 grant 解析时须保持等价或更强）。
- [ ] AC7 **范围锁定（严格）**：变更**仅限**契约 §12 冻结 allowlist（见下）；
      **不含** `src/application/export/pdf_qt.py`、`tests/reading_export/**`、PySide6/QML/Legacy、`apps/**`、
      Tauri/Rust、React/WebView、Schema/migration、依赖、其他产品行为，**也不含 Tauri host 的 issuer 实现**（另立 Task）。
- [ ] AC8 **真实测试**：在 `tests/core/**` 新增/扩展用例，覆盖 AC1–AC5；
      对 AC3 的 6 类拒绝与原子消费给出**判别证据**（含"错误引用不产生任何目标写入"的负向断言）。
- [ ] AC9 固定 head 非作者 Review、Coordinator 集成；未跑项标 `NOT_RUN` / `BLOCKED`，不得以总测试数替代逐项证据。
