# M2-I1 — Core Assembly Seam

## 来源与目标

用户于 2026-09-25 授权 M2 第一波 bounded implementation；[AD-001](../AD-001_TARGET_DESKTOP_ARCHITECTURE.md) 是目标架构，[M2-D1](M2-D1.md) 已在 `100abfb` 集成。固定代码基线为本地主线 `6a68fdeb92d8a1c7903166a8076d6260bf8fa79a`。将 `src/bootstrap/app.py` 的 Python Core 服务装配与 Legacy Qt UI/QML 装配分开，保持现有启动入口和业务权威。文件结构由 Owner 按现有代码确定；无需机械创建空目录。

## Acceptance Criteria

- [ ] **I1-AC1**：新增 Core Assembly 模块在禁止 `PySide6` 与 `src/ui` 导入的探针环境中可按模块名导入，不要求 `QGuiApplication` 或 `QQmlApplicationEngine`。
- [ ] **I1-AC2**：`src/domain/**`、`src/ports/**`、`src/application/**` 无新增 `PySide6` 依赖。
- [ ] **I1-AC3**：现有 Qt shell 保持原入口和行为；受影响的 bootstrap、UI shell 与业务测试通过，真实 GUI 验证若环境不可用须如实标 `NOT_RUN`。
- [ ] **I1-AC4**：Core Assembly 支持 adapter injection；其中不直接构造 `QtFontCatalog`、`QtTextLayoutEngine`、`QtImageCompositor`、`QtImageDecoder` 或 `QObject` ViewModel。Qt adapter 由 Legacy Qt 装配侧接入。
- [ ] **I1-AC5**：SQLite、Managed Copy、Provider、Pipeline 业务权威仍在 Python Core，不移至 Rust/UI，且现有装配副作用和恢复顺序不隐式变化。
- [ ] **I1-AC6**：新增有判别力的禁止 Qt/UI import 探针测试；保存原始输出、解释器/环境、exit code，记录对照失败证据。
- [ ] **I1-AC7**：现有业务测试无重构引入的隐藏行为变化；失败与 skip 分列并解释。
- [ ] **I1-AC8**：零 React/Tauri 初始化。
