- [ ] **AC4 未交付缺口保持禁用**：四页中所有**未交付能力**（含 G2 回收站、P15 未开放分区、任何未冻结 wire）在 E2E 中确认**可见但不可操作且有可理解原因**；**不得**因 E2E 便利而放宽或 mock 掉禁用态。
- [ ] **AC5 可复现与证据**：测试/清单命令与人工步骤**逐步可复现**；原始日志 + 退出码（或人工清单带截图/时间戳）入库；**如实声明哪些项未能运行及原因**（如无头环境限制）；**不得**把单测/DOM 测试表述为 GUI e2e。
