# T3.2.1-REPAIR-13：恢复章节图片导入并提高 QML 控件可读性

## 来源与目标

用户在固定 Build 3 的真实 Sandbox 交互中报告：点击导入无法选择图片、按钮文字与底色难以区分、因此无法继续 Reader 导出流程。Codex 将原始截图、固定包哈希、启动记录和 stderr 存入
[`manual-observations.md`](../../verification/T3.2.1/ac3-interactive-20260925/manual-observations.md)。

已核验的代码线索：原始 stderr 有
`BookshelfView.qml:23: TypeError: Cannot read property 'currentChapterId' of undefined`；
`BookshelfView` 通过 `detailArea.chapters` 访问 `BookDetailPanel` 内部的 `chapters` ID，
该 ID 没有公开为外部属性。Reader 截图则显示没有选择阅读章节；当前 Export 按钮因此
处于 disabled 状态，导出实现尚未被有效测试。

目标是修复章节图片导入的真实 UI 路径，令无效/未选章节状态提供清楚反馈，并使全局按钮
启用、禁用、聚焦等状态的文字可辨；随后用有效导入页面复测 Reader 的 Export 入口和真实
文件输出。不得预设导出实现有缺陷；若有效前置条件下 Export 仍失败，先记录证据并向
Codex 提交范围扩展请求。

固定 base `8738c41d7215920935e6fa067d3740e69280cdc6` 正是本次 Build 3 的源码 HEAD；
其产品代码/打包/打包测试与 Codex 候选 `188d72a9d144b8cab16f77757abc46318ac8e5e6`
差异检查为零。新 Task branch/worktree 由 Codex 从该 base 创建，开始时工作区干净。

## Acceptance Criteria

- [ ] **R13-AC1 — 导入入口无静默失败**：无书/无选中章节时，“导入”要么禁用并说明如何创建/选择章节，要么提供明确章节选择；任何状态下不得因 `chapters` 跨组件 ID 访问而产生 QML TypeError。固定 Sandbox stderr 中不再出现该错误。
- [ ] **R13-AC2 — 图片导入闭环**：在已有作品与选中章节时点击“导入”打开多文件选择器；选择两张固定合成 PNG 后，页面记录成功写入 Managed Copy、章节页数更新为 2，Workbench 可显示并选择两页。确认 fixture 源文件 hash 未变。
- [ ] **R13-AC3 — 按钮可读性**：Bookshelf、Workbench、Reader、Settings 和相关对话框中的按钮标签与底色可辨；至少检查 enabled、disabled、checked/highlighted、keyboard-focus 状态。保留现有 Graphite Atelier 色彩方向；提交对照截图及所用文字/底色值，不能只凭源码声称改善。
- [ ] **R13-AC4 — Export 有效状态复测**：导入成功后，在 Reader 明确选择有页面的章节；Export 按钮应可用并打开 ExportWindow。执行一次 ZIP/CBZ 导出，确认目标文件存在且包含预期两页。若在这些有效前置下按钮或导出仍失败，不扩展至 Python/export service；将最小复现和证据交 Codex 决定新范围。
