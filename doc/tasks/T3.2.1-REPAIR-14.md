# T3.2.1-REPAIR-14：恢复应用重启后的书架作品列表

## 来源与目标

来源为 REPAIR-13 最终 Handoff 与独立 Review 登记的 F-13-3：应用重启后 SQLite 中仍有作品，但书架列表显示为空。该问题尚未在 REPAIR-13 两次新建 data-root 的 GUI 会话中复现；需要使用同一个持久化 `--data-root` 完成正常退出和再次启动的复现。

Task 已由 Codex 登记为 `ready` 并释放给 Antigravity。依赖 REPAIR-13 已于 `6fe7455` 集成并完成。固定实现基线为当前 mainline HEAD `4ab6f58c06cb0691413e2630cb48a145c18c383a`；独立分支/worktree 和下列路径边界已冻结。实施前先按 R14-AC1 在隔离 data-root 复现并记录；若证据不支持当前根因线索，应停止修复推断并回报 Codex。
