# V11R-D-1：Design System (Avalonia)

## 目标
把冻结设计基线（`doc/design/redesign-v1/40-fusion/DESIGN_SYSTEM.md` + `tokens.json`）落成 Avalonia 可用的唯一设计系统：
令牌资源（`Nm.*`）、字体/间距/圆角/尺寸/密度、七态状态语言、基础控件样式、核心自定义控件、图标库、无障碍（焦点环/对比度/reduced-motion）。

## Acceptance Criteria
- [ ] AC1 `tokens.json` → Avalonia 资源字典的**可复现生成器**（脚本/工具）存在，重建产物逐字节一致；dark/light 全量键 + 全局 71 变量无缺失。
- [ ] AC2 `NewManga.DesignSystem` 编译通过，`dotnet build NewManga.sln -warnaserror` 0 warning。
- [ ] AC3 资源键命名符合契约 §2（`Nm.Color.Bg.Canvas` 等）；提供 C# 键常量，禁止字符串魔法值散落。
- [ ] AC4 标准控件样式：Button(4 变体 × 2 尺寸)/TextBox/TextBlock 6 层级/Border 5 级/ComboBox/CheckBox/Radio/ToggleSwitch/TabControl/ScrollViewer/ProgressBar/Separator/MenuFlyout/ToolTip。
- [ ] AC5 自定义控件 M0 集：`StatusGlyph/StatusBadge/Chip/Kbd/SegmentedControl/SearchField/EmptyState/AlertBanner/CountChips/Drawer/Modal/TopBand 基础版`。
- [ ] AC6 状态七态（+ 未开始/锁定）同色相 + 符号 + 文字三编码；`StatusGlyph` 为唯一符号源。
- [ ] AC7 主题/密度/对比度切换 = 替换资源字典；**同一视觉树动态刷新**，不重建窗口；有单测断言键齐全与切换后取值变化。
- [ ] AC8 reduced-motion 生效；焦点环 2px accent（outline，不用阴影）；对比度符合 DESIGN_SYSTEM §2.3。
- [ ] AC9 迁移/回退：加载失败回退默认字典不崩溃。
- [ ] AC10 证据：`verification/V11R-D-1/` 含构建日志、测试日志、双主题截图、偏差记录。

## 允许修改范围
见 frontmatter `allowed_paths`。旧 `NewManga.Theme` **不得**修改或新增引用。

## 禁止范围
旧 UI 视图（`Views/Pages.cs` 等）、Host/CoreClient、Python、其它 V11R 任务目录；不得引入未审批 NuGet 依赖（可用 Avalonia 11.3.x 原生能力）。

## 依赖/风险
- 令牌生成器必须容错 `rgba()`/`px`/`em` 等 DTCG 值形态；透明度用 `#AARRGGBB` 或 `Color.FromArgb`。
- Avalonia 无 `backdrop-filter`/阴影表达层级：按 DESIGN_SYSTEM 用 5 级明度 + 1px 描边实现。
