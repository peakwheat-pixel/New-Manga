# P10：凭据与配置通道契约

## 来源与目标

- 来源：P08 [SCOPE_DRAFT §69–86](../../verification/P08/SCOPE_DRAFT.md) 工作包 P10（第 76 行）与需求表第 37 行
  （Provider / 凭据 / 网络 / 设置，must：全部现行 P0/P1）。
- 现状缺口（SCOPE_DRAFT 第 37 行原文）：`CredentialRef exchange 缺失；普通settings DTO不能载secret`。
- 目标：产出一份**可冻结的凭据与配置通道契约**：CredentialRef exchange 协议、secret 不得出现在
  普通 settings DTO / SQLite 明文 / 日志中的强制边界、Credential Manager 集成契约、Network Profile 与
  Provider 绑定/回退语义、TLS 与连接测试契约；作为 **P15** UI/管理面与后续 Core 接线的唯一契约输入。
- 本 Task **只做契约设计与 verification**：不写 runtime、不接 Credential Manager、不改 Schema、不改依赖。
- 路由建议（SCOPE_DRAFT 第 76 行）：Owner=Codex；非作者 Reviewer=DeepSeek Harness。
  最终以 `.orchestrator/tasks/P10-role.json` 与 `route-agent.py` 结果为准。

      可用凭据、生命周期与失效时机）；**(b)** secret **MUST NOT** 出现在普通 settings DTO、SQLite 明文、
      日志与错误消息中（对应 `AC-SEC-001` / `AC-SEC-002`）；**(c)** Credential Manager 集成契约
      （`AC-SEC-003`）；**(d)** 凭据缺失/过期/替换/清除语义；**(e)** TLS 默认开启与关闭需确认
