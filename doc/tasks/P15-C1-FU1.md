- [x] **AC1 定案目标语义（已裁决：A1）**：`TestNetworkProfile { network_profile_id, provider_profile_id }` —— **`provider_profile_id` 改为必需**；目标恒为该 Provider 的 endpoint（经所选 Network Profile 的代理路径）；缺省/非法时按既有规则返回 `INVALID_REQUEST`。**不得**保留"缺省即 `passed`"的路径（那正是本 FU 要消除的假阳性）。<br>（A2——保留可选 + 新增 `not_testable` 终态——**用户 2026-10-17 未采纳**，仅留档。）

- [x] **AC4 安全与脱敏**：沿用 §5.2 既有约束（结果不得含原始响应/响应体/请求头/认证头/代理凭据/路径/endpoint 的敏感部分）；失败只走 §9 封闭投影。
