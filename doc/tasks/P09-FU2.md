# P09-FU2：导入侧 IPC 接线实现

## 来源与目标

- 来源（已冻结）：
  - **P18 真实运行暴露的运行时缺口**：`ImportPages` 返回 **`UNKNOWN_COMMAND`**
    （证据：`verification/P18/terminal-matrix.csv`、`verification/P18/raw/ja-r3/sidecar-stdout.jsonl`、`.../ko-r3/sidecar-stderr.log`）。
  - **权威 wire 契约**：`doc/contracts/M2-C1_TYPED_IPC_CONTRACT.md` **rev 2.2**
    —— §5 冻结 `ImportPages`、**§5.6 `ImportReport`**、**§10.4 `ImportSourceRef`**、**§12 导入侧授权与 allowlist**。
  - 需求：P08 [SCOPE_DRAFT §69–86](../../verification/P08/SCOPE_DRAFT.md) 需求表第 32 行与工作包 P12（第 78 行）；
    D08 `AC-IMPORT-001..005`、`AC-EXT-IMPORT-003/004`。
- 目标：在 Core 侧**接通**已冻结的导入 wire，使 `ImportPages` 真正可用（不再 `UNKNOWN_COMMAND`），
  从而解除 **P12（书架导入）** 与 **P19（四页 E2E）** 的端到端阻塞。
- **关键约束**：既有 `src/application/importing/**`、`src/application/library/**`、`src/infrastructure/sqlite/**`
  在本授权中是**只读复用面** —— 本 Task 只做**接线**，不得修改导入产品语义或 SQLite Schema。

## Acceptance Criteria

- [ ] AC1 **`ImportPages` handler 注册与装配**：在 `src/bootstrap/core_service.py` / `core_assembly.py` 注册并装配该 handler；
  **必须可证明**：请求 `ImportPages` 不再返回 `UNKNOWN_COMMAND`（判别证据）。
- [ ] AC2 **`ImportSourceRef` 验证与解析**（契约 §10.4，**安全 Gate**）：实现受信 grant 的签名/host session/scope/format/过期/撤销/重放校验，
  完整实现 §10.4 的稳定 `REF_*` 拒绝码（至少 `REF_MALFORMED`/`REF_SIGNATURE_INVALID`/`REF_EXPIRED`/`REF_UNKNOWN_ID`/`REF_REVOKED`/`REF_ALREADY_CONSUMED`）；
  **引用不是路径**：**不得**把任何路径/URI 字符串当作授权；**源文件零写**。
- [ ] AC3 **接入既有 P09 importer**：把解析后的来源交给既有 importer（**importer 只读，不改其语义**），
  并保证 P09 既有安全语义仍然成立：Managed Copy、真实 `width/height`、损坏/加密/路径逃逸/重复/中断/Unicode 的判定与拒绝。
- [ ] AC4 **`user-source` 只读 scope**：按 §12 在 `resource_channel` 中增加并校验 `user-source` **只读** scope；
  **不得弱化** §10.1/§10.2 的既有安全要求。
- [ ] AC5 **`ImportReport` 序列化**（契约 §5.6）：逐源逐页结果（成功/跳过/拒绝/pending）、源与 Page `hash`、真实 `width/height`、页序、
  重复判定、错误类别与副作用边界；命令与引用级拒绝返回 `ErrorEnvelope`。
- [ ] AC6 **测试**（`tests/core/**`）：AC1–AC5 逐项用例；AC2 必须有**负向断言**（错误引用**不产生任何库写入或文件写入**）；
  覆盖重复（缺省 `skip` 与 `import_as_new`）、中断、Unicode。
- [ ] AC7 **范围锁定（严格）**：变更**仅限**契约 §12 冻结 allowlist（见下）；
  **不得**修改 `src/application/importing/**`、`src/application/library/**`、`src/infrastructure/sqlite/**` 或任何 Schema；
  **不得**实现 Tauri host issuer（须独立 Task）。
