# V11R-F0-1：Region 写面契约（高风险）

## 目标

## Acceptance Criteria
- [ ] AC1 复用 `src/application/editing/service.py` 既有实现（先核实真实存在与语义），新增 Core 命令：`create_region / delete_region / save_region_geometry / merge_regions / split_region / reorder_regions / save_manual_translation / confirm_region_final / set_region_lock / pin_revision`。
- [ ] AC2 每条命令有 typed error、`expected_revision` 乐观锁语义（冲突码与既有 `INPUT_REVISION_CHANGED` 一致）、幂等说明。
- [ ] AC3 Host/CoreClient 侧注册（`HostCommandRegistry`、`HostCommandDispatcher`、`DomainServices`）与 minor 版本策略明确。
- [ ] AC4 用户数据安全：写操作必须有确认/版本校验；不得破坏 current/pinned revision；不得改源文件（Managed Copy 约束）。
- [ ] AC5 Python pytest 覆盖每条命令成功 + 冲突 + 非法参数；`dotnet test` 覆盖注册/参数写入。
- [ ] AC6 独立审查（非实现者）必须复核数据安全与锁语义；证据在 `verification/V11R-F0-1/`。
- [ ] AC7 契约文档更新（与 V11R-A-3 命令契约合并）。
