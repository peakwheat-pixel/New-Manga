## 来源与目标

This is Roadmap order 5 in [`REBASELINE_PLAN.md`](../REBASELINE_PLAN.md), after
T2.1.1. The product mapping requires chapter selection in the Reader toolbar
(`doc/05_UI_MAPPING.md` §§37–42), a Workbench context entry that remains an
honest empty state without context (`D05 §62`), and a non-blocking dismissible
error surface (`D05 §54`). The T2.1.1 non-author review deferred the missing
webtoon canvas ground to this Task; the paged and webtoon viewers must share
`Tokens.bgCanvas` without changing the existing tiled reading behavior.

## Acceptance Criteria

- [ ] Reader `readerPickChapter` opens an accessible, dismissible chapter picker; selecting a valid book/chapter uses the existing navigation/reader path and updates the displayed chapter without creating a page or bypassing existing state handling.
- [ ] Workbench `workbenchPickContext` opens the same or an equivalent picker from the no-context empty state; selecting a valid chapter enters the existing Workbench context. Standalone/no-ViewModel loading remains safe and honest.
- [ ] The command-error surface remains bound to `commandErrorText`, is reachable by keyboard/accessibility tooling, and its dismiss action calls `clearCommandError`, hides the surface, and leaves run state unchanged. A mutation test demonstrates the guard is discriminating.
- [ ] The production webtoon `Flickable` uses `Tokens.bgCanvas`, matching the paged viewer, while width-fit, natural height, tile serving, and saved scroll offset behavior remain intact.
- [ ] No new top-level page, command palette, glass effect, top navigation, Region six-state renderer, theme persistence, storage migration, bootstrap seam, Schema, provider/runtime, or dependency change is introduced.
- [ ] Delivery includes implementation tests, fixed author Handoff, reproducible verification evidence, independent Codex Review, and Codex integration evidence. `VERIFIED_COMPLETE` is forbidden before all gates pass.
