## Acceptance Criteria

- [ ] AC1：**Windows 打包与分发**——Tauri Bundler 产出可分发安装包（MSI/NSIS）；在干净 Windows 10/11 x64 环境可一键安装、可完整卸载无残留；安装包体积记录在案。
- [ ] AC2：**冷启动性能**——主窗口首次呈现 **≤ 2.0 s**；Python Core 就绪并可处理请求 **≤ 3.5 s**（整棵进程树计时，多轮取样）。
- [ ] AC3：**内存占用**——基础空闲驻留（不加载大模型，`Tauri + msedgewebview2* + python` Working Set 严格总和）**≤ 350 MB**；单图批处理峰值 **≤ 1.5 GB**。
- [ ] AC4：**交互响应与帧率**——按键/点击交互延迟 **≤ 50 ms**；单页/Webtoon 长图滚动 **稳定 60 FPS**；缩放平移无可见撕裂。
- [ ] AC5：**模型解耦与无 GPU 优雅降级**——无独立显卡/无 CUDA 环境下应用可正常启动、基础功能与在线 API 可用、本地模型自动降级为 CPU 模式；**严禁**因缺少 GPU 驱动导致启动失败。
- [ ] AC6：**故障隔离与自愈**——Python sidecar 异常退出时主窗口**不得白屏退出**，须拦截并提示；未提交草稿与操作状态不丢失；心跳探测与回收重启可用。
- [ ] AC7：**发布 Gate**——`npm run build` → `build_sidecar.ps1 -Force` → `cargo build` 全部成功；**`bundle` 与 `resources` 的 `core_service.exe` SHA-256 相等**；启动 smoke 中应用可启动且**四个一级页面（书架/工作台/阅读器/设置）均可达**。
