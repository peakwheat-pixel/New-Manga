# M2-I2 — Qt-free Logic Extraction

## 来源与目标

用户授权迁出 M2-D1 矩阵 M2D1-25/26 已验证为 Qt-free 的两个模块。将 `src/ui/models/tasks/projection.py` 的投影规则置于 `src/application/tasks/projection.py`，将 `src/ui/viewmodels/workbench/region_canvas.py` 的几何转换/拒绝规则置于 `src/application/editing/region_canvas.py`。目标路径按现有 `application/tasks` 与 `application/editing` 边界冻结；不改 Domain Contract。Legacy QML 使用方经新的 application seam 消费，现有导入兼容性与行为需有测试证明。

## Acceptance Criteria

- [x] **I2-AC1**：两个模块迁移前后输出 byte/semantic compatible；覆盖投影状态/按钮矩阵/步骤流与 region rounding/边界/零面积拒绝规则。
- [x] **I2-AC2**：`src/ui` 不再是两类规则的权威位置；Legacy ViewModel、PageListModel、QML 使用方经 `src/application` seam 消费。
- [x] **I2-AC3**：新位置按模块名无 PySide6 可导入；不新增 `src/application → src/ui` 依赖。
- [x] **I2-AC4**：迁移/补强原测试，新增 architecture guard 防止权威逻辑倒流 UI；禁止导入探针须有判别力与原始证据。
- [x] **I2-AC5**：既有 UI/业务测试通过；任何 skip、环境阻塞或兼容例外明确记录。
