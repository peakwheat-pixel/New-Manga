## 来源（Review R-011, P2 产品缺陷，非 Gate 项）

T3.2.1 全量独立 Review（Qoder，`doc/reviews/T3.2.1-78aba7c.md` @
`agent/qoder/T3.2.1-review-78aba7c` `4422f79`）定位的根因：

- `src/ui/viewmodels/bookshelf/viewmodel.py:270-278`：`_chapter_rows()` 把
  `page_count` 硬编码为 `0`，注释写明「0 = unknown」；
- `src/ui/qml/bookshelf/ChapterList.qml:66`：QML 无条件渲染
  `model.pageCount + " 页"` → 「未知」哨兵值被显示成真实计数。

表现：导入页面后书架章节行显示「0 页」，而 DB（pages=1）与 Reader（1/1 页）一致
——与 T3.2.1 Gate 证据（截图 `11-bookshelf-imported-chapter-row.png`、
`14-recovery-bookshelf-restored.png`；reviewer DB 探针）完全吻合。

同处 `"progress": None  # 字段未落地，诚实显示` 属同类「哨兵值被 QML 渲染」问题，
可并入本 slice 一并处理。

1. viewmodel 真实回填 `page_count`；
2. 未知时不渲染该段（不得显示 `0 页`）。
