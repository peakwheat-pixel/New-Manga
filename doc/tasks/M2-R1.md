# M2-R1 — Qt Runtime Feasibility Spike

## 来源与目标

解决 [M2-D1 报告](../research/M2-D1_HEADLESS_QT_COUPLING_AUDIT.md) 唯一 `UNVERIFIED` 项 M2D1-22。在匹配项目真实生产 Python/PySide6 版本的 Windows 环境下，验证无可见 GUI 时 Qt rendering/font stack 能否稳定运行。仅实验与研究，不改生产代码，也不预定渲染替代路线。

## Acceptance Criteria

- [x] **R1-AC1**：记录生产 Python、PySide6、Qt 与 Windows 版本的实际来源、解释器路径、安装/包版本及实验环境隔离方式；版本不匹配时明确限制结论。
- [x] **R1-AC2**：分别实测 `windows`、`offscreen`、`minimal` 平台下 `QGuiApplication`、`QFontDatabase`、`QtTextLayout`、Qt compositor 的装配、字体度量/文字布局与图像合成结果；给出可见窗口数量或其他无可见 GUI 证据。
- [x] **R1-AC3**：每个平台至少记录重复运行/进程退出的稳定性、失败类型、退出码、输入/输出 Hash 或尺寸；结论区分平台及仅部分可行的组合。
- [x] **R1-AC4**：报告将 M2D1-22 从 `UNVERIFIED` 收敛为实测结论或保留有明确 blocker 的 `UNVERIFIED`；给出对后续 Core/Qt adapter 边界的建议，不将研究结论冒充产品实现批准。
- [x] **R1-AC5**：`src/**`、`tests/**`、打包、Schema、依赖、T3.2.1 证据零修改；实验只接触隔离临时数据，不访问用户库。
