# P15-HOST-2：凭据入口与 Credential Manager 接线

## 来源（**为什么需要**）
**P15-HOST-1 如实上报范围冲突**（判断正确）：我的派发提示把范围限定为"17 条设置命令 + 2 条 Host-only route"，但 Task AC1 与契约 **§2/§4.1** 还要求 **WebView 可达的凭据入口**（契约汇总表记作 `credential_put` / `credential_clear`，§4.1 声明为 `PutCredential` / `ClearCredential`）。Owner **未擅自扩大范围**，故该面**仍未实现**；且 Host 侧凭据通道当前是**失败关闭桩**：

```rust
#[allow(dead_code)]
fn bind_profile_credential(...) -> Result<(), LibraryError> {
    Err(LibraryError::unavailable("P15 credential channel is unavailable"))
}
```

→ **诚实但端到端不可用**：用户目前无法在设置页录入/替换/清除凭据。本 Task 补齐该链。

## Acceptance Criteria
- [ ] **AC1 命名与范围先定案（硬门；BLOCKED）**：契约 **§4.1（L109、L114–L119）** 将 `PutCredential` / `ClearCredential` 描述为 WebView 可调用的 Host 命令，同时称 `PutCredential` 由 Host 提供 WebView 外的安全输入面；§2（L20–L27）则将 Tauri command 固定表列为 `credential_put` / `credential_clear`，未明确名称与 wire 的映射。已按硬门停止实现并上报，证据见 [AC1 blocker report](../../verification/P15-HOST-2/ac1-coordinator-blocker.md) 与 [blocked Handoff](../handoffs/P15-HOST-2-AC1-blocked.md)。待 Coordinator 明确① WebView 可达命令确切名称/参数；② WebView invoke 与 Host 外置安全输入面的关系。不得自行推定或改契约。
- [ ] **AC2 实现凭据入口**：按 AC1 定案实现 WebView 可达的凭据入口（录入/替换/清除），**payload 不含 Secret**；Secret 由 **Host 所有**的安全输入面采集，**绝不**进入 WebView 内存、Tauri invoke payload、Core 普通 settings DTO、日志、事件或任何错误。
- [ ] **AC3 接线 Credential Manager 通道**：把 Host 侧凭据通道从"不可用桩"改为**真实可用**（或若 OS/依赖不可用则**失败关闭并如实声明**）；`CredentialRef` 只在受信 Host↔Core exchange 与 Core 持久配置中出现。
- [ ] **AC4 四处同步**：新命令在 `main.rs`（`PRODUCTION_COMMANDS` / `generate_handler!`）、`capabilities/m2rc1-commands.json`、`build.rs`、**重新生成的** `gen/schemas/**` 与 `permissions/autogenerated/**` 一致；**计数按合并后真实值更新**（不删除既有断言）；**probe 7 / AC1 6 冻结面不得改变**；**两条 `Bind/ClearProfileCredential` 仍须仅 Host 可达**（不得因本 Task 而被暴露到 WebView）。
- [ ] **AC5 反例测试**：Secret/明文/`CredentialRef` **不得**出现在 WebView 的**请求、返回、事件、错误**任何一处（含错误路径与日志）；未授权/状态不匹配（`intent` 与状态不符）须 `conflict` 且**保留原绑定**；清除后**不换用其他 Credential/Provider**；WebView 传入 Secret 的尝试必须被拒绝。
- [ ] **AC6 交付**：固定 commit + Handoff + Canonical Evidence（`status: in_review`；`canonical_evidence_status: complete`；**BL-15/17/19/16(RV-P15-04)/18** 同前）。
