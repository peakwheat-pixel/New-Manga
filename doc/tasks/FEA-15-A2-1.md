## Scope 冻结（2026-11-10，DSH）

1. 复用或重建 sidecar（`core-sidecar/core_service.exe`），记录 sha256；不把产物提交仓库。

3. `install-smoke.ps1` 完成安装→启动→卸载并断言 `window_handle_found=true`、`console_window_count=0`、`exit_code=0`、`install_dir_after=false`、`residual_processes=0`。
4. 四页真实进程冒烟：对 bookshelf/workbench/reader/settings 各跑 `NewManga.App.exe --frontend=builtin.fluent --page=<page> --data-root <iso> --theme-home <iso> --exit-after=<ms>`，断言 EXIT 0 + 窗口句柄 + 截图；**隔离双根**（`--data-root` 与 `--theme-home` 均指向 workspace 临时目录），真实 `%APPDATA%\com.newmanga.desktop` 与 `%APPDATA%\NewManga` 指纹前后不变。
5. NOT_RUN 如实登记。
