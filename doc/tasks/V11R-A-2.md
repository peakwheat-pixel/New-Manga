# V11R-A-2：Run 控制服务层

## 目标

## Acceptance Criteria
- [ ] AC1 按契约 §5.2 交付 `IRunController` + DTO（`RunStartRequest/RunStartInfo/RunControlInfo/RunSnapshotInfo/TaskProjectionInfo/RunControlAction`），`HostController` 实现，`NullHostController` 提供确定性假实现。

- [ ] AC3 幂等键：`StartRun` 必填、`RetryFailedTargets` 必填、`ControlRun` 仅 restart 需要；缺失时本地拒绝并给 typed 错误，不静默生成。
- [ ] AC4 状态投影：`GetTaskProjection` 返回逐页/逐阶段状态，UI 可据此渲染矩阵（不得在服务层伪造进度）。
- [ ] AC5 错误映射：`INVALID_REQUEST/TARGET_NOT_FOUND/IDEMPOTENCY_KEY_REUSED/INVALID_RUN_TRANSITION` 映射为可读结果并保留 code。
- [ ] AC6 单测覆盖成功/非法转换/幂等复用/取消；`dotnet test` PASS。
- [ ] AC7 证据：`verification/V11R-A-2/`。
