# P15-C1：设置面 IPC 契约修订（解 G21–G24 + 部分 G25）

## 来源与裁决

本 Task 由 Coordinator **裁决记录** [ruling-G21-G25.md](../../verification/PROJECT-ORCHESTRATION-20261016/ruling-G21-G25.md) 授权创建并释放。**先读该裁决**——它规定了每个缺口的处置与硬性边界。

**缺口性质**：设计基线 §7 的 **G21–G24** 均为"**P10 已冻结逻辑边界、缺 IPC wire**"（P10 已 done，集成 `c46c0df0`，交付 [P10_CREDENTIAL_CONFIG_CONTRACT.md](../../doc/contracts/P10_CREDENTIAL_CONFIG_CONTRACT.md)）；**G25** 为"**逐分区**"键域 schema，设计原文即要求逐节契约 Task。

## Acceptance Criteria

- [ ] **AC1 契约修订（本 Task 的交付物，不改产品代码）**：在契约中冻结下列**新增**面，且**只新增 wire/键域、不重开 P10 已冻结的语义**：
      1. **G21 Provider Profile 面**：Profile CRUD、**Capability 默认绑定**、**绑定优先级解析**（按任务/章节/作品/全局，依据 D04 §40 与 P10 §5）、**Run Snapshot 冻结查看**；**必须支持多 Profile 同 Provider**。
      2. **G22 凭据操作面**：**专用一次性**凭据新增/替换/清除 + **`CredentialRef` exchange**；**只可读"已配置/缺失"**（允许 masked hint），**永不回显明文**、**提交后不可读回**；**普通 settings DTO 禁止承载 Secret**（沿 P10 §3.4/§9 与 M2-C1 §5.3）；失败文案**不得含原始响应/认证头**。
      3. **G23 Network Profile 面**：Profile CRUD（Direct/System/HTTP/HTTPS/SOCKS5）+ **分阶段连接测试**（Proxy→DNS→TCP→TLS→HTTP→Provider Auth）；**未执行阶段明确标记**、**失败保留阶段**、**代理失败默认不静默直连**；**TLS 校验关闭须危险确认且状态可见**。
      4. **G24 设置覆盖解析查询**：**只读**解析**最终有效值 + 来源标注**（全局→作品→章节→当前任务）；**不得**借该命令写设置。
- [ ] **AC2 G25 的「可编辑分区清单」**：产出一份**显式清单**，逐节给出**键集与值域**，且**仅纳入**：(a) 已有 Core 写入校验实例或既有 handler 的节（如 `sfx.policy`）；(b) 由 P10 或既有契约**已确立语义**的节。**未列入的节不在 P15 开放**（P15 将渲染为禁用 + 原因"等待 section schema 冻结"），并**逐节另立后续契约 Task** 的登记建议。清单必须写明每节的**依据来源**与**验证方式**。
- [ ] **AC3 兼容与版本**：按 M2-C1 §3.2 规则声明协议 minor 递增与向后兼容影响（只新增命令/字段，不改既有冻结语义）；如涉及 Tauri host 面，明确 production-only 与 probe/AC1 冻结形状不变。
- [ ] **AC4 Secret 与路径边界**：任何新增面**不得**把 Secret、明文凭据、认证头、文件系统路径或不透明写引用暴露给 WebView（请求/返回/事件/错误**四处**）；错误只走**稳定错误类别 + 失败阶段 + 可采取动作**的脱敏文案。
- [ ] **AC5 不改越界范围**：**不实现任何产品代码**（前端/Rust/Python）；不改既有冻结字段/语义；不改 Schema/迁移；不新增依赖。确需实现的部分留给 P15 或后续 Task。
- [ ] **AC6 证据与交付**：契约文件的**逐节修订记录** + **可复核依据映射**（每条裁决 → 契约条文 → 来源文档章节）；固定 commit、[Handoff](../templates/HANDOFF.md)、Canonical Evidence（**按磁盘字节**算 sha256，commit 用**原样** `git rev-parse HEAD`——**BL-17**）；不 `push`/`merge`；**BL-15**：`delivery_head` 不自引用即将产生的 SHA。

- `depends_on`：P10（凭据/设置逻辑边界，done）、P13-C1/P12-C1（既有设置与导入 wire 的冻结先例）。
