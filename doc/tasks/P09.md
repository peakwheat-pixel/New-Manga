# P09：导入 Core

## 来源与目标

- 来源（已冻结）：
  - P08 [SCOPE_DRAFT §69–86](../../verification/P08/SCOPE_DRAFT.md) 工作包 **P09**（第 75 行）与需求表第 32 行。
  - 需求表第 32 行原文缺口：`production decoder 恒 1×1；PDF/MOBI 解析存在但生产闭包未验证；D04 §8、AC-IMPORT/EXT；D04 含缩略图描述，缩略图首发按 D1 延期`。
  - 目标摘要：`P09 真实尺寸/受控来源/Managed Copy；损坏、加密、逃逸、重复、中断与 Unicode；源 hash 零变化`。
  - **用户 2026-10-16 裁决**：首发输入格式 = **图片/文件夹 + PDF**；**MOBI 不纳入首发**（`.orchestrator/BACKLOG.md` BL-2）。
- 现状：`src/application/importing/images/`（`ports.py`、`service.py`、`sorting.py`）与
  `src/application/importing/documents/`（`ports.py`、`service.py`）已存在；生产 decoder 取尺寸为占位（恒 1×1）。
- 目标：让**生产链**具备真实尺寸解码、受控来源与 Managed Copy 闭环，并以负向 Gate 证明损坏/加密/逃逸/中断/重复/Unicode 行为；
  为 P12（书架导入 UI）提供可消费者契约。

## Acceptance Criteria

- [ ] AC1 **真实尺寸 decoder**：图片/文件夹导入在生产装配下取**真实 width / height**（消除恒 1×1 占位），
      并按 `AC-IMPORT-001` 写入 Managed Copy 记录（source filename、source order、current sort order、hash、width、height）。
- [ ] AC2 **受控来源 + 路径逃逸拒绝**：仅接受用户显式选择范围内的路径；对 junction / symlink / 相对路径穿越 /
      盘符逃逸必须**拒绝**且零副作用；拒绝行为有可复核证据。
- [ ] AC3 **源文件零修改**（`AC-IMPORT-002` [P0]）：在导入 / 翻译 / 重修 / 重渲染 / 删除项目 / 永久删除项目后
      重算源文件 hash，**必须完全一致**（给出前后 hash）。
- [ ] AC4 **Copy 中断不产生坏 Page**（`AC-IMPORT-003` [P0]）：模拟 Copy 中断（故障注入），
      不得留下"数据库已有 Page 但 Managed Original 不存在"的状态；**零半成品**。
- [ ] AC5 **Unicode 路径**（`AC-IMPORT-004` [P1]）：覆盖 中文 / 日本語 / 한국어 / Emoji / 空格 / 括号，全部导入成功。
- [ ] AC6 **重复检测**（`AC-IMPORT-005` [P1]）：相同图片再次导入时按 **hash** 检测重复，并按既定策略处理（策略须在契约中写明，不得静默覆盖）。
- [ ] AC7 **PDF**：未加密 PDF 按页导入（`AC-EXT-IMPORT-003`）；**加密或损坏 PDF 必须零半成品拒绝**（`AC-EXT-IMPORT-004`）。
- [ ] AC8 **范围锁定**：首发格式严格为**图片/文件夹 + PDF**；**不实现 MOBI**；**不实现缩略图**（按 D1 延期）。
      越界实现视为交付失败。
- [ ] AC9 固定 head 非作者 Review、Coordinator 集成；未跑项必须标 `NOT_RUN` / `BLOCKED`，不得以总测试数量替代逐项证据。
