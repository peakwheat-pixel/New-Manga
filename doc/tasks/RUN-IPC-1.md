# RUN-IPC-1：Tauri host 接线 Run 命令面

## 来源与缺口事实（Coordinator 只读复核确认）

**这是一个此前未被任何 Task/缺口登记的实质阻塞。**

| 事实 | 证据（当前 main） |
|---|---|
| Core 侧**已实现** Run 命令 | `src/bootstrap/core_service.py:190-191` 列出 `StartRun`/`ControlRun`/`ResumeBlockedRun`/`GetRunSnapshot`/`GetTaskProjection`/`RetryFailedTargets`；handler 见 `:2317+`（`StartRun` `:2322`、`ControlRun` `:2342`、`GetRunSnapshot` `:2368`、`GetTaskProjection` `:2392`） |
| host 侧**完全没有**这些命令 | `apps/desktop/src-tauri/src/main.rs` 的 `PRODUCTION_COMMANDS`（18 条）**不含**任何 Run 命令；`start_run`/`control_run`/`resume_blocked_run`/`get_run_snapshot`/`get_task_projection`/`retry_failed_targets` 在全 `*.rs` 中 **0 命中**；**也没有**通用透传命令（无 `dispatch_request`/`call_core` 之类 Tauri command） |
| P13 **按范围本就不含** Tauri 侧 | `doc/tasks/P13.md:86`："不实现 P14 UI / React / Tauri 前端" |
| 设计基线**假设其可用** | [设计基线](../design/AD001_FOUR_PAGE_UI_BASELINE.md) §6 的 **W11–W16**（工作台：批处理发起 / 暂停停止继续 / 解除阻塞 / Run 快照 / TaskProgressPanel / 失败重试）绑定这 6 条命令；§6 表注把"产品 Tauri command 名"留给实现 Task 冻结，**但未核对 host 侧是否已有出口** |

**结论**：WebView **没有任何途径**发起/控制/查询 Run。因此 **P14（工作台）除了 G17（事件转发）之外，还被本缺口阻塞**；
若先释放 P14，实现者会发现控制面**完全不可达**——这正是 UI-DESIGN-1 I1 揭示的同一类风险（"契约冻结 ≠ 实现可达"）的反向实例。

## 依赖、风险与阻塞

- `depends_on`：P13（Core Run 运行时，done）、P13-C1（Run wire 冻结 rev 2.0，done）、UI-DESIGN-1（设计基线，done）。
- 风险一：**运行 Run 需要真实夹具**（book/chapter/page/catalog + Provider 配置）。若无法构造最小可运行 Run，
  则 AC4-③ 退化为分层证据（命令可达 + typed 拒绝）并如实标注；**不得**伪造一次"成功运行"。
- 风险二：`StartRun` 会真实改动持久化状态（Run/Task/StepRun 行）。测试必须使用**隔离数据目录**，不得污染主仓或用户数据。

- 阻塞条件：若 §5.5 缺少某条命令的**产品命令名**裁决且 Coordinator 判定必须先改契约 → `BLOCKED` + 证据。
