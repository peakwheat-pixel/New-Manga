# T3.2.1-REPAIR-15：Reader 导出丢 book/chapter 血缘

状态：**proposed / NOT_RELEASED**——本文件只是登记，未经 Codex/用户释放前不得实施。

## 来源（Review R-010, P2 产品缺陷，非 Gate 项）

T3.2.1 全量独立 Review（Qoder，`doc/reviews/T3.2.1-78aba7c.md` @
`agent/qoder/T3.2.1-review-78aba7c` `4422f79`）定位的根因：

- `src/ui/viewmodels/reader/viewmodel.py:459-461`：`openExporter()` 构造
  `ExportViewModel(self._export_service, self._chapter_export_pages, parent=self)`
  时**不传** `book_id`/`chapter_id`，二者默认 `""`；
- `src/ui/viewmodels/export/viewmodel.py:73-74,101-103`：`set_context()` 在 QML 侧
  无任何调用点（grep 零命中）；
- 对比书架路径 `src/bootstrap/app.py:273-278` 正确传入。

结果：从阅读器发起的导出，`export_history.book_id/chapter_id` 恒为空串（列
`NOT NULL` 但无非空 CHECK），`idx_export_history_book` 失效，导出血缘丢失。与本
Gate 观察吻合（`ac7-data-safety-check.log`：导出行 `book_id=''`/`chapter_id=''`
而 `scope_snapshot_json.page_ids` 有值；reviewer DB 探针独立复现）。

## 建议修复面（R-016 已由 Codex 收窄；仅限 VM 传参）

固定修复面为 ViewModel 内传递 Reader 上下文，不含 Schema/migration：

1. ReaderViewModel.openChapter(book_id, chapter_id, ...) 在成功打开章节时保存
   self._book_id = book_id 与 self._chapter_id = chapter_id。
2. ReaderViewModel.openExporter() 构造 ExportViewModel 时传入
   book_id=self._book_id, chapter_id=self._chapter_id。

ReaderViewModel 当前没有 _book_id / _chapter_id；不得只添加第 2 步而假设属性已存在。
允许修改面锁在 Reader ViewModel 与其定向测试。给 export_history 增加非空 CHECK
或 migration 的旧 option 2 已剥离；任何 Schema/migration 改动均需单独明确授权和单独 Task。
