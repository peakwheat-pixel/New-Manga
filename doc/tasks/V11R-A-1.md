# V11R-A-1：CreateChapter 服务层

## 目标
补齐审计 P-01 / F004 / F011：`CreateChapter` 已在 Core 与命令注册（C037, minor=8），但 `IHostController` 无 `CreateChapterAsync`，导致空库→建书→建章→导入链路在 UI 层断裂。

## Acceptance Criteria
- [ ] AC1 `IHostController`/`HostController`/`NullHostController` 新增 `Task<ChapterSummary?> CreateChapterAsync(string bookId, string title, CancellationToken ct = default)`，签名与契约 §5.1 一致。
- [ ] AC2 `HostController` 走 Core 命令 `create_chapter`（`CreateChapter`，minor 8），参数形状与 Core 端实参一致（读 `src/bootstrap/core_service.py` 与 `HostCommandDispatcher.WriteCorePayload` 核实，不猜）。
- [ ] AC3 失败路径：Core 返回错误时方法返回 null 并通过既有错误通道记录（不吞异常、不回显路径/secret）。
- [ ] AC4 空白/超长/重名标题的处理与 Core 语义一致；空 bookId 直接拒绝。
- [ ] AC5 单测：`NullHostController` 假实现确定性；`HostController` 用既有测试替身覆盖成功/失败/取消三路径；`dotnet test` PASS。
- [ ] AC6 证据：`verification/V11R-A-1/`（命令、exit code、摘要、契约差异记录）。
