# P05：category/retryable 契约注记收敛

## 来源与目标

路线来源为 [REBASELINE_PLAN P05](../REBASELINE_PLAN.md)；依赖的 M2-CATEGORY-CLARIFY-1、M2-RC4-DOMAIN-COMMANDS 与 M2-PAGE-RESOURCE-RESOLVE-1 均已集成。目标是补齐 RC4-10/RC4-08 后续登记的 §8 反向引用及 category/retryable 区分。只记录现有实现与已审查的命令级差异，不改变冻结错误语义，也不把 §8 的 PROPOSAL taxonomy 提升为全局运行时约定。

代码证据基线为 `main@c7a41f52aec961b30ad5e3c7e7569bac042bb847`：`rerender_page` 对 `MISSING_REQUIRED_INPUT` 输出 `category="unavailable"`、`retryable=false`；同命令的 `ARTIFACT_WRITE_FAILED` 为 `internal`、`retryable=false`。`resolve_page_resource` 的 `ARTIFACT_WRITE_FAILED` 为 `internal`、`retryable=true`。分类与是否可重试是独立字段，以上都是命令级现状，不得扩写成同一 error code 的全局规则。宿主侧 `CORE_UNAVAILABLE` 不属于上述 Core envelope 映射；本 Task 不为它补造 `category` 或 `retryable`。
