# M2-S3 — Tauri Asset Protocol Feasibility Probe

## 来源与目标

来源：M2-S1 报告 §8.2 的 S1-B1（`NOT_RUN`：在真实 Tauri 骨架中验证受限字节、权限、缓存与生命周期）；M2-C1 Typed IPC Contract 1.1 §10.1 T5、T6 与 §10.2（固定 blob `fc35913801297ee1876ea395f9c5041a16226f20`）；M2-S2 原型结论及其产品级限制；AD-001 Tauri/Rust host 与 Python Core 的目标边界。

目标：用隔离的真实 Tauri/WebView 骨架，判断 asset protocol 能否承载 Contract 1.1 要求的受限派生资源，并给出可复现证据供后续 runtime Task 选择实现路线。本 Task 只做可行性探针；结论不构成产品实现、路线批准或 runtime 授权。
