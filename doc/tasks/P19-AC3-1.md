# P19-AC3-1：AC3 全域安全边界扫描

## 来源（Codex R3 finding R3-002，P1）
`verification/P19/codex-review-r3.md` 判定：**不得**用 UIA 文本观察、创建功能安全投影或 P15-HOST-2 反例**替代** P19 要求的：
1. **全页面 / 全命令 / 事件 / 错误**在 **请求、返回、事件、错误四处**的**扫描**；
2. **WebView 访问面边界证明**（React/WebView **不得**直接访问 SQLite、任意 OS 路径、模型）。

## Acceptance Criteria
- [ ] **AC1 请求侧扫描**：对四页可触达的**全部 production 命令**，逐一检查**请求载荷**是否只含契约允许字段；**未知/多余字段 fail-closed**；**不得**接受路径、Secret、任意写入目标。
- [ ] **AC2 返回侧扫描**：逐一检查**响应**是否只含契约白名单字段；**不得**出现绝对/相对路径、Secret、原始异常、内部栈。
- [ ] **AC3 事件侧扫描**：检查**事件**通道（若有）载荷同规则；`credential_*` 语义**永不回显明文**。
- [ ] **AC4 错误侧扫描**：检查**错误**投影为稳定封闭类别（脱敏文案）；**不得**含路径/Secret/原始异常。
- [ ] **AC5 WebView 边界证明**：以**代码级证据**证明前端**不**经 `invoke` 之外访问 SQLite / 任意 OS 路径 / 模型（如列出前端可用的 Tauri API 面、`capabilities` 白名单、无 `fs`/`sql` 插件或已最小化）；并给出**反例测试**（越权调用被拒）。
- [ ] **AC6 覆盖矩阵**：产出「命令 × 请求/返回/事件/错误」四列矩阵（每条命令四格均有结论 + 证据引用）；**未实现命令**列明并标记 N/A 及理由。
- [ ] **AC7 证据与交付**：原始扫描产物（脚本 + 输出 + 退出码）+ 命令/文件:行引用；**不得**以文字结论替代原始输出；commit + **Handoff（必须）** + Canonical Evidence（`status: in_review`；BL-15/17/19/16/18）。
