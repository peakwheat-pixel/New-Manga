# P12-C1：导入侧 IPC 契约修订

## 来源与目标

- 来源（已冻结）：
  - **P18 真实运行暴露的缺口**：`ImportPages` 返回 **`UNKNOWN_COMMAND`**，端到端链路第一步即阻断
    （证据：`verification/P18/terminal-matrix.csv`、`verification/P18/raw/ja-r3/sidecar-stdout.jsonl`）。
  - 契约现状：`doc/contracts/M2-C1_TYPED_IPC_CONTRACT.md` §5 的 `ImportPages` 行**仍为未冻结**，
    原文写明"未来 IPC 必须由 Tauri host 授权并传递不透明、受限、可过期的 `ImportSourceRef`"；
    `ImportProgressChanged`（§6.2）仍为 **UNKNOWN / PROPOSAL**。
  - P08 [SCOPE_DRAFT §69–86](../../verification/P08/SCOPE_DRAFT.md) 需求表**第 32 行**（图片/文件夹/PDF/MOBI 导入）
    与工作包 **P12**（第 78 行）；P09 的"真实尺寸/受控来源/Managed Copy；损坏、加密、逃逸、重复、中断与 Unicode；源 hash 零变化"。
  - P16-C1 已确立 `ExportTargetRef`（**写**引用）并声明其与 `ImportSourceRef`（**读**引用）同源；
    本 Task 负责把这个**读**引用正式冻结。
- 目标：冻结导入侧的 wire 面与授权边界，使 **P12（书架导入）** 与 **P19（四页 E2E）** 有合法 wire 可用。
  本 Task **只做契约设计**，不实现 runtime、不改产品代码。

## Acceptance Criteria

- [ ] AC1 **`ImportPages` 与 `ImportSourceRef`**：冻结请求（`{chapter_id, sources: ImportSourceRef[]}`）与结果（`ImportReport`）的 wire 形态；
  定义 `ImportSourceRef` 为 **Tauri host 签发的不透明、受限、可过期引用**（**不得**承载原始 bytes/Base64、不得暴露原始路径）；
  明确 issuer / scope / 过期与续期 / 撤销 / Core 侧解析与拒绝规则。
- [ ] AC2 **与 P09 已实现语义对齐**：wire 必须能表达 P09 已交付的应用层行为 ——
  **真实 width/height**、**Managed Copy**、**源文件零写**，以及 **损坏 / 加密 / 路径逃逸 / 重复 / 中断 / Unicode** 的判定与拒绝。
- [ ] AC3 **`ImportReport` 内容**：逐源/逐页结果（成功、跳过、拒绝）、`hash`、`width/height`、
  重复判定结果与错误类别；错误面须完整且可判定（含"拒绝且零副作用"）。
- [ ] AC4 **导入进度事件**：把 `ImportProgressChanged` 由 UNKNOWN 提升为**冻结**或**显式保持非冻结并说明理由**；
  若冻结，须对齐 §3 `Event<T>` JSONL 纪律（**不携带路径/引用**、只作提示、快照为真值）。
- [ ] AC5 **授权边界与兼容性**：更新 §12，**明确授权导入侧 Python IPC Runtime**（限定冻结 allowlist 内），
  排除 React/Tauri/Rust/QML、Legacy、其他产品行为与依赖；写明**破坏性变更**与协议版本如何变、理由。
- [ ] AC6 **覆盖对照**：产出 D08 `AC-IMPORT-001..005`、`AC-EXT-IMPORT-003/004` 与需求表第 32 行的逐条对照，
  证明 wire 面足以承载且**不发明产品行为、不降低阈值**。
- [ ] AC7 **不越界**：除本契约文件外不改任何文件；不实现 runtime；不改 P11 / P13-C1 / P16-C1 已冻结的 wire 语义。
- [ ] AC8 固定 head 非作者 Review、Coordinator 集成；未完成项标 `NOT_RUN`。

## 依赖、风险与阻塞

- `depends_on`：P09（`closed_with_limitations`，应用层导入已集成）、P16-C1（`done`，契约 rev 2.1 已集成）。
- 风险一：导入侧同时被 **P12** 与 **P19** 依赖，且 P18 已实证其缺失会**直接阻断端到端链路**；
  本契约必须能承载 P09 的**全部**安全语义（源零写、逃逸拒绝、中断无坏 Page）。
- 风险二：若把 `ImportSourceRef` 设计得比 `ExportTargetRef` 更弱（例如允许裸路径），将破坏 §10 的既有安全边界 → 必须同源。
- 阻塞：无预期。
