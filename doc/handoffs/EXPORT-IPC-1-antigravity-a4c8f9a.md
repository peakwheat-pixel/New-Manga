## 去路径投影的保留/剔除逐字段说明（AC1/AC3 核心不变量）

依 M2-C1 §5 行 164 与 §10.3 L853，`output_path` 仅供宿主使用，严禁向前端暴露。投影严格采用**显式白名单构造**（禁止黑名单删字段）：

### 1. `ExportProgressSnapshot` → `ExportProgressSnapshotView`

| 字段 | 处理 | 理由 |
|---|---|---|
| `export_id` | **保留** | 不透明任务句柄，前端用于追踪进度或发起取消（W22/W23） |
| `status` | **保留** | 任务状态（`pending` \| `running` \| `publishing` \| `completed` \| `cancelled` \| `failed`），UI 展示必需 |
| `completed_pages` | **保留** | 已完成页数，进度条计算必需 |
| `total_pages` | **保留** | 总页数，进度条计算必需 |
| `current_page_id` | **保留** | 当前正在处理的页面 ID，供细粒度进度指示 |
| `accepted_at` | **保留** | 接收时间戳，UI 排序/展示耗时必需 |
| `completed_at` | **保留** | 完成时间戳，UI 展示必需 |
| `output.format` | **保留** | 产物格式（如 `pdf`/`zip`），UI 状态卡片展示必需 |
| `output.sha256` | **保留** | 产物 SHA-256 指纹，内容校验与信息卡片必需 |
| `lineage` | **白名单保留** | 保留 `page_id`、`order`、`source_artifact_id`、`source_artifact_revision_id`、`source_sha256`、`rendered_from_revision_id`、`current_source_revision_id`、`source_run_id`、`stale` 供溯源展示 |
| `error_code` | **保留** | 任务失败时的 typed 错误码（如 `EXPORT_FAILED`），供 UI 展示错误状态 |
| `output_path`（顶层及 output 内） | **剔除** | **核心红线**：严禁向 WebView 泄露用户文件系统路径（防信息泄露与路径注入） |
| `target_path_internal` | **剔除** | 内部目标绝对路径，严格剔除 |
| `lineage.*.internal_file_path` | **剔除** | 谱系内部文件路径，严格剔除 |
| `target_ref` / `grant_id` / 凭据 | **剔除** | 单次写授权凭据不得向前端扩散 |

### 2. `ExportHistoryEntry` → `ExportHistoryEntryView`

| 字段 | 处理 | 理由 |
|---|---|---|
| `export_id` | **保留** | 不透明历史条目 ID，前端后续触发打开文件夹（EXPORT-REVEAL-1）的唯一合法依据 |
| `book_id` | **保留** | 书籍标识，历史列表分组/关联必需 |
| `chapter_ids` | **保留** | 章节列表，UI 展示必需 |
| `ordered_page_ids` | **保留** | 页面列表，UI 展示必需 |
| `format` | **保留** | 格式名称，UI 展示必需 |
| `format_options` | **保留** | 导出配置（如 dpi 等参数对象），历史复查必需 |
| `created_at` | **保留** | 创建时间，历史排序展示必需 |
| `completed_at` | **保留** | 完成时间，历史展示必需 |
| `status` | **保留** | 终态，UI 状态指示必需 |
| `sha256` | **保留** | 产物指纹，UI 详情展示必需 |
| `lineage` | **白名单保留** | 安全谱系视图（同上） |
| `output_path` | **剔除** | **核心红线**：前端如需定位文件夹，必须依 §10.3 L853 经 `library_reveal_export_folder(export_id)` 经宿主代理执行，前端不可直接感知路径 |
| `target_ref` / 凭据 | **剔除** | 单次写凭据不得入历史投影 |
| `stale_policy` 等内部控制项 | **剔除** | 内部执行策略，前端无消费需要 |

### 3. 空态与错误净化

- **空历史**：无导出记录时，`library_get_export_history` 返回 `{"exports": []}`，**不返回错误**；
- **错误净化**：Tauri command 层采用 `map_err(|error| error.code)`，彻底剥离 Core 或系统原始 message，确保错误响应中绝对不夹带任何文件系统路径。
