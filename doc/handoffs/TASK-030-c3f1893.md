## 风险与遗留

1. **数据根默认值属装配决定**：`%LOCALAPPDATA%/New Manga`（`NEWMANGA_DATA_ROOT`/`--data-root`
   可覆盖）。正式的路径设置 UI 与数据迁移属 TASK-022；此默认无 D03/D07 明文规定，Codex 集成时可裁决或另行变更。
2. **PySide6 wrapper 时序事实**：root 对象的 Python 包装类型取决于包装发生时已导入的类型——
   `bootstrap/app.py` 顶层显式 `from PySide6.QtQuick import QQuickWindow` 是功能必需（缺它
   rootObjects()[0] 退化为 QWindow，无法抓帧）；同理抓帧用 `QQuickWindow.grabWindow()`，
   `QScreen.grabWindow` 在虚拟显示器上返回空帧。已写入代码注释。
3. **smoke/screenshot 走临时数据根**：不写真实用户数据；显式 `--data-root` 优先于临时根。
4. 回退：分支 revert 至 `087da45` 即可，无数据迁移（migration 复用主线既有 v1/v2，无新 Schema）。
