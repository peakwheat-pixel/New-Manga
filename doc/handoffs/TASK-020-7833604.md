## ⚠️ 重要：超大 fixture 的像素解码 BLOCKED（如实登记，未记 PASS）

Task 测试要求"按授权 fixture 验证约 1600x200000px"。**几何验证 PASS、像素解码 BLOCKED**：

- 实测（探针已入库测试文档）：Qt PNG handler 在 rgb32 字节数 ≳300MB 时**任何读取方式都失败**（高度 40000=256MB 成功、50000=305MB 失败、65535/70000/200000 全失败；`setClipRect` 不改变结果——handler 先分配整图再裁剪；系统可用内存 19GB，排除内存不足）。
- 1600×200000 = 1.28GB rgb32，**当前依赖下无法解码**。`test_oversize_page_geometry_and_decoder_limit_record` 据此交付两层：TileGrid 对 200000px 高的**几何**验证全过（50 tiles 恰好划分/回映/视口），解码失败固化为表征断言（`pytest.raises(OSError)`）+ `oversize-record.json` 记录 BLOCKED 口径与**解锁条件**（①批准引入流式 PNG 解码依赖；②Qt 上游修复）。
- **解锁后**：表征断言会失败提醒更新口径——这是有意的回归钩子。未把 BLOCKED 记为通过，未宣称任何"建议预算"为实测。
