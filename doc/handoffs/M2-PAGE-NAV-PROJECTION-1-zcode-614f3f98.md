## 设计裁定（Reviewer/集成方请特别核验）

1. **下钻数据流分层**：下钻读取 effect 与选择状态上浮 `<WorkbenchPage>`（与 books/regions/resolve/image 既有模式一致——client 由 WorkbenchPage 构造注入）；`<PageListPanel>` 保持纯展示组件；展开/收起（toggle 再点同书/同章）是 React 本地 UI 态，Core 无写路径（§5.2 边界不变）。
2. **`PAGE_NAV_MALFORMED` 是 client 本地码**：与 `PAGE_RESOURCE_MALFORMED` 同一性质——result 包装形状校验失败在 React 侧生成，不经 wire、不在 Core 错误码表；wire 错误面仍严格零新码（`INVALID_REQUEST`/`UNKNOWN` 复用）。
3. **切书/收起的重置语义**：`selectedBookId` 变化的 effect 首行 `setSelectedChapterId(null)`（切书必须清章节选择，防止旧书章节 id 在新书列表中悬空）；收起（null）分支同步清空 rows/busy/error。
4. **迟到回包守卫**：两个下钻 effect 沿用 region/history/resolve/image 循环同款计数+cancelled 守卫（`isCurrent()`），慢回包不污染后续选择。
5. **排序权威在 Core**：repository 既有 `list_chapters`/`list_pages` 已 ORDER BY sort_order，Core handler 透传不改排序；React 不重排（信任投影顺序）。
