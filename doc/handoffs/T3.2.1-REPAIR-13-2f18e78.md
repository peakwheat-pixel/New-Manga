### AC3 根因与修复原理（重要）

Build 3 的按钮不可读不是 token 值错误，而是**样式机制**：Windows 上 Qt Quick Controls
默认走原生 `windows` 样式，它忽略 `palette.button` 与 QML 对控件的 background 自定义
（stderr 大量 "The current style does not support customization of this control"），
但**遵守** `palette.buttonText`——于是系统浅色按钮底 + 浅色 `ink` 文字 = 白底白字。
修复把 buttonText 绑定到 F token 的反色文字 `ink-inv`（浅色表面上的深色文字语义），
不改动任何 token 值、不重做视觉系统；页面自身仍是 Tokens 驱动的 Graphite Atelier 深色表面。

曾尝试 `Qt.application.styleHints.colorScheme = Qt.Dark`（QML 可达，验证过属性可写），
但原生样式**不响应运行时/创建前 colorScheme 设置**（探针 `--scheme early` 实证按钮仍白底），
该方案已弃用并在 Main.qml 注释中留档。
