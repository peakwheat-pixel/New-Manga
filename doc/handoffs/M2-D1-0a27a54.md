## 关键结论摘要（供 Review 使用）

1. **Qt 导入期耦合 = 21 个模块**：`src/infrastructure/rendering/{font_catalog,pixel_source_style,qt_compositor,qt_layout}.py`、`src/bootstrap/app.py`、`src/ui/**` 16 个模块名；其余 **160/181 个 .py 在无 PySide6 环境导入成功**。
2. **Core 已 headless**：`domain` + `ports` + `application` 102 模块导入零 Qt；`application` 唯一 Qt 点是 `export/pdf_qt.py:19-20`（函数内惰性），且该适配器**在生产未接线**（`bootstrap/app.py:837` 未传 `pdf_composer`，缺它时 `application/export/service.py:412-415` 抛 `PdfUnavailableError`）。
3. **无 headless 入口**：`main()`（`bootstrap/app.py:1077`）无条件 `QGuiApplication`（`:1108`）并加载 QML（`:1125`、`:1046`）；仓库无第二入口/打包面（`E4` 零命中）。渲染栈另需**带字体库的平台插件**——4 份测试夹具明确记录 offscreen 平台不带字体库，入口测试禁止强制 offscreen。
4. **写者权威基本成立**：SQL 写只出现在 9 个文件（`sqlite/**` 8 个 + `providers/step_writes.py`）；`src/ui/**` **零 SQL**；bootstrap 只有 2 条 `SELECT`（`:466`、`:497`）。例外与未接线件（`open_readonly`、`SqliteBackupService`、`WebtoonTileCacheSweeper`、`any_in_transaction`/`release_current_thread_connection` 无生产调用点）已在报告 §2.5 与 M2D1-06 记录。
5. **可复用资产**：`imaging/streaming_png.py` + `webtoon_tiles.py`（纯 stdlib PNG 分块通路，零 Qt）；`ui/models/tasks/projection.py`（336 行）与 `ui/viewmodels/workbench/region_canvas.py`（97 行）本身 Qt-free，仅被包 `__init__` 的 Qt 重导出困住（P6 实测）。
6. **大二进制现状**：分块像素已走**文件 URI**（`reader/viewmodel.py:425`）；整页像素仍以 raw RGB32/PNG bytes 在进程内传递（`bootstrap/app.py:283-288` 等），跨语言 IPC 前必须按 AD-001 §33 另行 spike。
