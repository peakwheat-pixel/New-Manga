## 3. BookSummary 字段映射说明

冻结 DTO：`{book_id, title, original_title, is_favorite, is_archived, page_count, created_at, updated_at}`。

| DTO 字段 | Core 实际语义/来源 | 差异与映射说明 |
|---|---|---|
| `book_id` | `domain.books.entities.Book.book_id` | 同名直连映射 |
| `title` | `domain.books.entities.Book.title` | 同名直连映射 |
| `original_title` | `domain.books.entities.Book.original_title` | 同名直连映射 |
| `is_favorite` | `domain.books.entities.Book.is_favorite` | 同名直连映射（布尔类型） |
| `is_archived` | `domain.books.entities.Book.is_archived` | 同名直连映射（布尔类型） |
| `page_count` | 数据库 `chapters` + `pages` 关联聚合统计 | **差异**：Core 的 `Book` 实体中不直接持久化 `page_count`，页数属于章节。Core service 在执行 `ListBooks` 时，通过只读 SQL 聚合统计该书所有有效章节下已导入且未删除页面的数量；无页面或空章节时返回 `0`。不修改领域实体，不虚构字段。 |
| `created_at` | `domain.books.entities.Book.created_at` | 同名直连映射（ISO UTC 字符串） |
| `updated_at` | `domain.books.entities.Book.updated_at` | 同名直连映射（ISO UTC 字符串） |

安全红线遵守：
- `managed_original_ref`、本地路径、SQLite 内部主键未泄漏到 DTO 中。
