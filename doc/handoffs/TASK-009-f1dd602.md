## 交付内容与 AC 对照

- **AC1（多 Profile、能力/作用域解析、来源与快照）**：**满足**。`ProviderProfile`/`ProviderBinding` 支持同 Provider 多 Profile（AC-PROVIDER-001）；`ProviderBindingResolver` 按 任务临时 > 章节 > 作品 > 全局 解析能力默认绑定（AC-OCR-003/PROVIDER-002），无绑定时 `UnresolvedCapabilityError` 而非猜测（D06 §51）；`EffectiveSetting`/`BindingResolution` 携带来源标签（AC-SET-001）；`build_snapshot` 冻结解析结果，后续全局修改/Profile 改名不影响既有快照（AC-PROVIDER-003），`validate_snapshot` 对 missing/disabled 报 issue 要求用户重绑而非静默换 Provider（AC-PROVIDER-004，D06 §50）。
- **AC2（统一代理策略；代理失败默认禁直连；显式 fallback 可追踪）**：**满足**。`StdlibTransport.resolve_route` 统一 direct/system/http/https/socks5 + bypass（localhost 默认集为构造默认值）+ inherit_system + provider `proxy_policy`（inherit/profile/direct 经 `ProviderNetworkResolver`）；代理路径失败默认抛类型化异常且绝不重试直连（AC-NET-002），仅 `allow_proxy_failure_direct_fallback=true` 时一次 Direct 重试并返回可见 `FallbackEvent`（AC-NET-003，D06 §55）；`NetworkProfileService` 记录该开关变化。SOCKS5（RFC 1928/1929）、HTTP CONNECT 隧道、407→`ProxyAuthenticationError`、缺失 vault 项→`MissingCredentialError`（配置错误不参与 fallback，D06 §56.2）。
- **AC3（Secret 只进受保护 Store；无明文；TLS 默认开；分阶段诊断与数据提示）**：**满足**。Secret 全程 `SecretValue`（repr/str 恒 `<redacted secret>`、常数时间比较）；模型与契约只携带 `credential_ref`；`WindowsCredentialStore`（CredReadW/CredWriteW/CredDeleteW，UTF-16 blob）+ 契约测试对 InMemory 与真实 Windows vault 参数化执行；防泄漏扫描证明 v2 SQLite 字节与捕获日志无 Secret（AC-SEC-001/002/003）；新 Profile 默认 `verify_tls=True`，关闭需 `confirm_disable_tls=True` 否则 `DangerousSettingError`（AC-SEC-004/005，D07 §68）；`ConnectionTester` 分阶段 DNS/TCP/TLS/HTTP/Provider-Auth，类型化错误码、失败截断（AC-NET-004）；`describe_provider_data` 区分 Local/Remote 并按能力列数据类型（AC-PRIVACY，D07 §87~88）。

## 设计取舍（供 Review 关注）

1. **bypass 默认集语义**：`DEFAULT_BYPASS_HOSTS`（localhost/127.0.0.1/::1）是 `NetworkProfile` 构造器默认值而非 `is_bypassed` 内的隐藏叠加——测试与用户可显式清空；空 proxy 端点仅在 `inherit_system=true` 时合法（模型校验）。
2. **`MissingCredentialError` 不参与 direct fallback**：凭据缺失是配置错误（D06 §56.2 快速失败），重试直连只会掩盖问题。
3. **`_PROXY_FAILURE_TYPES` 含 DNS**：指解析 *代理主机名* 失败属代理路径故障，可按用户开关 fallback；解析目标主机失败不走 fallback（无代理参与）。
4. **Profile/Binding/NetworkProfile 持久化**：以 Store Protocol + InMemory 实现（测试 fake 同型）交付；SQLite adapter 需要后续切片（白名单未含 `src/infrastructure/sqlite/**`，该层归 TASK-029 既定边界），已在 verification 记 NOT_RUN。
5. **`SecretValue.__hash__`**：哈希 redaction 标记而非秘密本身，保证 secrets 入 set/dict 不引入时序侧信道。
6. **测试服务器**（tests/network/servers.py）：全部 127.0.0.1；TLS 用 openssl 自签证书（环境无 openssl 时 5 个 TLS 测试 skip 并如实记录）；`x-test-status` 头可注入 401/403 供 auth 阶段测试。
7. **`net_helpers` 改名**：pytest 无包结构下 `tests/network/helpers.py` 与 `tests/library/helpers.py` 同名冲突（TASK-008 同款问题），改名后全量收集通过。
