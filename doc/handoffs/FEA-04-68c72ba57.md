## VM 私有状态与第二真值审计

- CurrentFrontend 的 Instances/Active 弱引用与锁用于 Host 单例寻址和 ThemeStudio 当前 shell 路由，不保存业务数据。
- CurrentFrontend._regionDrafts 仅保存 DraftBuffer 对象；DraftBuffer 是 S1 指定的 ApplicationCore 权威。读写由 _draftGate 保护。丢弃时先从 registry 移除；DisposeAsync 的 flush callback 会检查注册身份，不会 flush 已丢弃 buffer。
- CurrentRunIntentCoordinator._pendingKey 是尚未 ACK 的 intent 状态；Run 查询不从它推导。IntentCoordinator 仅负责同 key 的 in-flight 协调。
- CurrentSessionMemento._knownRunIds 是最多 12 条的 UI Run 历史，线程安全快照；不是 Run snapshot/projection。
- RunStatusMonitor 的 _current/_subscription/_pollingEnabled 是 dispatcher adapter 生命周期和 polling preference；Dispose 仅释放订阅。
- StudioPage 的 _projection 是 RegionPageProjection（Host 页面与 regions 的显示投影），不是旧 _runProjection。Run projection 只从 Current RunMonitor 读取。
- StudioBatch 的 _stageColumns、Rows、cells、state/filter/highlight 是用户交互与投影显示树；Start intent、Run ID 与投影权威均在 Current 对象。
- Reader 的 _book、Pages、_pageIndex、image bytes 是本次 Host projection 的展示模型；跨重建锚点与布局状态在 CurrentReaderMemento，Core progress 是既有 Host 返回值。
- Console 的 formatted status text、RunStages、RunRows 是显示投影；snapshot/projection raw references 不再存于 ConsoleViewModel。Provider/network/backup forms 的临时编辑仍是既有设置表单，不属于本 Task 的 Run 真值。
- ShellState 的 _session 是 CurrentShellMemento 引用；workspace registries 是视图实例注册表。ThemeStudio service 仍是原来的主题 draft 权威；Current 只记 draft identity/name 并将 dirty draft 标成 unmapped。
