## Format_BGR888 复用口径（指令点名项）

任务指令要求"MOBI 光栅化复用 TASK-043 修好的 `Format_BGR888` 映射，不得另写一份"。**实际形态**：那条映射（`src/infrastructure/importing.py` 的 BGRA→`Format_ARGB32`、BGR→`Format_BGR888` 分支，TASK-043 F-1 修复）服务的是 **pdfium 裸位图缓冲**——字节序敏感的 `QImage(raw, w, h, stride, qformat)` 构造。MOBI 页面是 **JPEG/PNG/GIF/BMP 编码字节流**，适配器走 `QImage.loadFromData` 交给 Qt 图像插件自解码，随后与 PDF 路径共用同一 `image.save(PNG)` 出口——**全路径不存在第二份颜色映射，也无从复用 pdfium 特定的缓冲映射**（复用形态 = 共享端口语义 + 共享 PNG 编码出口；未写任何新映射）。若日后 MOBI 需走裸缓冲路径（如直接嵌入未压缩位图），该分支即唯一权威实现。

## 可替换性（AC ⑤：上游停更如何替换）

`mobi==0.4.1` 上游自 2016 年基本停更，且 Python 3.13 移除 stdlib `imghdr` 后需靠传递依赖 shim 兜底（本轮 warning 即实证）。隔离保证：**`mobi` 仅在 `MobiDocumentRaster` 适配器方法内 lazy import**，application 层不见其类型；端口面为 `DocumentRaster/DocumentHandle/RenderedDocumentPage`。替换路径：新写一个 `MobiDocumentRaster` 实现（如换 KindleUnpack 直调或自研 PDB 解析），在 `src/bootstrap/app.py` 装配处换实例即可，用例层与测试的合成容器断言不变。
