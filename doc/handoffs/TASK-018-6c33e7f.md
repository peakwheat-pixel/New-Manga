## Router / fallback / 资源建议（AC-3，供 TASK-019）

1. 默认应为**无关模型的确定性基线**（本环境唯一可运行、可重复、零违规的路线）。
2. 建议第一个 Router 判据是"Mask 内背景是否纯色"——白底样例证明纯色时常量填充足够。
3. "Mask 是否与已知结构（面板框、长直线）相交"应作为**升级到学习型路线的必要条件**；结构穿越样例是基线表现最差的一类。
4. fallback 链建议 `学习型 → 结构化基线 → Simple Fill`，且**不可用时必须留下 `BLOCKED`，不得静默降级后声称已修复**。
5. 基线实测资源上限：**CPU ≤ 46 ms/320×320、峰值 RSS ≤ 58 MB**；**学习型路线的资源数字在本环境完全未测，不得写入任何数值**。
