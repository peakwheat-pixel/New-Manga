## 设计取舍（Review 关注点）

1. **save 桥接 = `SqliteSnapshotProvider(conn, **kwargs)`**：构造即写（有值分支 set_defaults）。两个 provider 实例（装配内一个 + 桥接每次一个）共指同一行同一 conn，写入语义一致；未造第二持久化实现。
2. **RMW 非事务**：save 是 read-modify-write，跨调用者不原子；单用户桌面 + 单写线程（TASK-048）下交错有界，docstring 已声明。
3. **fallback 列表不深校验**：形状校验只要求主 provider 存在，`fallback` 键内容留给运行期链读取器（保存期拒绝过度会锁死合法拓扑）。
4. **known_steps 取自 handler 表**：application 层不 import infrastructure（分层守卫），由装配处注入集合——单一事实源仍是 handler 注册表。
5. **无配置时传 None 而非空 mapping**：保持 `__init__` DO NOTHING 分支，未配置安装连 `updated_at` 都不touching，逐字节一致。
6. **AC③ 用库里的 `RERENDER_SINGLE`（页级）做 AC① 快照断言**：rerender 链无 ocr、不触发 detect（TASK-049 收窄语义），快照断言与步骤执行解耦。
