## 关键技术点

1. **单遍游标**：PNG 的 Up/Sub/Average/Paeth 行滤波依赖前一行重构结果 → 读取必然顺序。游标只前进；越界回跳请求（缓存清空后向上滚动）触发 `rewind()` + 单次重扫（成本在 Handoff 记录，正确性优先）。生产视口访问模式（TASK-038 `requestTiles` 单调下滚 + tile 文件持久缓存）使全页只需一次顺序扫描。
2. **过滤器实现**：Sub = 按 bpp 分组的 C 级前缀accumulate（`itertools.accumulate`）；Up = 逐字节模 256 加（`map`+`zip`）；Average/Paeth 逐字节循环（正确性优先——真实编码器的自适应过滤路径，性能实测见下）。
3. **IDAT 流**：多 IDAT chunk 顺序喂同一个 `zlib.decompressobj`，`decompress(data, max_length)` 限制解压输出量 → 待解缓冲不膨胀。
4. **fail-closed 矩阵（AC ③）**：非 PNG/INTERLACED/UNSUPPORTED_BIT_DEPTH(≠8)/PALETTED(IHDR 或 PLTE)/TRUNCATED 一律 typed 拒绝——**不静默降级**为整图或空图（Qt 路径已整体移除，不存在"兜底"）。
5. **AC ④ 回退路径**：未注入 `tile_factory` 时 ReaderViewModel 走整图路径——TASK-020/038 既有测试原样通过（见回归表），行为不变。
