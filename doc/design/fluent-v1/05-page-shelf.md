# 05 书架页规格（Library）

**页 ID**：`SpaceId.Library`（与 C-02 §6.1 一致，不得新增空间）
**参考**：方案 §15.3（阅读持久化字段）、Current 书架基线（`V2ShellUiTests`/书架 ViewModel 行为，作为不退化基线）

---

## 1. 布局（Medium 断点）

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶部命令条：空间 1/2/3 · 书架 · 搜索/命令 · 窗口控制                     │
├────────┬───────────────────────────────┬────────────────────────────┤
│ 左导航 │ 书籍网格/列表（主区，可滚动）     │ 章节 + 页面缩略图（详情栏 320）│
│ 72/240 │                               │                            │
├────────┴───────────────────────────────┴────────────────────────────┤
│ 状态条：书数/章数 · Host 状态 · 扫描中 · 错误入口                       │
└──────────────────────────────────────────────────────────────────────┘
```

- 左导航项：书架（当前）、回收站、导入；折叠时仅图标 + Tooltip。
- 主区视图切换：网格（默认，封面卡）/ 列表（紧凑行）；切换状态属 UI memento。
- 详情栏：选中书籍时显示章节列表；选中章节时显示页面缩略图条（横向滚动）。

## 2. 组件与令牌

| 组件 | 令牌 |
|---|---|
| 封面卡 | `Nm.Corner.Fluent.Md`、`Nm.Elevation.1`（hover 提升至 2）、`Nm.Color.Bg.Raised` |
| 多选态封面 | 2px `Nm.Color.Accent.*` 边框 + 角标 |
| 列表行 | `Nm.Corner.Fluent.Sm`、行高 `Nm.Size.RowNormal`（26）/`Nm.Size.RowDense`（24），由 `Density` 决定 |
| 详情栏 | `Nm.Color.Bg.Sunken`、`Nm.Corner.Fluent.Lg` |
| 缩略图条 | `Nm.Corner.Fluent.Sm`、选中 2px 强调边框 |
| 状态徽标 | `Nm.Color.Status.*` 语义色 + 图标（非仅颜色） |

## 3. 状态（AC1 必须齐全）

| 状态 | 触发 | 表现 |
|---|---|---|
| **空（首次）** | 无任何书籍 | 居中空态：图标 + 「导入你的第一本漫画」+ 主按钮「导入文件/文件夹」；Esc 不关闭 |
| **空（筛选后）** | 有书但筛选/搜索无结果 | 保留筛选条 + 「清除筛选」按钮；不显示导入按钮 |
| **载入** | 首次加载列表 | 骨架屏（6 个封面卡占位，`Skeleton` 既有组件）；状态条显示「正在读取书架…」 |
| **错误** | Host 返回错误 | 错误卡（图标 + 原因 + 「重试」+ 「打开控制台」）；不隐藏筛选与导航 |
| **满** | 有书 | 网格/列表正常；状态条显示统计 |
| **部分/扫描中** | 正在扫描目录或导入 | 顶部细进度条 + 状态条「扫描中 12/40」；已就绪的书可正常操作 |
| **只读/旧壳运行** | Host 只读 | 顶部警示条「当前为只读：旧壳仍在运行」；导入/删除按钮禁用并给原因 Tooltip |

## 4. 交互

- 单击选中（单选）；`Ctrl` 单击多选；`Shift` 区间多选；双击/`Enter` 打开（作品→章节列表；章节→阅读器）。
- 右键菜单：打开、导入到章节、重命名、回收站（软删）、在资源管理器中打开（若允许）。
- 拖拽导入：文件/文件夹拖入章节 → 预览确认（导入数量/目标章节）→ 确认后入队。
- 回收站入口：左导航；回收站内支持还原与显式彻底删除（彻底删除须走 ADJ-001 披露 + 专门确认，应用内永不删除原文件）。

## 5. 响应式

| 断点 | 行为 |
|---|---|
| Compact | 单列；详情栏变抽屉（点击书籍打开） |
| Medium | 双栏（主区 + 详情 320） |
| Expanded/Wide | 三栏（左导航 240 + 主区 + 详情 360）；主区网格列数自适应（最小卡宽 160） |

## 6. a11y 与键盘

- Tab 序：左导航 → 书籍网格 → 章节列表 → 缩略图条 → 详情操作区 → 状态条。
- `J`/`K` 上下移动对象；`Enter` 打开；`Space` 切换多选；`Esc` 清除多选（有浮层时先关浮层）。
- 书籍卡 `AutomationProperties.Name` = 「书名 · 章节数 · 最近阅读页」。
- 空态主按钮自动聚焦（首次进入且无书时）。

## 7. 数据与真值（不引入本地业务真值）

- 书籍/章节/页面/进度全部来自 Host 读接口；书架页不得缓存为业务权威（列表可缓存为 UI 投影，但以 Host 刷新为准）。
- 最近阅读进度读 `reading_progress` 既有字段（C-05 / FEA-14-READ 前不新增 normalized anchor 字段）。
