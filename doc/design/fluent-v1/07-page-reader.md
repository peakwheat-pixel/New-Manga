# 07 阅读器页规格（Reader）

**页 ID**：`SpaceId.Library` 内的 `ShellSurface.ReaderOverlay`（C-02 §6.1，不得新增 surface）
**参考**：方案 §15.3（`ReaderOverlayViewModel` book/pages/index/mode/direction/scroll 迁出）、Current 阅读器基线（`V2ReadingProgressTests` 等为不退化基线）

---

## 1. 布局（全屏浮层 + 顶部/底部条）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部信息条：返回 · 作品/章节 · 页码 · 模式 · 方向 · 缩放        │ 高 `Nm.Size.ControlHeight`（自动隐藏）
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                    页面视图（单页 / 滚动 / 双页）              │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 底部进度条：进度 · 缩略图跳转 · 快速跳页 · 设置                 │ 高 `Nm.Size.ControlHeight`（自动隐藏）
└──────────────────────────────────────────────────────────────┘
```

- 阅读器是浮层（`ShellSurface.ReaderOverlay`），不改变 `SpaceId`；退出回到书架原位置。
- 顶部/底部条自动隐藏（移动鼠标/触摸后 2s 淡出，`reduce` 下直接切换）；点击页面中部切换显示。
- 浮动工具条（缩放/方向/全屏）在右侧，`Elevation.2`，`reduce` 下无动画。

## 2. 组件与令牌

| 组件 | 令牌 |
|---|---|
| 页面图像 | `Nm.Corner.None`；背景 `Nm.Color.Bg.Sunken` |
| 页面容器 | 无圆角；阴影仅浮动条用 `Elevation.2` |
| 浮动工具条 | `Nm.Corner.Fluent.Md`、`Elevation.2`、`Nm.Material.Acrylic.*`（可用时） |
| 进度条 | `Nm.Color.Accent.*` 填充 + `Nm.Color.Bg.Sunken` 轨道 |
| 页码徽标 | `Nm.Corner.Fluent.Sm`、半透明背景（`Nm.Material.Acrylic.Opacity`） |
| 缩略图条 | `Nm.Corner.Fluent.Sm`；当前页 2px 强调边框 |

## 3. 状态（AC1 必须齐全）

| 状态 | 触发 | 表现 |
|---|---|---|
| **空（无页面）** | 章节无页 | 居中空态：「本章节暂无页面」+ 返回按钮 |
| **载入** | 首次打开/翻页 | 页面骨架占位（保持上一页可见直到新页就绪）；进度环 |
| **错误** | 图片读取失败 | 错误占位（原因 + 「重试」+ 「返回书架」）；不自动跳过 |
| **满** | 正常阅读 | 页面按模式显示；顶部/底部条自动隐藏 |
| **部分/缺页** | 部分页缺失（referenced source 未就绪） | 缺页占位（「页面未就绪」+ 可重试）；其余页可正常翻 |
| **只读/源文件不可用** | referenced 源被移动/删除 | 顶部警示条 + 缺页占位；不写进度到不可用页 |

## 4. 交互

- 翻页：`←`/`→`（单页）、`PgUp`/`PgDn`、滚轮（滚动模式）、点击左右区域（单页）。
- 缩放：`+`/`-`/`0` 复位；`Ctrl+滚轮` 缩放。
- 全屏：`F` 或按钮；`Esc` 退出全屏（若在浮层内先关浮层）。
- 方向：单页/双页（横排/纵排）通过顶部条切换；状态存 UI memento（S4）。
- 进度：滚动/翻页后写 `reading_progress`（既有 Core 既有命令；不新增字段）；写失败提示但不阻塞阅读。

## 5. 响应式

| 断点 | 行为 |
|---|---|
| Narrow（<1024） | 单页；顶部/底部条覆盖式；缩略图条垂直（右侧抽屉） |
| Medium（1024–1279） | 单页；缩略图条横向底部 |
| Compact/Full（≥1280） | 单页或双页；缩略图条横向；浮动工具条常显（可隐藏） |

## 6. a11y 与键盘

- Tab 序：返回 → 页面视图 → 翻页按钮 → 浮动工具条 → 底部进度 → 顶部信息条（隐藏时不在 Tab 序）。
- 页面图像 `AutomationProperties.Name` = 「第 N 页，共 M 页」；进度 `Name` 含百分比。
- 方向/模式切换按钮有 `Name` + 当前状态（`ToggleButton` 的 `IsChecked` 需有语义标签）。
- 高对比：页面图不调整（图像内容），但控件条用高对比颜色；焦点环 3px。

## 7. 数据与真值

- 页面/进度来自 Host/Core；阅读器不缓存业务真值（展示模型可缓存图片字节）。
- 跨会话锚点：`pageId` + 语义锚点（FEA-01 冻结字段）优先于 index；无法无损映射 → 保留旧状态并报告（FEA-04 S4 语义）。
- 第二窗口只读模式共享同一 Run/进度读源，不双写。
