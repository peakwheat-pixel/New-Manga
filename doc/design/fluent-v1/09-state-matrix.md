# 09 状态矩阵（四页汇总）

**用途**：AC1 的机械核对表——四页 × 状态；每格给出「表现 + 恢复路径」。四页正文（05–08）为详细描述，本表为一致性检查。
**规则**：任何状态都不得清空导航/隐藏可恢复操作；错误态必须给「重试/返回」；未保存编辑态必须 fail-closed（不静默丢弃）。

| 状态 | 书架（05） | 工作台（06） | 阅读器（07） | 设置（08） |
|---|---|---|---|---|
| **空** | 首次空态 + 导入主按钮 | 未选章节空态 → 跳书架；批量无 Run → 「开始处理」 | 「本章节暂无页面」+ 返回 | 防御空态 + 重试（正常不出现） |
| **空（筛选后）** | 保留筛选 + 「清除筛选」 | 批量筛选无结果 → 保留 chips + 清空选择 | — | 搜索无结果 → 显示「无匹配」+ 清空搜索 |
| **载入** | 6 封面骨架 + 「正在读取书架…」 | 画布/检查器骨架 + 「读取中」 | 上一页保留 + 进度环 | 卡片骨架；分组列表先显示 |
| **错误** | 错误卡 + 重试 + 控制台入口 | 错误卡 + 重试；画布保留上一帧 | 错误占位 + 重试 + 返回 | 顶部错误条 + 重试；保存失败保留输入 |
| **满** | 网格/列表 + 统计 | 画布+检查器+操作条；未保存圆点 | 正常阅读；条自动隐藏 | 全分组可编辑 |
| **部分/未决** | 扫描中进度条；已就绪项可用 | 未决确认模态（保存/丢弃/取消）；flush 失败留旧 UI | 缺页占位；其余页可翻 | 字段禁用 + 原因 Tooltip（Fluent 材质在 Current 下） |
| **冲突** | — | 冲突条（文本/锁/binding）+ 查看对照；应用禁用；不自动合并 | — | — |
| **只读** | 顶部警示；导入/删除禁用 | 检查器禁用 + 转移入口 | 只读警示（源不可用） | 保存禁用；可浏览 |
| **运行中** | 扫描/导入进度 | Run 投影条 + 控制（暂停/停止/重试）；intent key 复用 | 进度写回中（不阻塞） | — |

## 正交通道检查

- 所有「空/错误」态都保留顶部命令条与左导航（可离开）。
- 所有「只读/冲突」态都有可见原因与恢复动作。
- 所有「未决/未保存」态都不自动执行、不重放旧回调。
- 所有状态切换有动效时符合 `02-motion.md` 三类降级规则（`reduce` 下 0ms/纯色）。
