# 04 布局与响应式基线（Fluent v1）

**范围**：四页共用的窗口骨架、断点、分栏折叠、双屏/拔屏、DPI 缩放规则。
**上游**：方案 §15.3（多窗口草稿）、C-02 V-05（Fluent 例外）、C-05（页可见性）。

---

## 1. 窗口骨架（四页共用）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部命令条（TopBand）：空间切换 1/2/3 · 标题 · 搜索/命令 · 窗口控制 │  高 48
├──────────────┬───────────────────────────────────────────────┤
│ 左导航 rail  │ 主内容区（页面按 05–08 规格）                    │
│ 宽 72 / 240  │                                               │
├──────────────┴───────────────────────────────────────────────┤
│ 状态条（StatusBand）：Host 状态 · Run 状态 · 进度 · 错误入口     │  高 28
└──────────────────────────────────────────────────────────────┘
```

- 顶部命令条与状态条在四页**恒定**；左导航可折叠（宽度 72 ↔ 240）。
- 主内容区四页各自定义（05–08）。
- 全部尺寸用 `Nm.Space.*` 令牌（48/28/72/240 为布局常量，须在实现中引用令牌或 `LayoutProfile` 值，不得散落裸数）。

## 2. 响应式断点（窗口宽度）

| 断点 | 宽度 | 行为 |
|---|---|---|
| `Compact` | 720–1023 | 左导航折叠为 72；主内容单栏；检查器/详情改为抽屉（`Elevation.2`） |
| `Medium` | 1024–1439 | 左导航 72；主内容双栏（列表 + 内容）；检查器固定右栏 320 |
| `Expanded` | 1440–1919 | 左导航 240；主内容三栏（列表 + 画布 + 检查器 360） |
| `Wide` | ≥1920 | 同 Expanded，画布区最大宽 1600 居中，两侧留白 |

最小窗口：720×600（低于则提示并禁止继续缩小；布局不裁切可操作控件）。

## 3. 分栏折叠

- 折叠单位为「左导航」「检查器/详情」两栏；折叠后由顶部命令条按钮恢复，快捷键不新增（通过命令面板）。
- 折叠状态属于 UI memento（跨页面保留）；不写入业务数据。
- 折叠不得导致主内容区宽度 < 480。

## 4. 双屏 / 拔屏

- 第二窗口只承载**只读或独立会话**内容（阅读器视图 / 主题预览）；不复制主窗口的可编辑画布（避免双写）。
- 同一 `(SessionId, RegionId)` 草稿仍由主窗口单一 owner 写入（FEA-03 语义）；第二窗口只读，切换/编辑需转移（`CurrentFrontend` 语义）。
- 拔屏（显示器移除）：第二窗口内容关闭并回到主窗口对应页面；未 flush 的编辑态按 fail-closed 保留在主窗口缓冲，不丢。

## 5. DPI 缩放

- 支持 100% / 125% / 150% / 200%；所有尺寸按逻辑像素计算，由 Avalonia 缩放。
- 200% 下：左导航强制折叠为 72；检查器改为抽屉；顶部条保持单行（超出用省略号 + Tooltip）。
- 图标与文字在缩放切换后不得重叠；最小可点击区域 32×32 逻辑像素（触摸友好）。

## 6. 层级（z-order）

| 层 | 内容 | 令牌 |
|---|---|---|
| 0 | 页面背景（材质/表面） | `Nm.Material.*` / `Nm.Surface.*` |
| 1 | 主内容 | — |
| 2 | 左导航 / 检查器 | `Elevation.1` |
| 3 | 浮层（抽屉/命令面板） | `Elevation.2` |
| 4 | 模态对话框 + 遮罩 | `Elevation.3` |
| 5 | Tooltip / 通知条 | `Elevation.3` + 置顶 |

## 7. 评审检查点

- [ ] 四页都使用 §1 骨架（顶部条 + 左导航 + 状态条恒定）。
- [ ] 四个断点行为可机械核对（§2 表）。
- [ ] 折叠不导致主内容 < 480；折叠状态属 memento。
- [ ] 双屏只读/独立会话，不双写草稿。
- [ ] 200% DPI 下无裁切/重叠；最小点击区域 32×32。
- [ ] z-order 与令牌对应符合 §6。
