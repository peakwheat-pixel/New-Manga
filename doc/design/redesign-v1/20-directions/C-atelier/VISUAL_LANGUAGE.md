# 方向 C · 工坊 Atelier —— 视觉语言

> 令牌唯一源：`tokens.json`（DTCG）。CSS 唯一源：`styles.css` 的 `:root`。本文件解释"为什么"，数值一律以两文件为准。
> 已实现页面：`index.html`（原型）、`spec.html`（规范页）。

## 1. 一句话视觉主张

**印刷工坊的生产调度台**：不做卡片、不做浮层、不做装饰。整个界面由 3 级明度、1px 细线、7 个状态符号和一套等宽数字构成；彩色只允许出现在状态上。

## 2. 三级明度替代阴影

| 层级 | 变量 | 深色 | 用途 |
|---|---|---|---|
| sunken | `--bg-sunken` | `#101314` | 表格头、门禁条、Run 带、画布外底、输入底 |
| shell | `--bg-shell` | `#15181A` | 应用底座、抽屉罩、滚动条 |
| panel | `--bg-panel` | `#1B1F21` | 资源树、工作面、抽屉、命令面板 |
| raised | `--bg-raised` | `#232829` | hover、选中行、按钮底 |
| edge | `--bg-edge` | `#2C3234` | 选中/当前块、进度槽、批量条 |

**没有阴影**（`elevation.none`），层级只靠上述明度差 + `--line-hair / --line-default / --line-grid` 三级 1px 线。抽屉、命令面板、对话框同样只用 1px 边线，避免"浮起来"的观感。

## 3. 状态色：唯一允许的彩色

七种矩阵状态 + 门禁态，每格都由**色相 + 明度 + 形状**三重编码（详见 `spec.html` §01）：

| 状态键 | 符号 | 深色色值 | 语义 |
|---|---|---|---|
| `completed` | ● 实心圆 | `#4C9A6A` 绿 | 结果有效、可导出 |
| `not_started` | ○ 空心圆 | `#6B7377` 灰 | 从未执行 |
| `running` | ◐ 半实心（呼吸 1600ms） | `#2F9EA8` 青 | 正在执行，唯一允许的循环动效 |
| `stale` | ▨ 斜纹方块 | `#8A7BA8` 紫 | 曾成功、上游变更后过期 |
| `failed` | ✗ 叉 | `#C0503F` 红 | 执行失败，必须带错误码 |
| `skipped` | – 短横 | `#555C5E` 深灰 | 跳过 / 不适用，必须可查原因 |
| `pending` | · 小点 | `#8C9593` 浅灰 | 等待上游 |
| `blocked`（门禁） | 门禁段琥珀 | `#C08A2E` | 可继续但产物不完整 |

硬约束：`stale ≠ not_started`（形态必须不同）；`failed` 不得只靠红色；`skipped` 不得无原因。
强调色 `--accent-base #3E9E8F` **只**用于焦点环、当前阶段指针、选中集合 1px 描边，全屏占比 < 2%。

## 4. 字体与数字

- UI：`Segoe UI Variable Text` → `Microsoft YaHei UI` → `Noto Sans SC`。
- 数据：`Cascadia Mono` + `font-variant-numeric: tabular-nums`，开启 `"tnum" 1`。页码、百分比、计数、耗时、Revision、Region 数**一律**走数据字体并右对齐。
- 6 档字号：10 / 11 / 12 / 13 / 15 / 20，相邻差 ≥1px。`20px` 仅用于危险确认标题。
- 大写阶段名与面板标题加 `letter-spacing: 0.06em`（`--ls-tracked`），中文正文不加字距。
- 数字永远带**分母**（`18/23 页`），不单独给百分比。

## 5. 空间与尺寸刻度

间距只取 4 / 6 / 8 / 12 / 16 / 24（`--sp-1…6`）。行高三档：矩阵 22、表 26、常规 30。矩阵单元 18×18 冻结。
关键布局常量：阶段轨道 58（40 Tab + 18 门禁）、资源树 200、矩阵 496（视口 ≤1439 降 420）、抽屉 360、状态面板 420、命令面板 560、Run 带 24、批量条 40、Run 面板 268。

## 6. 圆角与线宽

圆角只有 0 与 2px 两档（`--r-0/--r-1`），禁止 >2px。线宽只有 1px；2px 仅用于"选中 + 焦点"叠加时的双线标记与当前项的左侧标记条。

## 7. 标尺与裁切标记（真实功能）

允许的边缘装饰只有两种，因为它们对应真实几何：

- `.safe`：安全区内缩 6%，是 Region 越界检测的基准（DETECT 报"越界 2"即越此线）。
- `.trim` + `.trim i`：四角裁切标记，对应成品导出边界（出血 0）。

它们随页面图缩放同步，不得作为纯装饰贴在大屏上。

## 8. 抽象页图（禁止真实素材）

所有页面预览都由 `.art` 用 CSS 自绘：`panel-line`（分格线）、`tone`（网点，内联 SVG 点阵而非渐变）、`txt`（原图文字块）、`rgn`（Region 框）、`mask`（修复 Mask 斜纹）、`is-clean`（修复后文字被抹除）。任何真实漫画图、插图、emoji 都禁止。

## 9. 图标

内联 SVG symbol，20×20 网格，线宽 1.5px，`stroke-linecap: square`，无圆角端点。三档尺寸 12/16/20（默认 16）。共 33 枚（`index.html` 的 sprite），规范页展示其中 15 枚。图标默认 `currentColor`，仅当前项可用 accent。

## 10. 反模式（红线）

渐变 / 玻璃拟态 / 圆角 >2px / 装饰性阴影 / emoji / 彩色图标（除状态色）/ 卡片堆叠 / 纯展示大屏。矩阵必须可点击、可框选、可下钻——只读即判不合格。

## 11. 最小修补记录（实现者补充，已写在 styles.css §25）

1. `.ip-canvas .art { width:100%; height:auto }`：原 `height:100%` 会让 2:3 页面横向溢出面板被裁成切片。
2. `.vf-page.is-stack` + `.vf-chk*`：VERIFY 左栏补"页图 → 页切换条 → Region 检查清单"，消除 1fr 空洞。
3. `.st-item .tt/.dd { display:block }`：状态面板标题与描述原为同行内联而挤在一行。
