# 方向 C · 工坊 Atelier —— 核心流程走查

> 对应 `10-ux/12_USER_JOURNEYS.md` 的 J1/J2/J4/J5/J6/J7。每条给出：入口 → 操作序列 → 状态可见性 → 失败回退。
> 数据口径固定为 `00_SAMPLE_DATA`：批次 B-012 / 第12话 23 页 / Run #R-8831。

## J1 首次导入与自动流水线（空态 → 运行中）

1. 空工作区（状态 01）：面板给出数据根 `D:\NewManga\library`、缓存路径与「导入文件夹 / 导入文件」，无插画占位。
2. 拖入文件夹 → 对话框「识别到 23 页，作为第 12 话导入？」带 `.import-list`，逐文件显示状态与总进度（状态 02）。
3. 导入完成 21/23，2 个失败（`021.CR2` 格式不支持、`022.jpg` 重复页）→（状态 03）「重试失败项 / 跳过继续」。
4. 跳过继续 → 自动进入 DETECT，Run #R-8831 出现在 Run 状态带与队列；门禁段 DETECT 开始爬升。
5. 用户停留在矩阵观察全批推进（不必进任何"页面"），失败单元即时变 ✗。

## J2 批量异常处置（本方向的杀招）

1. 概览条显示「失败 12」→ 点击 → 矩阵非失败行降到 35%，右侧出现筛选 chip。
2. 从 018 行 TRAN 拖到 019 行 INP，框选 2 个失败单元（`.marquee` 矩形 + accent 描边）→ 底部出现批量条：「选中 2 单元 · 作用域 2 页 × 2 阶段」。
3. `Ctrl+Shift+R` 或「重试失败」→ 提示「已提交重试 2 个 failed 单元 · 新 Run #R-8832 · 预计 1m10s」；矩阵对应单元变 ◐。
4. 若选中里混入非 failed 单元，动作会明确回报「选中的 N 个单元里没有 failed 单元（重试只作用于 failed）」，不静默忽略。
5. 批量推进用 `Ctrl+Enter`：跳过已完成/已锁定单元并给出原因（不覆盖 Lock）。

## J4 校对与确认（VERIFY 工作面）

1. `3` 进入 VERIFY：左栏页图（007.jpg）+ 页切换条 + Region 检查清单（6 条），右栏为 原文 / 机译 / 人工译 三列对照。
2. 光标默认落在第一条待确认（Region 3「三日後の朝」，虚线框 + pending 点）；`Enter` 确认并下一条，`E` 编辑译文，`O` 编辑原文。
3. 术语冲突就地提示：「第 008 页 Region 2 把『車掌』译为『乘务员』，与术语表『列车长』冲突 · 1 条」，`.vf-callout` 用琥珀左边线。
4. `Ctrl+Enter` 确认本页 → 提示「已确认第 007 页 6 个 Region（2 条待确认 → confirmed）」，矩阵 REV 列由 · 变 ●。
5. 单条确认不修改其他页状态；批量确认必须在对话框里显示影响面（状态 11）。

## J5 图像修复（INPAINT 工作面）

1. `4` 进入 INPAINT：原图 / 修复后双栏同尺寸对比，右栏叠加 Mask 斜纹；右侧 Region 列表给出几何百分比与状态。
2. 019 页 `inpaint` 失败（`ModelLoadError`，`anime_lama_v2` 权重缺失）→ 面板底部 `.ip-err` 就地说明并给「安装模型」。
3. 换路线：工具条「换路线」→ 提示 `anime_lama_v2 → BrushNet`（仅影响彩色背景 Region）；重修复后 Mask 仍可见但状态转 ●。
4. 修复轨失败必须在矩阵 INP 列单独可定位（不影响 TRAN 列的 ●）——四轨不一致是本产品必须表达的事实。

## J6 单气泡精修（下钻 → 抽屉 → 四轨）

1. 双击 007 页Region 或矩阵单元 → 360px 抽屉：单元事实（页/阶段/状态/错误码/重试次数/Provider/耗时/Revision/Lock）。
2. 四轨完成度条：原图轨 completed / 文本轨 running / 修复轨 completed / 排版轨 stale —— 一眼看出"译文有了但成品过期"。
3. Region 表与 Revision 时间线（r5 人工改译 → r4 pipeline 覆盖 → r3 字号 +1 → r2 inpaint → r1 OCR）。
4. 底部动作：重试该阶段 / 推进 / 跳过 / 换 Provider / 日志；`Esc` 关闭且矩阵选中不变。

## J7 中断恢复（三选一）

1. 队列横幅：`R-8827 interrupted · 异常退出 · 已完成 7/20 页`，右侧「继续 / 放弃」。
2. 点「继续」→ 对话框三选一：继续（剩余 13 页，不重跑已完成）/ 重新开始（清空中间产物全量重跑）/ 放弃（标记 cancelled，已成果保留）。
3. 危险动作（重新开始）用 `.kicker` 红标 + impact 表列出影响面与不可逆性，`Esc` 可退。
4. 恢复后 Run 状态带从 37% 继续，矩阵对应列从 ·/✗ 回到 ◐。

## 贯穿：动作 → 反馈（状态转换可见性）

| 动作 | 立即反馈 | 完成反馈 |
|---|---|---|
| 任何批量动作 | 底部提示条（accent 外框）+ 作用域计数 | 结果摘要（成功/失败/跳过） |
| 上游变更致下游 stale | 矩阵行 derived 变 紫 ▨，事件列写明「render 过期 ← p019 geometry」 | 提供「重跑过期项」 |
| 暂停 | 「将在当前步骤（translate）安全结束后生效」 | 状态带变 paused，◐ 停止呼吸 |
| 停止 | 危险确认列出未处理 5 页 | 「18 页成果保留 · 剩余 5 页等待重新排队」 |
| 筛选/选中 | 矩阵即时重绘，`√已选 N` 摘要更新 | — |

## 不做什么

- 不用 Toast 报告可恢复错误（就地标记 + 汇总入口），Toast 只用于"操作已完成"。
- 不静默重试任何乐观锁冲突（`INPUT_REVISION_CHANGED` 必须让用户选刷新/覆盖）。
- 不在没有分母的情况下显示百分比。
