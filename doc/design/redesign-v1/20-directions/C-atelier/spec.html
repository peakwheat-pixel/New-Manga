01状态色系统 · 色相 + 明度 + 符号三重编码

状态色是本方向唯一允许的彩色。四组色相：绿（结果有效）/ 青（进行中）/ 紫（过期）/ 红（失败）； 琥珀与灰阶分别承担「门禁未通过」与「未开始 / 等待 / 跳过」。颜色永远不单独承担语义： 每个单元同时给出形状（实心 / 空心 / 半实心 / 斜纹 / 叉 / 短横 / 点）、 明度（同一色相内 saturated → 半透明阶梯）与文字键（在抽屉与图例中给出枚举名）。 任意两者失效时仍可判定。

禁止组合
stale ≠ not_started
过期必须是独立形态（斜纹 + 紫），不得用空心圆；否则用户无法区分"没跑过"和"跑过但过期"。
failed ≠ 仅红色
失败必须带叉形与错误码；色盲与灰度打印下仍可判定。
skipped ≠ 无原因
短横必须可下钻到跳过原因（Lock / 策略 / 无目标）。
accent ≠ 状态
强调色（青绿）只用于焦点环、当前阶段指针、选中集合描边；不得用于状态填充。
门禁态（blocked）
--st-blocked

琥珀 · 门禁未通过 / 低置信警告 / 需要人工介入。与 failed 的区别是"可继续但产物不完整"。

强调态（accent）
--accent-base

青绿 · 焦点 / 当前项 / 选中集合。全屏占比目标 < 2%。

三级明度层级

sunken / panel / raised 三级明度 + 1px 边线替代阴影。本方向禁用一切阴影与渐变。

04标尺与裁切标记 · 真实功能而非装饰

允许且仅允许两种"边缘装饰"，因为它们对应真实几何：.safe = 安全区（Region 越界检测基准，页面内缩 6%）， .trim = 四角裁切标记（成品裁切边界与出血检查）。二者都画在页面图容器内、使用绝对百分比定位，随缩放同步，不可作为纯装饰贴在大屏上。

.safe安全区内缩 6%；Region 越出即触发 DETECT 越界提示（示例：2 页 / 3 Region）
.trim四角裁切标记；成品导出按此边界裁切，出血 0
.rgnRegion 覆盖框：绿 = 对白，琥珀 = 拟声，青 = 旁白，紫 = 注释；虚线 = needs_review
.mask修复轨 Mask 覆盖（斜纹填充）；修复后页面用 .is-clean 隐藏文字块

08反模式清单（评审红线）

渐变
不允许 linear/radial-gradient；深浅一律用 solid + 透明度。斜纹用内联 SVG pattern（stale）。
玻璃拟态
不允许 backdrop-filter / 半透明叠加层；层级靠 sunken→panel→raised 三级明度。
圆角 > 2px
所有控件 0 或 2px；胶囊形仅用于 kbd / tag 等微元素，且不得做成圆角卡片。
装饰性阴影
elevation 恒为 none；抽屉与命令面板只靠 1px 边线 + 明度区分。
emoji
禁止。所有语义用 20×20 内联 SVG 或状态符号。
彩色图标
除状态色外图标一律 currentColor；accent 仅当前项。
卡片堆叠
不做卡片流。信息用表格 / 矩阵 / 分段 + 1px 分隔线组织。
纯展示大屏
矩阵必须可操作（选中 / 框选 / 下钻 / 批量动作）；任何数字都要能点进去。
