# 方向 C · 工坊 Atelier —— 信息架构

## 1. 主张

产品的瓶颈不是某一页，而是**一条流水线上哪里卡住了**。因此导航不按"页面/章节"组织，而按**流水线阶段**组织；主工作对象是「任务批次 + Page×Stage 状态单元」，不是画布，也不是文本行。

## 2. 三层结构

```
阶段轨道（6 个工作面，顶栏，40px + 18px 门禁条）
├── 资源树 200px：作品 / 章节 / 批次 / 队列
├── Page×Stage 矩阵 496px（常驻，可直接操作）   ← 状态真相
└── 阶段工作面（弹性）：概览条 32px + 工作面 + 批量动作条 40px
底部 Run 状态带 24px（可展开 268px 任务面板）
右侧抽屉 360px（单元详情，覆盖不打断矩阵）
状态演示面板 420px（12 状态真相）
命令面板 560px（Ctrl+K）
```

## 3. 阶段轨道（一级导航 = 流水线阶段）

| # | 键 | Tab | 工作面 | 主操作 | 数字键 |
|---|---|---|---|---|---|
| 01 | `detect` | DETECT 检测 | 页 × 检测结果网格（Region 几何 / 越界） | 重检测、修几何 | `1` |
| 02 | `ocr` | OCR 识别 | 识别质量桶表（置信度分桶） | 重 OCR、改原文 | `2` |
| 03 | `verify` | VERIFY 校对 | 对照复核面（页图 + 原文/机译/人工） | 确认、改译、加术语 | `3` |
| 04 | `inpaint` | INPAINT 修复 | 原图 / 修复后 双栏对比 + Mask | 重修复、换路线 | `4` |
| 05 | `render` | RENDER 排版 | 成品预览矩阵 | 重渲染、调样式 | `5` |
| Q | `queue` | QUEUE 队列 | Run 列表 + 后台任务 | 暂停/继续/重试/取消 | `Q` |

阶段轨道同时是**进度条与门禁**：每个 Tab 下方 18px 门禁段显示完成度、异常计数，未达标段用琥珀/红填充；右侧常驻门禁说明（如「RENDER：12 页未修复，导出将缺失成品」）。

## 4. 资源树（二级导航）

- **作品**：夜光列车 / 雨の停車場 / 汉江之夜 / 旧校舍的夏天；展开当前作品显示章节（第9–13话），点击章节切换矩阵数据。
- **批次**：`B-012 第1–10章 240 页`（当前）、`B-011 第1–9章 216 页`；badge 显示运行中/失败数。
- **队列**：5 个 Run（`R-8831…R-8827`），badge 显示 62% / 完成 / 阻塞 / 中断。
- 树底固定摘要：本章 23 页 · 完成 18 · 失败/过期 2/1 · 待确认 3。
- 折叠状态由 `.tree-group` 控制；当前项 `aria-current="true"` 带 2px 左侧标记条 + accent 图标。

## 5. 概览条（CountChips）

`240 页 · 182 完成 · 12 失败 · 6 过期 · 40 待确认 · 0 阻塞`（批次口径，**类别允许重叠**：完成含已过期与待确认）。

点击即筛选矩阵：非匹配行降为 35% 不透明度，右侧出现筛选 chip 可清除；矩阵底部同步显示「已选 N 单元 · 失败 x · 过期 y」。

## 6. 能力 → 入口可达性矩阵

| 能力 | 一级入口 | 二级入口 | 快捷键 |
|---|---|---|---|
| 看整批状态 | 矩阵（常驻） | 概览条筛选 | — |
| 定位失败单元 | 概览条「失败」 | 门禁段 INPAINT/REVIEW | `Ctrl+Shift+R` |
| 批量重试/推进 | 批量动作条 | 命令面板 | `Ctrl+Enter` |
| 单元详情 | 双击单元 | 批量条「查看详情」 | `Enter` |
| 校对译文 | VERIFY 工作面 | 矩阵 REV 列下钻 | `3` |
| 修图/换 Mask | INPAINT 工作面 | 抽屉四轨 | `4` |
| 成品验收 | RENDER 矩阵 | 门禁横幅「仍然导出」 | `5` |
| 任务控制 | Run 状态带 | QUEUE 工作面 | `Q` |
| 导出 | RENDER 工具条 | 命令面板 | `Ctrl+E` |
| 换主题/状态演示 | 轨道右侧图标 | 命令面板 | `T` / `S` |
| 跨阶段跳转 | 阶段 Tab | 命令面板 | `1`–`5` / `Q` |

## 7. 与"页面级导航"的区别（方向差异自证）

- 没有"设置页"：Provider / 网络 / 并发以对话框与 Run 面板内联，不离开矩阵。
- 没有"阅读器页"：成品验收在 RENDER 工作面完成。
- 没有"图表看板页"：矩阵本身就是状态真相，不做只读仪表盘。
- 任意两处切换都不丢失矩阵滚动位置与选中集合——矩阵是常驻参照系。

## 8. 文件结构

`index.html`（DOM 骨架）+ `styles.css`（样式）+ `tokens.json`（令牌）+ `data.js`（假数据，对齐 00_SAMPLE_DATA）+ `views.js`（纯渲染）+ `app.js`（状态/事件/键盘/URL）+ `spec.html`（视觉规范）+ `SCREENSHOTS/`。
