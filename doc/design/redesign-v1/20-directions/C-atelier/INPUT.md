# 方向 C · 工坊 Atelier —— 键鼠映射

> 与共享 `10-ux/14_INPUT_SPEC.md` 的差异：本方向新增 `1`–`5`/`Q` 阶段直达与矩阵空间导航，**不使用** J/K 行流移动（那是方向 B 的范式）。
> 实现位置：`app.js` 的 `keydown` 委托；焦点在 `input/textarea` 时不触发单键快捷键。

## 1. 阶段导航（核心）

| 键 | 动作 |
|---|---|
| `1` | DETECT 检测 |
| `2` | OCR 识别 |
| `3` | VERIFY 校对 |
| `4` | INPAINT 修复 |
| `5` | RENDER 排版 |
| `Q` | QUEUE 队列 |
| `M` | 矩阵最大化（隐藏工作面，只留产线） |
| `T` | 深 / 浅主题切换（写入 localStorage） |
| `S` | 状态演示面板开关 |
| `Ctrl+K` | 命令面板 |

## 2. 矩阵空间导航（焦点 = 单元格）

| 键 | 动作 |
|---|---|
| `↑ ↓ ← →` | 在 23 行 × 11 阶段内移动焦点（越界夹紧，自动滚动到可见） |
| `Shift + 方向键` | 从锚点扩展到当前焦点（矩形框选） |
| `Space` | 切换当前焦点单元的选中态 |
| `Enter` | 下钻详情抽屉（当前焦点单元） |
| `Esc` | 关闭浮层；无浮层时清空选中 |
| 单击 | 单选（重设锚点） |
| `Shift` + 单击 | 从锚点矩形框选 |
| `Alt/Ctrl` + 单击 | 追加 / 取消单个单元 |
| 拖拽 | 框选（`.marquee` 矩形，实时更新计数与批量条） |
| 双击 | 下钻详情抽屉 |

## 3. 批量动作

| 键 | 动作 | 前置 |
|---|---|---|
| `Ctrl+Shift+R` | 重试选中 failed 单元 | 选中 > 0；无 failed 时明确回报"重试只作用于 failed" |
| `Ctrl+Shift+K` | 跳过选中单元 | 选中 > 0；提示记录原因 |
| `Ctrl+Enter` | 推进所选到下一阶段 | 选中 > 0；已完成/已锁定会跳过并给原因 |
| `Ctrl+E` | 导出批次 | 弹出门禁对话框（含 12 页未修复影响面） |
| `Ctrl+K` | 命令面板（包含以上全部动作的可搜索入口） | — |

## 4. 工作面内部

| 上下文 | 键 | 动作 |
|---|---|---|
| VERIFY | `Enter` | 确认并下一条 |
| VERIFY | `E` / `O` | 编辑译文 / 编辑原文 |
| VERIFY | `Ctrl+Enter` | 确认本页 |
| 抽屉 | `Esc` | 关闭（矩阵选中与滚动位置不变） |
| 命令面板 | `↑ ↓` / `Enter` / `Esc` | 移动 / 执行 / 关闭 |
| 对话框 | `Esc` | 取消（危险确认默认焦点在"取消"侧） |
| Run 状态带 | 点击「详情」 | 展开 268px 任务面板 |

## 5. 鼠标约定

- 矩阵单元、Tab、胶囊、门禁段、树行、表格行全部是可点击元素（`button` 或 `role=button` + `tabindex`），`hover` 用 `--bg-raised`，激活用 accent 描边。
- 拖拽框选与单击的判定阈值：位移 > 4px 视为框选，否则视为点击。
- 抽屉与状态面板为覆盖层，**不**遮挡 Run 带（bottom 让出 24px）。
- 滚动：矩阵纵向滚动；横向不滚动（事件列在 ≤1439 隐藏而非滚动）。

## 6. 与共享规范的差异说明

| 共享规范 | 本方向 | 理由 |
|---|---|---|
| `J/K` 上下移动对象 | 用方向键做二维矩阵导航 | 主对象是"页×阶段"二维单元，不是一维行流 |
| `Space` 平移画布 | `Space` 切换单元选中 | 本方向没有全屏画布 |
| `Enter` 确认当前项 | `Enter` 下钻抽屉 | 确认动作在 VERIFY 工作面内（`Enter` 语义随工作面收敛） |
| `Ctrl+1/2/3` 切空间 | `1`–`5`/`Q` 切阶段 | 单空间架构，无"空间"概念 |

## 7. 可访问性

- 所有可交互元素有 `aria-label` / `aria-current` / `aria-selected` / `aria-pressed`，矩阵单元 `aria-label="第 018 页 · translate · failed"`。
- 焦点可见：`:focus-visible` 1px accent 外框（全局），矩阵单元另有 `data-focus` 1px 内描边。
- 动效可关闭：`@media (prefers-reduced-motion: reduce)` 关闭 pulse 与过渡。
- 状态不依赖颜色单通道：形状 + 文字键（图例/抽屉）+ 颜色三重。

## 8. URL 参数（截图与深链）

| 参数 | 取值 | 作用 |
|---|---|---|
| `stage` | `detect\|ocr\|verify\|inpaint\|render\|queue` | 打开指定阶段 |
| `theme` | `dark\|light` | 指定主题（缺省读 localStorage） |
| `state` | 12 状态键 | 直接进入某状态真相演示 |
| `filter` | `all\|done\|failed\|stale\|review\|blocked` | 矩阵预筛选 |
| `sel` | `r:c,r:c` | 预选中单元（批量条随之出现） |
| `drawer` | `r:c` | 打开详情抽屉 |
| `run` | `1` | 展开 Run 面板 |
| `matrix` | `max` | 矩阵最大化 |

例：`index.html?stage=detect&theme=dark&sel=17:4,18:7` 可直接复现"批量动作条"截图。
