# 方向 C · 工坊 Atelier —— 工作空间布局规范

基准 1600×1000，最小 1280×800（`.app { min-width:1280px }`）。全部弹性布局，不做固定像素画布。

### 区域尺寸与行为

| 区域 | 尺寸 | 行为 |

## 2. 矩阵列结构（15 列 / ≤1439 时 14 列）

`page 62px | 11 × cell 18px | derived 82 | reg 36 | event 1fr`（≤1439：`page 56 | 11×18 | derived 1fr | reg 36`，`.che` 与 `.mx-event` 隐藏）。

11 阶段：detect / ocr / color / term / translate / segment / mask_refine / inpaint / render / review / export。
列头为竖排 4 字内缩写（DET OCR CLR TERM TRAN SEG MASK INP REND REV EXP），`title` 给全名，`data-active` 标记当前阶段列。

## 3. 矩阵最大化

`body.matrix-max`：`.main` 变为 `200px | 1fr | 0`，工作面隐藏，矩阵列宽放宽为 `page 96 / derived 132 / reg 56`。用于"只看产线"的巡检姿态，再次点击或 `M` 恢复。

## 4. 次级空间（覆盖式，不离开主空间）

| 空间 | 触发 | 尺寸 | 关闭 |
|---|---|---|---|
| 详情抽屉 | 双击单元 / `Enter` / 批量条 | 360 | `Esc` / 关闭按钮 |
| 状态演示面板 | 轨道眼睛图标 / `S` / `?state=` | 420 | `Esc` / 关闭 |
| 命令面板 | `Ctrl+K` | 560 | `Esc` / 执行 |
| 对话框 | 门禁 / 停止 / 恢复 / 导出 | 520 × ≤72vh | `Esc` / 取消 |
| Run 面板 | 状态带「详情」 | 全宽 268 | 再次点击 |

## 5. 1280×800 适配

- 矩阵降为 420px，`.mx-page` 56px，事件列隐藏（`@media (max-width:1439px)`）。
- Tab 与门禁段 `min-width` 由 132 降 112（`@media (max-width:1339px)`）；轨道右侧批次上下文隐藏，仅保留命令按钮与 3 个图标。
- VERIFY 对照表隐藏「人工译文」列；INPAINT 侧栏 232 → 196。
- 概览条摘要文案缩短为「本章 23 页 · 待确认 3」，避免 1280 下被截断。

## 6. 布局不变量（评审可验证）

1. 矩阵在任何阶段、任何主题下都完整可见，不因工作面内容被挤掉。
2. 抽屉与状态面板**不改变**矩阵滚动位置与选中集合。
3. 批量条不遮挡 Run 状态带；抽屉底部让出 Run 带 24px。
4. 无横向整页滚动；`body{overflow:hidden}` 只在抽屉/命令面板内滚动。
