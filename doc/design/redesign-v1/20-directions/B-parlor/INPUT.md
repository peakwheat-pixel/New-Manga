# 方向 B · 校阅台 —— 特有键位与输入约定

> 共享下限见 `10-ux/14_INPUT_SPEC.md`。本文件只定义 B 追加/重定义的部分。B 的核心是「行光标连续流」，因此键位以"不移动鼠标即可完成一条 Region 的全部处理"为设计目标。

## 1. 行光标流（L2，核心）

| 键 | 动作 |
|---|---|
| `J` / `↓` | 下一行（光标下移，右侧边注同步更新） |
| `K` / `↑` | 上一行 |
| `Shift+J` / `Shift+K` | 扩展选区（多行） |
| `Home` / `End` | 首行 / 末行 |
| `Enter` | 编辑当前行译文（内联） |
| `Esc` | 取消编辑 / 退出选区 |
| `Ctrl+Enter` | 确认并跳到**下一个待确认**（跳过已确认与跳过项） |
| `Shift+Enter` | 确认当前行但不前进 |
| `O` | 编辑当前行原文（OCR） |
| `L` | 锁定 / 解锁当前行 |
| `Shift+Enter`（锁定态） | 重渲染当前 Region |

## 2. 呈现与视图（L1）

| 键 | 动作 |
|---|---|
| `V` | 轮换呈现：对照 → 画布 → 成品 → 对照 |
| `1` / `2` / `3` | 直接切到 对照 / 画布 / 成品 |
| `[` / `]` | 上一页 / 下一页（同一章节内） |
| `Shift+[` / `Shift+]` | 上一章 / 下一章（工程树同步展开） |
| `Ctrl+F` | 稿面内搜索（Region / 原文 / 译文） |

## 3. 稿面工具（L1）

| 键 | 动作 |
|---|---|
| `Ctrl+K` | 命令面板（命令带作用域：当前条目 / 第007页 6 条 / 本章 23 页 / 全局） |
| `Ctrl+E` | 导出抽屉（含预检：未确认 / 过期 / 失败） |
| `Ctrl+Shift+T` | 工具抽屉（任务 / 术语 / 设置） |
| `Ctrl+,` | 设置抽屉 |
| `F1` | 键位速查抽屉 |
| `Ctrl+=` / `Ctrl+-` | 稿面字号 +10% / −10% |
| `Ctrl+0` | 字号与布局重置 100% |

## 4. 画布呈现内的额外键位

| 键 | 动作 |
|---|---|
| `J/K` | 在 Region 之间移动（画布框高亮随行光标联动） |
| `V` | 切回对照，光标位置保留 |
| 单击 Region 框 | 选中并把行光标移到对应行 |

## 5. 与共享规范的关系

- 共享 L0 全部保留；B 未重定义任何 L0 键。
- `J/K`、`Enter`、`O`、`L` 与共享 L2 语义一致；B **追加**「`Ctrl+Enter` 确认并前进」作为主推进键（共享层定义为"确认并自动前进"，B 把它作为唯一推荐路径）。
- IME 红线：内联编辑激活时，`J/K/O/L/V` 全部让位；`Esc` 取消编辑、`Ctrl+Enter` 确认并前进仍可用。
- 无障碍：行光标必须同时可见（左侧 `›` 光标符 + 整行浅朱红底），不能只靠背景色。
