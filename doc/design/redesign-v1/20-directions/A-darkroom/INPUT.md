# 方向 A · 暗房 —— 特有键位与输入约定

> 共享下限见 `10-ux/14_INPUT_SPEC.md`。本文件只定义 A 在此基础上追加/重定义的部分，**不得与共享层 L0 冲突**。

## 1. 空间与导航（L1）

| 键 | 动作 |
|---|---|
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | 资料柜 / 工位 / 控制台（切换保留上下文） |
| `J` / `K` | 下一个 / 上一个 Region（HUD 环随之移动） |
| `[` / `]` | 上一页 / 下一页（胶片条同步高亮） |
| `Shift+[` / `Shift+]` | 上一章 / 下一章（切换 breadcrumb 层级） |
| `Ctrl+Shift+F` | 跳到下一个失败单元 |
| `Ctrl+Shift+E` | 展开 / 收起底部流水线带 |
| `F` / `1` | 画布适应窗口 / 100%（`+` `-` 缩放） |

## 2. 对象动作（L2，HUD 环等价）

| 键 | 动作 | HUD 位 |
|---|---|---|
| `Enter` | 确认当前 Region（review_state → confirmed） | N |
| `Ctrl+Enter` | 确认本页全部 | — |
| `Shift+Enter` | 重渲染当前 Region | NE |
| `E` | 编辑译文（焦点进入检查器文本域） | E |
| `O` | 编辑原文（OCR） | W |
| `L` | 锁定 / 解锁当前 Region | S |
| `Ctrl+Shift+R` | 重跑当前 Region 全链路（需确认） | SW |
| `Ctrl+Shift+O` | 重新 OCR 当前 Region | — |
| `Tab`（HUD 激活时） | 在 8 个 HUD 动作位间循环 | — |
| `Esc` | 逐级退出：输入框 → 浮层 → 检查器 → 选择 | — |

## 3. 检查器（L2）

| 键 | 动作 |
|---|---|
| `1`–`5`（检查器聚焦时） | 文本 / 样式 / 修复 / 锁定 / 历史 |
| `Ctrl+B` | 展开 / 收起检查器（40px ↔ 320px） |

## 4. 画布手势

| 操作 | 行为 |
|---|---|
| 空格 + 拖拽 / 中键拖拽 | 平移 |
| `Ctrl+滚轮` | 以光标为中心缩放 |
| 单击 Region | 选中并显示 HUD 环 |
| 双击 Region | 进入文本编辑 |
| `Esc`（拖拽中） | 取消本次拖拽 |

## 5. 与共享规范的关系

- 共享 L0（`Ctrl+K` 命令面板、`Ctrl+E` 导出、`Ctrl+,` 设置、`F1` 键位速查、`Esc` 逐级退出）全部保留且优先。
- `J/K`、`Enter`、`E`、`O`、`L` 与共享 L2 一致，A 未重定义语义，只把它们接到 HUD 环上。
- IME 红线：检查器文本域获得焦点时，`J/K/E/O/L` 全部让位给输入法，仅 `Esc` 与 `Ctrl+Enter` 保留编辑语义。
