# 桌面端键鼠操作规范（共享下限）

> 三套方向必须实现「共享层」；方向特有键位在各方向 `INPUT.md` 中定义，不得与共享层冲突。
> 平台：Windows。修饰键统一用 `Ctrl`（不假定 macOS）。

---

## 1. 按键分层

| 层 | 作用域 | 冲突规则 |
|---|---|---|
| L0 全局 | 任何界面 | 最高优先，不可被局部覆盖 |
| L1 空间/视图 | 当前工作空间 | 不得占用 L0 |
| L2 对象 | 当前选中对象 | 仅在焦点不在文本输入时生效 |
| L3 文本 | 输入框内 | 输入框获得焦点时，L2 让位；仅 `Esc` 与 `Ctrl+Enter` 例外 |

**IME 红线**：文本输入中不得把字母键作为快捷键；`Enter`/`Esc` 在输入框内的语义必须与"确认/取消编辑"一致，且不得误触发 L2 动作。

---

## 2. L0 全局（必须实现）

| 快捷键 | 动作 |
|---|---|
| `Ctrl+K` | 命令面板（模糊搜索全部命令，显示作用域与可用性） |
| `Ctrl+P` | 快速跳转（作品/章节/页/Region 名称跳转） |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做（仅可编辑内容，不可撤销任务执行） |
| `Ctrl+S` | 保存当前编辑（若存在显式保存模型）；无显式保存时为空操作并提示"已自动保存" |
| `Ctrl+E` | 导出（当前作用域） |
| `Ctrl+,` | 设置 |
| `F1` | 快捷键速查（覆盖层，列出当前上下文可用键位） |
| `Esc` | 逐级退出：输入框 → 浮层 → 面板 → 选择 |
| `Ctrl+1..5` | 空间切换（各方向自行分配，需在 UI 显示） |

**焦点规则**：任何浮层（命令面板/抽屉/对话框）必须 `Esc` 可关闭、`Tab` 可循环、打开时焦点落入首个可操作项、关闭后焦点回到触发元素。

---

## 3. L1 空间/视图（必须实现）

| 快捷键 | 动作 |
|---|---|
| `F5` / `Shift+F5` | 下一个 / 上一个需要处理的对象（待确认 → 失败 → 过期，按优先级） |
| `Ctrl+Shift+F` | 跳到下一个失败单元 |
| `Ctrl+Shift+R` | 重跑当前选中对象（当前阶段起） |
| `Ctrl+Shift+E` | 展开/收起任务面板 |
| `Ctrl+0` | 重置布局（面板宽度/折叠恢复默认） |

---

## 4. L2 对象（必须实现，按对象类型）

### 4.1 导航
| 快捷键 | 动作 |
|---|---|
| `J` / `K` | 下一个 / 上一个对象（Region 或行，按方向） |
| `[` / `]` | 上一页 / 下一页 |
| `Shift+[` / `Shift+]` | 上一章 / 下一章 |
| `Home` / `End` | 第一个 / 最后一个对象 |

### 4.2 编辑与确认
| 快捷键 | 动作 |
|---|---|
| `Enter` | 确认当前对象（审阅态 → confirmed） |
| `Ctrl+Enter` | 确认并自动前进到下一个待确认 |
| `E` | 编辑译文 |
| `O` | 编辑原文（OCR 文本） |
| `L` | 锁定/解锁当前对象（显示当前锁定类型） |
| `Shift+Enter` | 重渲染当前对象 |
| `Delete` | 删除当前对象（Region）——必须二次确认 |
| `Ctrl+D` | 复制译文到剪贴板，或从剪贴板粘贴（依上下文提示） |

### 4.3 选择
| 快捷键 | 动作 |
|---|---|
| `Shift+J/K` 或 `Shift+方向` | 扩展选择 |
| `Ctrl+A` | 全选当前作用域 |
| `Ctrl+Shift+A` | 清空选择 |

---

## 5. 画布（有画布的方向必须实现）

| 操作 | 行为 |
|---|---|
| 滚轮 | 垂直滚动/缩放（方向自定，但必须在 F1 速查中说明） |
| `Ctrl+滚轮` | 缩放（以光标为中心） |
| 空格 + 拖拽 / 中键拖拽 | 平移 |
| `F` | 适应窗口 |
| `1` | 100% |
| `+` / `-` | 放大 / 缩小 |
| 单击 | 选中对象 |
| 拖拽对象 | 移动（Region） |
| 拖拽角点 | 缩放（Region） |
| `Shift` + 拖拽 | 约束比例/正交 |
| 双击 | 进入该对象的编辑态 |
| 右键 | 上下文菜单（次要入口，不得是唯一入口） |

**几何编辑要求**：移动/缩放必须显示实时数值（x, y, w, h）与对齐辅助线；`Esc` 取消本次拖拽；`Ctrl+Z` 撤销。

---

## 6. 鼠标与悬停规范

- 悬停提示延迟 400ms，出现后 0ms 消失；提示内容为"名称 + 快捷键 + 状态摘要"，不超过 2 行。
- 可点击元素必须有 hover / active / focus-visible 三态，且三态差异在深色下仍可辨（ΔL ≥ 8%）。
- 拖动阈值 3px，避免误触发选择。
- 右键菜单必须提供与主入口等价的能力（不得只有右键才能完成某操作）。

---

## 7. 危险操作

| 要求 | 说明 |
|---|---|
| 不可逆操作 | 必须显示影响数量与不可逆提示；默认焦点在"取消"上 |
| 键盘可达 | `Esc` 取消；不得把 `Enter` 作为默认确认键 |
| 批量破坏 | 提供"预览影响列表"；超过 10 项时强制滚动查看 |
| 可撤销 | 有可行撤销路径的操作优先提供撤销而非确认（如 Region 删除 → 回收站） |

---

## 8. 可访问性

- 全部功能键盘可达；焦点顺序与视觉顺序一致。
- 焦点环：2px、`accent` 色、与背景对比 ≥3:1，任何状态下不隐藏。
- 状态不得只靠颜色：必须配合形状/图标/文字/线型。
- 支持 `prefers-reduced-motion`：关闭所有非必要动效。
- 正文对比度 ≥4.5:1；次要文字 ≥3:1（不可用于关键信息）。
- 高 DPI：100%/150%/200% 下不得出现文字裁切、图标模糊、1px 线消失（用 `0.5px` 或 `1px` + 合适缩放策略）。

---

## 9. 方向特有键位（各方向自行定义，但必须满足）

- 不得与本文档 L0 冲突。
- 必须在该方向的 `F1` 速查与 `INPUT.md` 中列出。
- 高频动作（该方向的主路径）必须有单键或 `Ctrl+` 单键组合。
