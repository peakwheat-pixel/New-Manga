# 书架页面参考分析：Saber-Translator

> 参考对象：`https://github.com/MashiroSaber03/Saber-Translator`（GPL-3.0，Vue 3 + Pinia）
> 取证方式：README、`pic/bookshelf-display.png` 截图、`vue-frontend/src/views/BookshelfView.vue`（24 KB）源码。
> 用途：只借鉴**书架信息架构与交互逻辑**，不复用其视觉、组件实现或代码。

---

## 1. 它的书架 UX 逻辑（从源码提炼）

| 层 | 做法 |
|---|---|
| 主视图 | **封面卡片网格**：`minmax(160px,1fr)` 自适应列，gap 24；封面 2:3 占卡片主体 |
| 卡片信息 | 封面 → 书名（粗）→ 章节数 → 标签胶囊；封面上有角标 |
| 查询区 | 搜索框 + 标签筛选（每个标签带命中计数）+ 排序下拉（更新时间/创建时间/标题 × 升降） |
| 主操作 | 右上：新建书籍（primary）· 管理标签 · 快速翻译 · 批量管理（toggle） |
| 详情 | **点击卡片 → 弹窗**（BookDetailModal），章节在弹窗里管理 |
| 批量 | 进入批量模式后卡片可多选；出现 sticky 批量条：全选 / 已选 N 本 / 翻译全部章节 / 下载 / 加标签 / 移除标签 / 删除 |
| 反馈 | `ProductStatusBanner` 两种错误（书架加载失败、标签加载失败）各自带「重试」 |
| 空态 | 三种：加载中（spinner）/ 书架为空（"新建第一本书"）/ 筛选无结果（"调整搜索条件或标签筛选"） |
| 危险操作 | 批量删除走 `confirmProductAction`（danger tone），文案说明"存在活动任务的书籍会被保留" |

## 2. 吸收（进入本设计）

1. **卡片网格取代三栏主从表**——漫画是靠封面识别的，三栏里的 44px 小缩略图识别效率太低。
2. **卡片承载「章节数 / 页数 / 标签 / 完成度」四元信息**，让书架本身能回答"这本书还要不要做"。
3. **搜索 + 标签筛选（带计数）+ 排序** 三件套放进一条工具条，不另设筛选侧栏。
4. **批量管理模式**：显式进入/退出，卡片可多选，底部 sticky 批量条常显作用域计数。
5. **空态分三种**（加载 / 真空 / 筛选无结果），每种给不同出路——这是很多产品漏掉的。
6. **错误可恢复**：加载失败必须在原位置给重试，不能只 toast。

## 3. 转化（同一逻辑，本设计系统的做法）

| 参考做法 | 本设计 | 理由 |
|---|---|---|
| 点卡片弹详情弹窗 | **右侧常驻详情面板 320px** | 桌面软件不需要用弹窗遮挡书架；常驻面板让"选书—看章节—进工作台"一步不丢 |
| 卡片圆角 8–12px + 阴影 | 2px 圆角 + 1px 描边 + 无阴影 | 全局无阴影体系（`SIX_DIMENSIONS §5`），层级靠明度差 |
| 紫色渐变品牌头 + emoji（📚 🔍） | 无渐变；线性 1.25px 图标 | 反塑料感清单（`DESIGN_BRIEF §5.6`）明令禁止 emoji 与渐变 |
| 批量条带 `box-shadow` 浮起 | 1px 强边框 + `bg.raised` | 同上 |
| Toast 提示 | 行内状态 + 底部一次性提示 | 错误必须可就地定位，不能只 toast |
| 标签用彩色胶囊 | 标签用描边胶囊（无彩色填充） | 颜色在本体系中只表达状态与焦点，不用于分类装饰 |
| 章节在弹窗里管理 | 章节在详情面板内，点章节即设为当前章节 | 与工作台/阅读共享同一个"当前章节" |

## 4. 未采纳

- 卡片角标数字（章节数已有文字，不必重复）。
- "快速翻译"独立入口：本设计里它有明确归属——工作台 Batch 模式，不放在书架。
- header 里的局域网地址 / 试用声明等运营信息（本产品是本地桌面软件）。
- 其标签的颜色自定义能力：本设计暂不引入，避免颜色语义被分类占用。

## 5. 结果对照

| 维度 | 改前（三栏主从） | 改后（卡片网格 + 详情） |
|---|---|---|
| 识别作品 | 44px 缩略图，靠标题 | 2:3 封面，靠画面 |
| 判断"该不该做" | 需看章节列 | 卡片上直接给完成度条 + 页数 |
| 到工作台 | 2 次点击 | 双击卡片直接进；或选中后按「进入工作台」 |
| 批量能力 | 无 | 批量模式 + 多选 + 作用域计数 |
| 筛选 | 无 | 搜索 + 标签（带计数）+ 排序 |
