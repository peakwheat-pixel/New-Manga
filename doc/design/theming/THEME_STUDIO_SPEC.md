## 1. 定位与不变量

Theme Studio 是**独立覆盖式表面**（`ShellSurface.ThemeStudio`），不是第五个空间、不是设置页里的一个分区。入口三个：TopBand「主题」按钮、`Ctrl+,`、Console「外观」分区。

**硬不变量（违反即不合格）**：

1. 主题=**性格**（颜色/字体/圆角/材质/阴影/动效）；布局（导航位置/书架布局/密度/工作台/阅读器）与外观（浅/深/系统/高对比）**独立于主题**、独立持久化。
2. 实时预览走 `IThemePreviewEngine` 会话：改动即时反映，但**不重建主界面、不改漫画原图像素、不丢未保存编辑**。
3. 「应用」= 提交并持久化；「取消」= 完整回滚到进入前的主题/外观/布局；「恢复默认」= 二次确认后重置全部。
4. 主题包非法/损坏 → 逐条 issue + 回退默认，**绝不**崩溃或白屏。
5. 预览中的三个视图（书架/工作台/阅读器）必须是**真实控件渲染**（复用生产视图的控件），不是图片，不是第二套假 UI。
6. 无 emoji 图标；无渐变/模糊/阴影表达层级（DESIGN_SYSTEM §9 反面清单全程有效）。

## 2. 信息架构

```
Theme Studio（覆盖表面，保留 TopBand 返回按钮 + 应用/取消状态区）
├─ 左栏 224px：7 分区导航（图标 + 标题 + 副标题 + 当前脏标记）
│   1 主题库    2 预览    3 我的主题    4 主题编辑
│   5 外观      6 导入导出 7 恢复默认
├─ 主区（随分区）
└─ 右栏 320px：实时预览摘要
    ├ 当前主题卡（名称/作者/版本/明暗支持/标签）
    ├ 外观（浅/深/系统）· 高对比 · 减少动效
    ├ 密度 · 布局（V1 导航锁 TopBand，其余显示"预留"）
    ├ 对比度校验结果（逐项 通过/失败）
    └ [取消] [应用]  ← 有脏标记时高亮；应用后显示"已应用"并 2s 后淡化
```

分区切换不丢草稿：编辑状态存于 `ThemeStudioState`（唯一状态源），切分区只换主区视图。

## 3. 分区规格

### 3.1 主题库（Library）

- 布局：顶部搜索框（名称/作者/标签）+ 分类 Chip（全部/内置/我的/收藏）+ 筛选（明/暗/均支持/高对比友好）；主体卡片网格（≥1600 四列 / 1280 三列 / 1024 两列），卡片 = 迷你三视图预览（书架/工作台/阅读器各一小块渲染）+ 名称 + 作者 + 明暗徽标 + 收藏星标 + 「预览」「应用」。
- 交互：单击选中 → 右栏摘要；双击 = 应用到预览会话（未提交）；`Enter` 应用预览；`Ctrl+F` 聚焦搜索。
- 空态：搜索无结果 → `EmptyState`（一句话 + 清空筛选）；无用户主题 → 提示导入。

### 3.2 预览（Preview）

- 三视图切换 `SegmentedControl`：书架 / 工作台 / 阅读器（真实控件，1600×1000 基准缩放，支持 1280/1024 断点预览）。
- 顶部工具条：明暗（浅/深/系统模拟）· 高对比开关 · 密度（紧凑/舒适/宽松）· 缩放（50/75/100%）。
- 预览区显示**当前会话主题**，右侧摘要显示「当前主题= X / 会话主题= Y」差异提示（避免误以为已应用）。
- 内容来源：只读示例数据（与生产数据隔离，明确标注"示例内容"），不得读取用户真实书库（隐私 + 性能）。

### 3.3 我的主题（My Themes）

- 三个页签：已安装 / 收藏 / 自定义（自定义 = 从内置主题"另存为"产生的用户主题）。
- 每项操作：应用、收藏/取消收藏、复制、导出（`.nmtheme`）、删除（二次确认；内置不可删）。
- 空态：`EmptyState` + 主操作「导入主题包」。
- 用户主题目录：`%APPDATA%/NewManga/themes/*.nmtheme`（JSON，schema `newmanga.theme/1`）。

### 3.4 主题编辑（Editor）

五个分组（左树或折叠面板），每组改动即时进入预览会话：

| 组 | 控件 | 约束 |
|---|---|---|
| 配色 | 语义色组（背景 5 级 / 描边 4 级 / 文本 5 级 / 强调 6 级 / 状态 7 态）；每组一个取色器 + 十六进制输入 + 重置 | 保证状态与强调语义分离（不可把状态色用于强调位）；实时对比度校验 |
| 字体 | UI/数据/显示字体族（系统字体列表，禁止随包字体）、字号缩放（80–130%）、行高预设 | 缺字体回退链可见；不打包商业字体 |
| 圆角 | none/sm/md 三档（禁止 >3px） | DESIGN_SYSTEM §1 硬规则 |
| 背景/材质 | Solid / None（V1 不支持 Mica/Acrylic/模糊） | 破坏"无模糊"约束的选项不提供 |
| 阴影/高度 | 仅 none / raised（1px 描边 + 明度） | 禁止彩色投影/大阴影 |
| 动效 | 时长 fast/normal/slow 三档 + 减少动效开关 | 默认 90ms；`reduced-motion` 全关 |

- 「从当前主题另存为」→ 输入名称/作者/标签 → 写入用户主题目录 → 出现在我的主题。
- 编辑中显示"未保存草稿"标记；离开分区/关闭表面时若有未提交改动 → Modal 三出口（继续编辑/放弃/应用）。

### 3.5 外观（Appearance）

- 主题模式：浅色 / 深色 / 系统跟随（三选一，单选卡片 + 说明各自后果）。
- 高对比度：开/关（开 = 加强描边与文本对比、状态符号加粗）。
- 减少动效：开/关（系统 `prefers-reduced-motion` 优先，可覆盖）。
- 跟随系统强调色：开/关（关闭时用主题自带强调色）。
- 密度与布局：密度三档；布局（导航/书架/工作台/阅读器）——V1 仅导航 `TopBand` 生效，其它显示"预留"，**不得做成假开关**。
- 立即生效；不依赖「应用」按钮（外观是设置不是主题包）。

### 3.6 导入导出（Import/Export）

- 导入：`拖拽` 或 `选择文件`（`.nmtheme`/`.json`）；导入前校验：schema 版本、必填键、颜色格式、对比度、圆角/阴影约束、未知字段（警告不阻止）、ID 冲突（提示覆盖/重命名）。
- 校验结果逐条展示：级别（错误/警告）+ 路径 + 说明 + 建议；有错误时「导入」禁用。
- 导出：选择主题 → 导出 `.nmtheme`（含 schema 版本/作者/标签/令牌）；校验导出后再导入等价（round-trip 一致性）。
- 兼容性提示：明确显示"该主题包适用于 New Manga Theme Engine v1"。

### 3.7 恢复默认

- 二次确认 Modal：说明将重置主题、外观、密度、布局到出厂默认；列出将被覆盖的自定义主题（不删除用户主题文件，只重置选择）。
- 「恢复默认」不会删除用户自定义主题包；若用户勾选"同时清除我的主题"，需再确认并列出文件名。

## 4. 状态模型

```csharp
public sealed record ThemeStudioState(
    ThemeStudioSection Section,        // Library/Preview/MyThemes/Editor/Appearance/ImportExport/Reset
    string SelectedThemeId,
    string? PreviewThemeId,            // 会话主题（null = 当前已应用主题）
    bool HasDraft,                     // 有未提交改动
    ThemeValidationResult? LastValidation,
    bool IsBusy,
    string? LastError);
```

- 会话生命周期：进入表面 → `IThemePreviewEngine.Begin()`；改动 → `Update()`；应用 → `Commit()` + `IThemeService.ApplyAsync`；取消/关闭 → `Cancel()`（回滚）。
- 脏状态：有草稿时返回按钮 / `Esc` 触发三出口 Modal。
- 失败：应用失败 → 保持会话、显示 issue、允许重试/取消；不得静默回退用户。

## 5. 键盘与无障碍

| 键 | 行为 |
|---|---|
| `Ctrl+,` | 打开 Theme Studio（设置入口语义） |
| `Esc` | 关闭预览浮层 → 再按退出表面（有草稿走三出口） |
| `Ctrl+F` | 聚焦主题库搜索 |
| `↑↓/←→` | 分区/卡片导航 |
| `Enter` | 选中/预览 |
| `Ctrl+Enter` | 应用 |
| `Tab` | 焦点顺序：左栏 → 主区 → 右栏，焦点环 2px accent |

- 对比度：正文 ≥7:1、次要 ≥4.5:1、状态 ≥4.5:1（编辑器实时计算并显示数值）。
- 状态不得仅靠颜色：主题卡片明暗徽标带文字；校验结果带图标 + 级别文字。
- 减少动效：预览切换无动画；主题应用淡入 90ms 且可关。
