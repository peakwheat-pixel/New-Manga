# Fluent 漫画界面：用户需求与交互概念

日期：2026-10-30

最后更新：2026-10-31

状态：用户讨论记录；不是已冻结的实现规格、Task 或已实现能力。

范围：独立的 Windows 11 风格界面方案，以及讨论中明确的书架、阅读器、工作台、设置和数据行为。效果图为视觉概念，不代表真实数据或功能。本文不替代当前 Plan、Status、契约或架构决策。

## 1. 方向与约束

- 用户希望新增一套布局和 UI/UX 与当前界面完全不同的方案，独立编写新界面的布局、组件、交互与动效代码；已确认采用下述 E 方案，共享应用内核与后端，具体实现边界由 DSH 冻结。
- 本次 Fluent 界面采用深色 Windows 11 风格、亚克力材质、圆角、层次感和柔和动效；其各页面默认使用紧凑按钮与卡片，保持文字清晰和足够点击空间。书架、工作台、阅读器、设置共用主导览栏，在此前已缩小的方案基础上再缩窄约四分之一；页面缩略图等功能面板不属于主导览栏。这些几何与视觉默认值适用于本次 Fluent 方案，不强制未来其他界面方案采用左侧导航或相同尺寸。
- 界面以简体中文为默认和优先适配语言；设置中暂定英文、日语、韩语。效果图中的英文和示例数据不构成实际功能要求。
- 书架、详情、阅读器和工作台的视觉方案均属于概念设计，尚未签发实现授权或验收结论。

> 架构差异：用户后来明确提出导入时直接引用原文件，不复制原文件，取代之前讨论的 Managed Copy 方案。现行 [AD-002](../AD-002_TARGET_DESKTOP_ARCHITECTURE.md) 仍规定 Managed Copy；本文不自行修改该决策。实施前由 DSH 处理架构变更、数据安全与契约影响，冻结任务范围。

### E 方案：共享应用内核与可切换界面方案

用户已确认此设计方向；本节不是正式 ADR，不更改现有冻结契约。

| 层次 | 作用 | 示例 |
|---|---|---|
| 界面方案 | 独立的布局、导航、面板组织、交互与界面代码 | 现有界面、新 Fluent 界面、未来其他方案 |
| 视觉主题 | 配色、字体、圆角、材质、图标与动效 | 深色紫、浅色及其他风格 |
| 比例方案 | 导航宽度、控件、卡片及面板比例 | 紧凑、宽松、自定义 |

- 主题中心统一提供上述三层选择，持久化分别管理；视觉主题和比例是否适用于某套界面方案，须在实现规格中明确兼容范围。
- 其他界面方案可采用不同的导航和组件组织；比例方案记录所属界面方案及适用组件。跨方案应用前检查兼容性，不把 Fluent 的导航宽度或卡片尺寸强行应用到不对应的组件；不兼容时保留目标方案的有效设置并说明，DSH 冻结具体映射规则。
- 每套界面通过稳定的接口/适配边界访问共享应用内核与后端。书籍/页面/区域及阅读位置、任务与进度、人工编辑草稿和保存状态、Lock 与版本、模型/字体/提示词/词表配置、文件引用/数据库/备份/回收站由共享能力管理；切换界面不应创建第二份业务状态。
- 纯界面改动应尽量不要求更改后端；新增领域能力或现有能力不满足已确认需求时，仍须由 DSH 评估接口和后端变更，不承诺后端永远不变。现有底层能力先核对再复用。
- 第一阶段在当前 Avalonia 技术栈内提供现有与 Fluent 两套内置界面方案，验证切换不丢失编辑、不重复启动任务；后续再评估独立安装更多界面方案。更换整个前端技术栈不属于此阶段范围。
- 未保存修改、运行任务、浮动面板及当前选择等在切换前后的保留和恢复需制定可验证规则；不能把加载失败或无法映射状态作为丢弃用户数据的理由。
- 现行 [V11R 契约 §4](../plan/V11R_AVALONIA_CONTRACT.md#4-theme-engine-公开面冻结) 限定 ThemePackage 只定义外观、禁止布局与导航，且已有切换不重建窗口等规则。完整界面方案需独立机制及契约扩展，由 DSH 裁决；不得直接把完整界面代码塞进现行主题包。

## 2. 书架

### 浏览、搜索与收藏

- 封面网格与列表视图可切换，记住视图选择。顶部提供导入、选择、回收站、搜索、标签、排序、收藏筛选和视图切换。
- 搜索书名、作者和自定义标签，输入时即时更新，可清空。收藏、搜索和标签可组合；多标签要求同时匹配全部已选标签。
- 每本书可添加多个标签；筛选面板支持搜索和内部滚动，标题、清除及完成操作保持可见。面板提供标签管理；删除标签前说明它从所有关联书籍移除，不删除书籍。标签过多时展示部分，其他通过更多查看。
- 支持最近添加、最近阅读、书名排序及正序/逆序。长书名省略后悬停展示全文。无匹配结果提供清除筛选；空书架提供导入入口。
- 书籍右键菜单：查看详情、继续阅读、添加内容、编辑书籍信息、定位原文件、收藏/取消收藏、删除。收藏可在网格和列表直接切换。
- 当前使用期间，从详情或阅读器返回时保留滚动位置、搜索词、排序和筛选。关闭软件后不恢复这些状态；下次默认全部书籍、最近添加从新到旧。视图样式单独记住。
- 窗口缩小时网格减少列数，顶部次要操作收入更多菜单，列表优先隐藏次要列；详情可内部滚动，恢复大小后不改变视图选择。

### 书籍详情及顺序

- 点击封面打开默认居中且可拖动的详情浮层，可通过关闭、遮罩或 Esc 退出。提供开始/继续阅读，每项提供阅读、工作台和更多操作。
- 详情浮层的书籍级更多菜单提供删除整本书和重置整书阅读进度；每个卷、话或番外的更多菜单也提供单项删除及进度重置。删除与重置前均确认，并清楚显示影响范围。
- **卷、话、番外同级**；「全部」按阅读顺序混合显示，「番外」单独筛选。列表可在带缩略图和简洁样式间切换；显示标题、阅读进度及上次位置。
- 默认按数字排序；数字相同按导入顺序，无编号排后并按导入顺序排列。多个数字优先识别类型对应编号；不确定时视为无编号，可在预览手填。正序/逆序改变展示方向。
- 可拖动形成自定义顺序，切回数字排序不丢失自定义顺序。在番外中拖动只改变番外相互顺序；调整番外与其他项的相对位置时在全部中拖动。切换标签保留排序与滚动位置。
- 数字排序下新增项按编号插入，修改编号或类型后重新排列；自定义排序下新增项追加，改编号或类型保留原位置。
- 更多菜单提供重命名、类型调整、更换缩略图、定位原文件、重置阅读进度、删除。未读显示未开始；最后一页标记已读完，可从头或继续阅读；重置前确认。读完后提供下一项入口，按完整顺序包含番外。

### 编辑信息与封面

- 允许编辑书名、作者、封面、标签，只保存到应用内，不修改原文件。作者可空，显示未知作者；未保存关闭时可保存、放弃或继续编辑。
- 不允许同名书籍，比较时忽略首尾空格及英文大小写。重名时可改名或向已有书籍追加；回收站不占名称，恢复重名时改名或取消。
- 默认从阅读顺序第一项选封面；默认页码可设置，初始第 1 页。指定页码超出时选最后一页并提示。书籍封面及每项缩略图均可手动更换，也可选其他页面或图片。

## 3. 导入与原文件

- 支持导入新书及向已有书籍追加；选择文件、文件夹或多项。预览中确认书名、卷/话/番外、编号与顺序，可拖动调整；源文件不复制、不覆盖。
- 目标格式：图片及图片文件夹、ZIP、CBZ、PDF；图片暂定 PNG、JPEG、WebP、BMP、GIF（首帧）。PDF 按页码；图片按自然数字顺序。文件夹默认一个内容项，包含子文件夹图片，按路径和文件名自然排序；ZIP/CBZ 非图片不作为页面。
- 不支持、空内容、损坏、加密等情况说明原因，可跳过或重试；加密文件可输入密码重试，其他项目继续。重复页名保持来源顺序；无法确定时按稳定路径及文件名排序并允许手动调整。具体格式、顺序与技术能力须实施验证。
- 已被其他项目引用的文件提示已有引用，默认跳过，可选择继续引用。不同项目的阅读进度、处理结果和人工修改独立。
- 进度显示当前项目；失败可重试或跳过。取消保留已成功项目，展示结果。新书导入后留在书架并突出显示；追加后留在详情并突出显示新增项。
- 文件缺失、移动或改名时提示重新定位，保留应用内阅读记录和人工修改。可选择文件或文件夹，先预览匹配；多项目共享时可选择更新当前或一起更新，失败保留记录。
- 外部修改或替换时暂停依赖该文件的操作并提示，不自动将人工修改套用到不匹配内容。先识别未变化页面，不确定项标记需确认，允许手动指定对应页面。文件夹新增、缺失或变化先预览数量和明细，用户确认后同步；缺失页的人工修改和问题标记保留。隐藏和系统文件默认忽略；损坏图片提示，其余页面可浏览，原文件不删除。
- 处理结果、人工修改和问题标记存于应用管理数据，默认不写入或覆盖原文件。页面匹配、变化检测及数据安全机制需在架构裁决和实现规格中明确。

## 4. 删除、回收站与备份

### 删除与恢复

- 书架和详情支持多选、全选、取消全选和退出。详情「番外」全选仅选番外；切换标签保留选择及总数；确认列出全部所选项。删除确认默认居中、可拖动，分别说明人工修改、处理结果和阅读记录的影响。
- 默认删除仅将应用内项目移入应用回收站，不删除原文件。可主动勾选同时删除原文件，列出具体文件及其他引用，再确认移入 Windows 回收站。其他项目仍引用的文件默认保留并列出原因；无法移入回收站时保留并说明，不自动永久删除。
- 文件夹仅处理实际引用的文件；仅删除用户选择的导入文件夹及其内部因本次操作变空的子文件夹，不删除导入文件夹外的父目录。有无关或共享文件则保留并说明；空目录无法移入 Windows 回收站时保留并提示，不改为永久删除。部分文件失败时保留文件并列出原因、可重试；所选项目仍进入应用回收站。批量结果显示成功/失败数量和明细；移入回收站后提供撤销入口。
- 应用回收站保留书籍信息、阅读状态、人工修改、处理结果和问题标记。默认手动清理；可选 7、30、90 天或自定义期限并显示预计清理日期。自动清理只清除应用回收站及应用内数据，不操作原文件或 Windows 回收站。彻底删除前提示数据影响。
- 自动清理时保留 Lock、current/pinned Revision 和恢复所需数据，并显示未清除原因。彻底删除前同样检查保护状态，不自动解除保护；保护的具体语义与处置由 DSH 按现有契约裁决。
- 整书恢复回书架；单项恢复到原书及原顺序，原位置不可用则提示检查。所属书籍不存在时，仅恢复必要书籍信息和选中项；其他项留在回收站。为此单项需保留足够的所属书籍基本信息。恢复重名时改名或取消。
- 原文件不存在时先恢复应用数据并标记缺失，提示从 Windows 回收站恢复或重新定位；依赖原文件的操作暂不可用。

### 备份与恢复

- 默认备份应用内数据和原文件引用信息，不含原文件；可选择同时备份原文件，并在开始前显示预计大小和位置。
- 恢复前预览新增、更新、冲突；不自动覆盖人工修改。冲突逐项对照当前与备份，选择保留当前、使用备份、暂不处理，默认暂不处理。未处理项先跳过，其余确认项继续；完成后列出待处理冲突。
- 选择使用备份前先将当前人工修改保存为可恢复版本；完成后提示可查看或恢复该版本。无法安全保留时暂停该冲突项并说明原因。
- 备份含原文件时恢复前选择位置，目标有同名文件则提示，不自动覆盖；原文件缺失时保留应用数据并提供重新定位。

## 5. 阅读器（用户确认的设计）

### 阅读模式与章节衔接

- 无最近阅读设置时，日漫首次打开默认完整单页、从右向左；韩漫按窗口宽度铺开、连续向下滚动。新书优先沿用最近一次阅读设置，已有书籍恢复自身设置。单页、双页和连续滚动可快捷切换，阅读方向可设置，切换尽量保留位置。
- 双页默认封面单独显示、后续成对；支持调整封面单独显示及配对起点 +1/−1，解决错位。模式、方向和配对按书籍分别记住。
- 连续滚动页面之间不留间距，滚动到底自动进入下一项，向上可自然回看上一项；当前章节与页码随阅读位置更新。章节交界可显示分隔线和名称，设置可分别控制分隔线和章节名称提示；名称短暂提示不打断滚动。
- 翻页模式到达末尾后提供下一项入口，也可继续点击页面边缘进入；顺序遵循完整阅读顺序，包含卷、话和番外。整本书最后显示「已阅读完毕」和返回书架入口。下一项缺失或加载失败时在交界处提示并提供重试，不自动跳过。

### 导航、搜索与书签

- 左侧可隐藏面板共用「目录」「页面」「书签」标签，点击按钮展开，打开时显示上次标签。目录显示全书卷、话和番外；页面显示当前项带页码的缩略图，内部滚动并自动定位当前页。双页同时高亮当前两页，点击任一缩略图跳转到包含该页的组合。
- 书签记录所属项和页码，备注可选；工具栏可为当前页添加或取消。双页时可选择左页、右页或两页。点击书签跳转，文件缺失时提示；删除前确认，不影响漫画与进度。
- 搜索内容名称并在目录中定位；已有可搜索文字时可搜索并跳转页面，没有文字数据时显示「暂无可搜索文字」，名称搜索仍可用。
- 点击页码可输入并按回车跳转，超出范围提示；双页跳到包含该页的组合，连续滚动时页码随主要可见页面更新。

### 翻页、缩放与操作

- 翻页方式包括方向键、页面左右边缘及工具栏；方向键随阅读方向调整，点击页面中间不翻页。Page Up/Page Down 按模式翻页或滚动，Home/End 跳到当前项开头/结尾。
- 普通滚轮浏览；Ctrl + 滚轮或按住鼠标左键滚轮均以鼠标位置为中心缩放。按住左键拖动画面；仅按下到松开基本没有移动且期间没有滚轮缩放时才视为单击翻页，拖动或缩放后本次松开不翻页。连续模式放大后仍可上下滚动及拖动查看左右。
- 右下角显示缩放比例，支持按钮、滑块、数值输入；提供适合页面、适合宽度、自定义缩放及重置。双击在适合页面与上次自定义比例之间切换。每本书记住缩放比例。
- 翻页效果可选直接切换、平滑滑动、模拟翻书，记住所选效果；另可设置界面动效强度或跟随系统。

### 界面、全屏与设置

- 工具栏和侧边栏可设为自动隐藏或始终可见；自动隐藏等待时间可设置，鼠标移动时显示。全屏隐藏窗口边框和主导览栏，仍可唤出阅读工具栏和左侧面板入口；始终可见时全屏保留阅读工具栏。
- Esc 先关闭打开的面板，无面板时退出全屏；退出后恢复先前窗口大小及位置。
- 阅读设置从右侧展开，采用紧凑卡片和控件，调整立即预览，关闭自动保存。设置包括阅读模式、方向、双页配对、封面单独显示、缩放、深色/浅色/跟随系统背景、原图/处理后默认选择、翻页效果、动效、章节衔接、工具栏隐藏方式及等待时间，并提供快捷键说明。
- 阅读模式、方向、缩放和配对按书籍保存；背景、动效强度、工具栏隐藏方式、翻页效果、章节提示及左侧面板上次标签全局记住。恢复默认前确认，可选择恢复当前书籍或全部阅读器设置。
- 首次打开新书时沿用最近一次阅读设置；已有书籍优先恢复该书保存的设置。尚无最近阅读设置时使用默认值。

### 进度、原图与异常

- 卷、话和番外分别记录阅读进度与位置，也显示全书总体进度；总体进度按页面数计算。切换模式、章节或退出时保存，再次打开恢复。未读显示「未开始」，最后一页标记「已读完」，可从头重读或继续。
- 可快捷切换原图/处理后，尽量保持页码、滚动位置和缩放；按书籍记住选择。处理结果缺失时提示并提供原图入口；部分页面完成时逐页显示可用状态。
- 文件缺失时保留记录并可重新定位；加载失败显示原因及重试，其余可用页面仍可阅读。外部变化需提示确认，不自动套用不匹配的人工修改。长图加载显示占位，失败可重试。

## 6. 工作台（用户确认的设计）

本节为交互和产品需求记录，不表示现有实现已支持。任务状态、暂停恢复、版本、Lock、模型选择和操作范围等应由 DSH 对照真实 Core/Host 契约后冻结；步骤名称与效果图仅为示意。

### 布局、页面与画布

- 以检查画面为主要场景：顶部工具栏提供原图/处理后/对照、缩放、撤销/重做及处理状态；底部显示当前内容、页码、缩放和保存状态。左侧页面栏、中央画布、右侧编辑/待处理面板均使用紧凑设计。
- 页面栏默认展开、可收起，显示页码、处理状态及未解决问题数量，当前页高亮并可滚动；可筛选全部、未处理、失败或有问题的页面，筛选不改变原有顺序。状态包括未处理、处理中、已完成和失败，失败可查看原因及重试；处理中可查看原图和已有结果，未完成结果明确标识。
- 切换页面恢复工作台默认缩放方式，初始为适合页面，可在设置更改。普通滚轮上下浏览；Ctrl+滚轮或左键按住加滚轮以鼠标位置为中心缩放。左键平移、区域拖动与框选按下述工具及命中规则区分；单击处理结果的区域选择，单击空白处取消，拖动不误触单击。
- 提供原图、处理后、对照三种模式；对照时左原图右结果，同步换页、缩放、移动。设置可选择对照时直接编辑或只查看；允许编辑时只修改结果侧。结果缺失时提示并提供原图入口。分隔线可拖动调整左右宽度，提供等宽恢复；面板收起后画布利用空间。
- 编辑/待处理共用右侧区域，标签切换；编辑面板默认收起，选中可编辑区域后展开，待处理可主动打开。默认右侧停靠并缩小画布，也可拖出独立窗口到第二显示器，仅支持重新停靠右侧。记住位置、大小及停靠状态；第二屏不可用时回主屏。面板内部可滚动，恢复默认布局前确认。
- 方向键微调所选区域，Shift+方向键加大步幅；Ctrl+Z 撤销、Ctrl+Y 重做。提供快捷键说明；输入文字时优先处理文本输入。

#### 画布工具与手势优先级

- 默认检查/选择工具：空白处拖动平移画布；单击区域选中，已选且可编辑的区域内部拖动用于移动区域，控制点拖动用于调整大小。原图侧及只读对照模式只允许平移与查看，不执行区域编辑。
- 平移工具：画布内拖动始终平移，不移动文字区域。框选创建、框选多选和标记工具需明确启用后再操作，分别创建区域、选择区域或添加问题标记，不与默认平移混用。
- 左键按住加滚轮后，本次手势进入缩放，直至松开前不继续平移、移动区域或框选，松开不触发单击。切换工具或取消手势不应提交意外的区域修改。
- 移动阈值、工具快捷键与具体可编辑状态由 DSH 在交互契约中冻结；Lock 对自动覆盖的保护继续按既定规则处理，不能仅因用户进入编辑工具而自动解除 Lock。

### 页面选择、处理入口与任务

- 页面栏支持单选、多选、全选/取消，Shift 连续选择、Ctrl 增减选择；筛选后全选只选择可见页，切换筛选保留选择和总数。选中页面可批量处理、重试失败项或添加整页问题标记；执行前确认范围，完成后显示成功/失败/跳过及明细。
- 右键未选页面先将其作为唯一选中项；右键已选页面保留多选范围。菜单为「翻译选中页」「翻译未翻译」「重新渲染选中页」，只作用于选中页。
- 「开始处理」下拉菜单为「翻译全部」「翻译未翻译（跳过已翻译）」「重新渲染全部」，作用于当前卷、话或番外的全部页面；当前页/选中页另有入口。翻译全部遇已有未锁定译文先提示范围和数量并确认，锁定人工内容受保护；翻译未翻译跳过已有译文。
- 重新渲染使用现有译文及样式，不重新请求翻译；包括人工修改与锁定内容，但只更新样式，保留人工译文和锁定状态。翻译前显示范围、模型、源/目标语言和锁定区域；临时选择只影响本次任务，缺少服务时提示配置。重新渲染前显示样式及影响范围，不要求选择翻译模型。失败不删除已有结果；原文件变化暂停受影响项目并提示。
- 重新渲染锁定区域时，保持原文、人工译文和锁定状态；仅更新用户明确选择的字体、字号、颜色、对齐、行距、方向、描边及背景。区域位置和大小默认不变，新样式放不下时提示，不自动改动区域。应用前显示受影响锁定区域数和预览，并保留可恢复版本；无法安全保留时暂停并说明。具体语义须 DSH 对照现有 Lock 契约裁决。
- 工作台直接显示当前内容项任务进度、正在处理的页或范围及步骤；与用户当前查看的页码分开展示，详情浮层展示各页及各步骤状态、失败原因和重试。概念步骤为检测文字、识别原文、翻译、修复画面、排版生成，**实际步骤与顺序待对照真实流程**。锁定跳过不误报成功。
- 任务总体进度以「已完成页数 / 本次任务实际选择的总页数」显示，不显示总体完成百分比；仅任务要求的步骤完成且结果保存成功的页面计入已完成。处理中的当前页另行显示，等待、失败或跳过页面不计入已完成；结束时分别显示各状态数量。页面其余内容成功、仅锁定区域跳过时标为「已完成（含跳过区域）」，另示跳过区域数量。
- 整话/整卷或分段批量请求翻译时，显示实际请求范围，例如「正在翻译第 1–24 页」，不虚构单页翻译进度；逐页生成结果时再显示正在处理的页。仅收到整批译文尚未保存页面最终结果时，不增加已完成页数；非适用步骤标为不适用/跳过，具体按任务实际流程展示。
- 任务列表展示当前和近期任务、所属内容、范围、进度、耗时及状态；支持状态筛选、可用的暂停/继续/取消、失败页重试、跳转及明细。任务状态区分等待、处理中、暂停中/已暂停、取消中/已取消、部分失败、全部失败和完成。详情可筛选及逐页展开；任务完成后显示简短提示，任务结束后保留明细直至用户主动清理。
- 暂停在安全点完成，继续从可恢复处进行；取消确认后保留已完成结果，未完成停止，可重新发起。意外关闭后显示中断任务，由用户选择继续或取消，不自动重跑；继续前检查原文件变化、人工修改及锁定状态。切换页面时任务继续；正在编辑的页面收到新结果先提示，不自动覆盖。

#### 任务配置快照

- 每次启动翻译、识别或重新渲染任务时，固定本次配置：操作与目标范围、输入及区域版本、服务配置与模型、语言、请求参数、提示词及所用版本/内容、启用词表、上下文范围和内容、样式与字体引用。任务启动后的设置修改只影响新任务，不改变运行或暂停中的任务。
- 启动确认/发送预览使用同一份待执行配置；确认后固化为任务快照。确认前若目标、配置或输入发生变化，更新预览并重新确认，不能展示旧内容却发送新内容。
- 任务记录保存可追溯的配置快照；凭据只记录安全引用，不将密钥明文写入普通任务记录、日志或诊断。凭据不可用或变化导致无法继续时明确提示，不悄悄换服务或模型。
- 暂停后继续、意外中断恢复及失败重试默认沿用原快照；如要使用修改后的配置，应预览差异并确认为新任务，保留与原任务的关联。
- 配置固定不冻结用户保护状态：继续/重试和结果应用前仍检查最新原文件身份、区域版本、人工修改和 Lock。发现变化时暂停或暂存结果供确认，不用旧快照覆盖新修改或新锁定。

### 文字区域、识别与翻译

- 可框选手动创建区域，输入原文及译文；可点击、列表定位、选择重叠区域及多选。画布显示边界，可调整位置大小；多选显示数量，可批量样式、锁定/解锁和删除，解锁或删除前提示，删除可撤销。不可编辑区域跳过并说明，结果显示成功/失败/跳过及明细。
- 编辑时同时查看原文及译文，可修改译文、字体、字号、颜色、对齐、行距和横/竖排；实时预览、确认保存。超出区域时提示不截断，可预览适应区域；可将样式应用到选中区域并确认范围。人工修改标记并默认锁定，不覆盖原文件。
- 选中区域可单独识别，选择识别范围及模型；完成后对照当前原文与结果，可先编辑再应用；有原文时提示替换，应用后未保存。失败保留原文及译文并可重试；识别可取消。
- 区域编辑面板提供翻译此区域及模型/AI 服务选择，默认当前配置，临时选择不改全局默认。翻译目标仅为选中区域原文；为空时提示填写或识别，可临时修改本次原文而不更改原记录。显示过程并允许取消，失败可重试。
- 单区域翻译的目标文字仅为选中区域原文；辅助内容可包括当前生效的通用或服务专用提示词，以及用户启用的术语表/禁翻表中与目标原文匹配的条目。默认不发送相邻页面、其他区域或图片，AI 图像识别为独立操作；可携带结果对应所需区域标识，不必发送本地文件路径。启用发送预览时显示所选服务、目标原文、提示词来源、启用的匹配词条及其他实际发送内容，确认后发送；密钥用于认证，不显示在预览、普通日志或诊断信息中。预览开关与关闭时的确认方式见第 7 节。
- 翻译完成后对照当前与新译文，可先编辑、应用或放弃；结果关联发起的区域，切换区域不改变归属；区域删除或等待期间变化时提示，不自动应用。应用后未保存，放弃未保存修改时恢复应用新译文前的译文；保存后标记人工修改并锁定；可撤销/重做，失败保留编辑，超出提示不截断。
- 查找面板默认收起，可按页码跳转、搜索原文/译文并定位高亮区域；支持筛选未翻译、人工修改、锁定、有问题区域。无数据时明确提示；切页保留条件直至清除或关闭，查找不修改内容。

### 人工修改、问题与版本

- 人工修改默认锁定，锁定状态可见；手动解锁前说明可能被自动处理覆盖。处理前显示影响范围与锁定数量；冲突保留人工修改并提示。可对照新旧结果再决定应用，应用前保留可恢复版本。
- 保存状态显示未保存/保存中/已保存/失败；失败保留内容并可重试。切换页面、内容项或关闭时提示未保存修改。保存后更新结果和缩略图，保留历史版本；可预览版本、查看时间及来源。恢复前确认并保留当前版本；受保护版本不自动清理，具体 Lock/current/pinned 规则由 DSH 冻结。
- 支持整页和位置问题标记，备注非必填、不强制分类。点击标记问题后选择位置，整页可直接标记；位置显示编号。当前内容项所有页面汇总到待处理，默认未解决、可看已解决，支持重新打开和批量解决。点击跳到页面及位置；误标删除前确认，不影响漫画与人工修改。不同内容项分别保存。

### 全局样式与独立字体库

- 全局样式区可创建、命名、保存、复制、重命名、删除和预览样式，删除前确认。样式包括字体及变体、字号、颜色、对齐、行距、文字方向、描边和背景；支持属性选择或保持原样。修改保存的样式不自动更改已应用页面，删除样式也不改变已有结果。
- 可应用到当前区域、选中页面或当前内容项；先预览并显示范围、区域数及锁定区域数，只更新选中样式，保留译文和锁定状态。应用前保留可恢复版本；可设置默认样式，仅影响之后的新处理任务。
- 用户将字体放入独立字体库文件夹，软件识别使用，不直接使用系统字体列表。设置提供打开文件夹、刷新、搜索、字体家族与变体、预览及自定义示例文字；刷新显示可用/失败数量及原因。具体格式需核实；随包字体须先确认许可及来源。
- 独立字体库用于漫画文字排版；软件菜单、按钮及提示等界面文字允许使用系统界面字体。不得把系统字体打包分发，随包字体仍须核对许可。
- 缺失/加载失败时保留字体记录、译文和排版数据；可临时替代预览或确认永久替换并显示影响范围。字符不支持时提示，可选择字体库中的备用字体；原字体恢复可用时提示。软件内删除字体前确认并列出引用样式，不自动修改或删除用户字体。备份/导出是否包含字体由用户选择，嵌入支持与许可需核实。

### 检查、导出与设置

- 新结果待确认时缩略图提示，可与当前结果并排对照、查看范围并选择应用或保留；锁定人工译文不自动覆盖，应用前保留版本，不完整/失败明确提示。
- 导出可选择当前页、选中页或当前内容项，预览范围与顺序，选择原图或处理结果、格式、保存位置与文件名；缺少结果时提示并由用户选择。显示空间估计及同名文件，默认不覆盖；进度可取消，已成功导出保留，失败说明并可重试，完成可打开位置。导出不修改原文件、人工修改或阅读进度。
- 工作台设置包括默认缩放、对照编辑/只读、默认查看模式、页面栏与步骤栏显示、面板位置、待处理默认筛选、任务默认模型和语言、样式和字体库管理；恢复默认前确认。

## 7. 设置页面（已确认的设计）

本次 Fluent 方案的设置为四个一级页面之一，沿用其窄主导航；设置内部左侧分类、右侧内容，控件和卡片紧凑。分类包括常规、界面与主题、阅读器、工作台、翻译、术语与禁翻、文字识别、字体库、文件与存储、备份与回收站、快捷键、关于。翻译与文字识别分开；术语与禁翻为设置内独立一级分类。图中额外控件、路径、服务状态和示例数字不代表已实现或已配置。

### 常规、托盘、界面与主题

- 简体中文默认，暂定英文、日语、韩语；启动页面可选书架、工作台、阅读器或上次页面，默认书架；记住窗口大小和位置。开机自启与启动时最小化可选，默认关闭；关闭窗口可选退出或最小化到系统托盘，默认退出。任务完成通知和自动检查更新可设置；重要删除/清空保留确认；恢复常规设置前确认。
- 最小化到托盘时任务继续，点击图标恢复窗口，右键提供打开主窗口、查看任务、退出及运行任务数量；系统通知可关闭。退出时检查运行任务与未保存修改，提供处理选择；完全退出后图标消失。
- 现有界面与新的 Fluent 界面方案可切换并记住选择；新方案支持深色、浅色、跟随系统，切换前预览，加载失败保留当前界面并提示。亚克力可开关、调整透明和模糊；不可用时使用纯色且保持清晰。
- 强调色默认紫色、可调整；状态色保持可辨识。支持高对比度、界面缩放、控件紧凑程度、主导航展开/收起；动效可开启、关闭或跟随系统，分别控制页面切换、浮层和悬停，并遵循系统减少动态效果偏好。预览可查看书架、工作台、阅读器和设置。
- 组件比例支持整体缩放及分别调整主导航、顶部工具栏、书籍卡片、列表行高、页面缩略图栏、编辑面板、浮层弹窗和界面文字；即时预览、确认应用，可保存多套方案，单项或全部恢复默认。默认紧凑布局及窄导航；漫画画布缩放和译文字号独立。比例范围和小窗口适配待验证。

### 翻译服务、模式与提示词

- 翻译页采用三个独立区、各服务横向列表：本地模型、在线 AI 服务、在线翻译。AI 预设为 DeepSeek 官方、Gemini、OpenAI、OpenCode、CommandCode，并支持自定义；在线翻译包含百度、有道。每项按能力提供配置、测试及管理，独立保存凭据、默认隐藏。预设不是已支持或已配置的承诺，实际协议、字段、模型与能力须核实；各服务凭据不能假定共用。
- AI 服务设置包含接口地址、模型名称、支持时获取模型列表与手填、单独密钥和连接测试；可设默认服务并在任务中临时切换。高级设置默认折叠：请求频率限制、网络与解析失败分别重试、支持时可选流式调用、附加 JSON 格式校验且不得覆盖主配置管理的核心字段。未设置频率限制时遵循服务自身限制。翻译模式、服务能力及预设默认值需对照实际接口验证。
- 提示词仓库集中管理自建模板和受保护的内置默认模板：支持名称、说明、内容、新建、搜索、编辑自建模板、复制、引用查看及删除。内置模板只读不可直接覆盖或删除，可复制后编辑。通用提示词使用下拉单选，所有 AI 默认共用；服务可开启覆盖并从同一仓库单选专用模板，界面标明实际使用的通用或专用状态。在线翻译服务按自身实际能力决定是否支持提示词。
- 删除被引用模板前列出所有引用并要求选择替代项，未选择不删除；可恢复默认，删除不改变已有译文。自建提示词和选择关系随应用数据备份，密钥是否备份单独选择。
- 翻译模式包括单区域、整页批量及整话/整卷。单区域的翻译目标仅为选中区域原文，可按第 6 节附带生效提示词和用户启用的匹配词条等辅助内容；整页可选择携带相邻页面上下文，默认开启前后各 2 页，前后分别最多 5 页，可关闭。边界只取实际存在页面；只将结果应用目标页，相邻页不自动修改。
- 完整发送内容预览默认开启，可在设置中关闭。开启时在启动确认中显示摘要并允许展开完整提示词、原文、词条、图片/区域及其他本次待发送内容；关闭后仍显示启动确认摘要：目标服务/模型、操作范围、上下文及词表是否启用、在线发送的数据类型，以及已有译文和锁定内容的处理影响，不要求展开全文。关闭预览不绕过已有的替换、范围或数据影响确认；密钥在两种状态下始终隐藏。实际发送使用本次任务快照，预览与请求的一致性须按服务验证。
- 上下文默认提供识别原文；是否提供已有译文默认关闭，术语表可选。缺少相邻页识别文字时提示；在线处理前显示发送页及内容类型。容量不足提示减少范围或更换模型，不静默截断；返回结果需校验区域对应关系。锁定区域的原文可作参考，译文发送受相应选项控制。
- 整话/整卷按阅读顺序组织当前内容项的文字，保留页码与区域标识；开始前显示页数、区域数、服务与预计用量，可选择术语表、禁翻表及已有译文作为参考。容量不足时不静默截断或改成逐页；提供按相邻页面分段并携带必要前文和术语的可选方案，由用户确认。结果缺失、重复或对应不明时不自动错位应用，保留已有译文并允许检查或重试；锁定人工译文不自动覆盖。是否发送图片需另行明确，在线发送范围必须可见。

### 术语表与禁翻表

- 术语表记录原文、指定译文及可选备注；禁翻表记录需保留原样的原文及可选备注。可建立、命名、搜索、编辑、导入、导出和删除多套表，删除前显示影响且不更改已有译文。
- 可设置全局默认、为单本书指定表，翻译时选择启用哪些表或关闭；适用于单区域、整页、整话/整卷。开始前显示启用表及在线发送内容。具体服务能否严格遵循术语与禁翻规则，须按能力验证，不把提示词遵循当作已保证结果。
- 同一词条在术语表与禁翻表冲突、或单书与全局不一致时显示来源和影响书籍，由用户选择指定译文或保留原文；未解决翻译前提示，可返回修改；处理不改变已有译文，选择可查看修改。

### 文字识别与字体库

- 文字识别页分本地识别模型、在线识别服务、AI 图像识别三个区，横向列表显示名称、状态、配置和测试。可设默认方式、语言和自动检测/已有区域；任务可临时切换。AI 可选已有且支持图片输入的服务，也可独立配置；能力未确认时显示待测试，实际模型、语言与输入方式须核实。
- AI 支持整页或选区、横竖排识别；在线识别前显示将发送的图片或区域。默认只识别，是否同时翻译另选；返回文字与区域对应不确定时待检查。结果可编辑并单项或批量确认应用，已有原文替换先对照，人工修改及锁定默认保留；空结果不删除已有区域，失败可重试并保留内容。应用后仍需保存，不改原文件。
- 字体库独立于系统字体列表：用户可手动放入字体文件夹后刷新，也可选择一个或多个文件、预览并确认后复制到字体库，原字体文件保留。显示文件夹、打开/刷新、搜索、家族与变体、状态和中日韩示例预览；重复或同名不自动覆盖，读取失败显示原因，不影响其他字体。
- 软件内移除字体前列出引用并确认；缺失时保留原样式记录，可临时预览替代或确认永久替换并显示影响。字符不支持时提示，可选库内备用字体；原字体重新可用时提示。字体备份/导出由用户选择，格式、随包许可和嵌入能力需验证。

### 文件、备份、回收站与快捷键

- 文件与存储分别展示原文件引用状态、应用数据位置、缓存位置和字体库位置；缺失文件可查看并重新定位，应用数据与缓存容量分开显示。更改应用数据位置前展示迁移范围、目标和空间，显示进度，失败保留原数据。缓存仅作为可重新生成内容，清理前说明范围，人工修改和受保护版本不作为缓存删除。
- 更改缓存位置可选迁移或在新位置重新生成；检查目标可写及容量，使用中的缓存等待安全点，迁移显示进度并可取消；验证成功后切换，失败/取消继续使用原位置，旧缓存清理由用户确认。具体数据边界、状态一致性及失败恢复需后续冻结。
- 备份与回收站单独分类：设置备份位置、立即备份与恢复，自动备份可关闭或设每天、每周、自定义间隔及时间。错过计划时下次启动提示是否补做；检查目标可写及容量，备份使用一致的数据状态，显示结果和失败原因；可设保留数量，清理旧备份时保留最近一次可用备份。
- 默认备份应用数据，不含原文件；原文件、字体和服务密钥分别选择，密钥默认不包含。备份前展示估计大小和位置；恢复、冲突及回收站按第 4 节。手动清理为默认，也可设期限；自动清理不操作原文件或 Windows 回收站。恢复入口不因自动备份关闭而禁用。
- 快捷键按全局、书架、阅读器、工作台分类，支持搜索、修改、单项和全部重置；冲突提示并重新设置，不自动覆盖已有绑定。不同页面按生效范围区分；文本输入优先处理文字。全部恢复默认前确认。
- 关于页显示名称、版本、当前界面方案和语言、更新检查、项目许可和第三方许可、项目主页/反馈入口及运行环境基本信息。诊断信息复制前预览，不含密钥和漫画内容，不自动上传；实际版本和链接以发布内容为准。
